## 1. 단순회귀분석 (9장)

### 모형

$$Y_i = \alpha + \beta x_i + \varepsilon_i, \qquad \varepsilon_i \overset{iid}{\sim} N(0, \sigma^2)$$

오차 가정은 곧 **독립성, 정규성, 등분산성** 세 가지다. $$x_i$$는 확률변수가 아닌 주어진 값이다.

### 최소제곱 추정

$$\hat{\beta} = \frac{S_{xy}}{S_{xx}} = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}, \qquad \hat{\alpha} = \bar{y} - \hat{\beta}\bar{x}$$

교재 예제: `mtcars`의 자동변속기 차량 19대(am = 0)의 마력(x)과 연비(y).

```python
import numpy as np
from scipy import stats
x = [110,175,105,245,62,95,123,123,180,180,180,205,215,230,97,150,150,245,175]
y = [21.4,18.7,18.1,14.3,24.4,22.8,19.2,17.8,16.4,17.3,15.2,10.4,10.4,14.7,21.5,15.5,15.2,13.3,19.2]
r = stats.linregress(x, y)
print(r.intercept, r.slope)   # 26.625, -0.0591
print(r.rvalue ** 2)          # 0.691
print(r.pvalue)               # 1.02e-05
```

$$\hat{y} = 26.62 - 0.0591x$$

마력이 1 늘 때 연비가 평균 약 0.059 mpg 줄고, 마력이 연비 변동의 약 69%를 설명한다.

### 분산분석으로 본 적합도

$$SST = SSR + SSE, \qquad \sum(y_i-\bar{y})^2 = \sum(\hat{y}_i-\bar{y})^2 + \sum(y_i-\hat{y}_i)^2$$

| 요인 | 제곱합 | 자유도 | 평균제곱 | F |
| --- | --- | --- | --- | --- |
| 회귀 | SSR | 1 | MSR = SSR/1 | MSR/MSE |
| 잔차 | SSE | n-2 | MSE = SSE/(n-2) | |
| 합계 | SST | n-1 | | |

- **결정계수** $$R^2 = SSR/SST$$. 단순회귀에서는 $$R^2 = r^2$$
- 계수 검정 $$H_0: \beta = 0$$은 $$T = \hat{\beta}/SE(\hat{\beta}) \sim t(n-2)$$. 단순회귀에서는 $$T^2 = F$$

### 잔차 진단

| 그림 | 확인하는 가정 | 나쁜 신호 |
| --- | --- | --- |
| 잔차 vs 적합값 | 선형성, 등분산성 | 곡선 패턴, 깔때기 모양 |
| 잔차 QQ-plot | 정규성 | 직선에서 벗어난 꼬리 |
| 잔차 vs 순서 | 독립성 | 연속된 패턴 (Durbin-Watson 검정) |
| 지렛값, Cook 거리 | 영향점 | 한 점이 직선을 크게 끌어당김 |

### 신뢰구간과 예측구간

$$x_0$$에서

$$\text{평균 반응의 신뢰구간: } \hat{y}_0 \pm t_{\alpha/2}(n-2)\,s\sqrt{\frac{1}{n} + \frac{(x_0-\bar{x})^2}{S_{xx}}}$$

$$\text{새 관측값의 예측구간: } \hat{y}_0 \pm t_{\alpha/2}(n-2)\,s\sqrt{1 + \frac{1}{n} + \frac{(x_0-\bar{x})^2}{S_{xx}}}$$

> 예측구간은 개별 오차 $$\varepsilon$$까지 포함하므로 **항상 신뢰구간보다 넓다.** 두 구간 모두 $$x_0$$가 $$\bar{x}$$에서 멀수록 넓어진다.
{: .prompt-warning }

다중회귀로 넘어가면 범주형 설명변수를 **더미변수**(0/1)로 넣고, 변수 선택에는 수정 $$R^2$$, AIC 같은 기준을 쓴다. R 실습은 기존 글 "06-1. Regression analysis(hp & mpg)"에 있다.

## 2. 분산분석 (10장)

### 일원배치 모형

$$y_{ij} = \mu + \alpha_i + \varepsilon_{ij}, \qquad \sum \alpha_i = 0, \qquad \varepsilon_{ij} \overset{iid}{\sim} N(0,\sigma^2)$$

$$H_0: \alpha_1 = \cdots = \alpha_k = 0 \quad \text{vs} \quad H_1: \text{적어도 하나는 0이 아니다}$$

| 요인 | 제곱합 | 자유도 | F |
| --- | --- | --- | --- |
| 처리 | SSTR | k-1 | MSTR/MSE |
| 오차 | SSE | n-k | |
| 합계 | SST | n-1 | |

실험은 **완전 무작위 순서**로 해야 하고, 고정효과모형의 결론은 실험에 넣은 수준에만 적용된다.

### 예제: InsectSprays

살충제 6종을 각 12번 뿌려 죽은 벌레 수를 셌다.

```python
from scipy import stats
A=[10,7,20,14,14,12,10,23,17,20,14,13]; B=[11,17,21,11,16,14,17,17,19,21,7,13]
C=[0,1,7,2,3,1,2,1,3,0,1,4];            D=[3,5,12,6,4,3,5,5,5,5,2,4]
E=[3,5,3,5,3,6,1,1,3,2,6,4];            F=[11,9,15,22,15,16,13,10,26,26,24,13]
print(stats.f_oneway(A,B,C,D,E,F))  # F = 34.70, p = 3.2e-17
print(stats.bartlett(A,B,C,D,E,F))  # p = 3.3e-05 -> 등분산 가정 의심
```

평균은 A 14.5, B 15.3, F 16.7로 높고 C 2.1, D 4.9, E 3.5로 낮다. F-검정은 "모두 같지는 않다"까지만 말해 주므로, **어느 쌍이 다른지는 다중비교**(Tukey HSD, Bonferroni 등)로 확인한다. 다중비교를 하는 이유는 t-검정을 여러 번 반복하면 전체 제1종 오류가 $$\alpha$$보다 커지기 때문이다.

> Bartlett 검정이 등분산을 기각하므로, 이 자료는 제곱근 변환 후 분석하거나 비모수 **Kruskal-Wallis 검정**(p = 1.5e-10)을 함께 보는 편이 안전하다.
{: .prompt-info }

이원배치법은 두 요인과 **교호작용**을, 공분산분석은 연속형 공변량을 보정한 뒤 처리 효과를 본다. R 실습은 기존 글 "07. Statistics(ANOVA)"에 있다.

## 3. 범주형 자료분석 (11장)

### 모비율 검정

$$\hat{p} = \frac{X}{n}, \qquad Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}} \approx N(0,1) \quad (n\hat{p} > 5,\; n(1-\hat{p}) > 5)$$

- 일표본: UCBAdmissions 학과 A는 933명 중 601명 합격. `binom.test(601, 933, 0.6)` → $$\hat{p} = 0.644$$, 95% CI (0.612, 0.675), p = 0.0061 → 합격률이 60%라고 보기 어렵다
- 이표본: 학과 A 601/933, 학과 B 370/585. `prop.test` → p = 0.6845 → **합격률이 다르다고 할 근거가 없다**

### 적합도 검정

$$\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} \sim \chi^2(k-1), \qquad E_i = n p_{i0}$$

예: 휴대전화 브랜드 A, B, C의 점유율이 1:2:1인지 100명에게 조사해 20, 55, 25명을 얻었다. 기대빈도 25, 50, 25로

$$\chi^2 = \frac{25}{25} + \frac{25}{50} + 0 = 1.5, \qquad \text{p} = 0.472$$

이므로 1:2:1이 아니라고 할 근거가 없다.

### 독립성 검정

$$r \times c$$ 교차표에서 $$E_{ij} = \dfrac{n_{i\cdot}\,n_{\cdot j}}{n}$$, $$\chi^2 \sim \chi^2((r-1)(c-1))$$.

**기대빈도 조건**: 모든 셀의 기대빈도가 5 이상이어야 카이제곱 근사가 맞다. 아니면 셀을 합치거나 **피셔의 정확검정**(초기하분포)을 쓴다.

교재의 가짜 자료(흡연 40명 중 폐암 6명, 비흡연 100명 중 폐암 3명):

```python
import numpy as np
from scipy import stats
T = np.array([[6, 34], [3, 97]])
chi2, p, dof, E = stats.chi2_contingency(T)
print(E)                        # [[2.57 37.43] [6.43 93.57]]
print(stats.fisher_exact(T))    # p = 0.0165
```

폐암 열의 기대빈도 2.57이 5보다 작으므로 카이제곱 대신 피셔 검정을 쓰고, p = 0.0165로 흡연과 폐암이 독립이 아니라고 결론짓는다.

## 최종 핵심 정리

1. 단순회귀의 오차 가정은 독립성, 정규성, 등분산성이다
2. 최소제곱 기울기는 Sxy/Sxx이며 직선은 항상 평균점을 지난다
3. 결정계수는 SSR/SST로 반응변수 변동 중 모형이 설명하는 비율이다
4. 잔차도와 QQ-plot으로 회귀 가정을 진단하고, 예측구간은 신뢰구간보다 항상 넓다
5. 일원배치 분산분석의 F-검정은 평균이 모두 같은지만 판단하고, 어느 쌍이 다른지는 다중비교로 찾는다
6. 등분산 가정이 깨지면 변환하거나 Kruskal-Wallis 같은 비모수 검정을 쓴다
7. 적합도 검정은 관측빈도와 가정된 비율의 기대빈도를 카이제곱 통계량으로 비교한다
8. 독립성 검정에서 기대빈도가 5보다 작은 셀이 있으면 피셔의 정확검정을 쓴다
