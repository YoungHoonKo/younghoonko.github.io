## 1. 정보통신이란

- **정의**: 컴퓨터를 이용한 정보처리 기술과 정보를 전달하는 통신 기술의 결합. 컴퓨터, 스마트폰 같은 단말을 통신망에 접속해 데이터를 전송하고 교환하는 체제
- 4차 산업혁명: 개별적으로 발전한 기술들이 **융합**해 새 가치를 만들고, 초연결성과 초지능화가 특징 (IoT, 클라우드, 빅데이터, AI)
- 기술 발전 방향: 정보통신(IT)이 나노(NT), 바이오(BT), 문화(CT), 환경(ET), 우주(ST) 기술과 융합 → 인간 중심형 기술
- 딥러닝: 인간의 뇌 구조를 본뜬 다층 인공신경망. 사람이 규칙을 정하지 않아도 데이터에서 스스로 학습

## 2. 통신 속도와 용량

| 용어 | 뜻 | 단위 |
| --- | --- | --- |
| 데이터 신호 속도 | 1초에 보내는 비트 수 | bps |
| 변조 속도 | 1초에 바뀌는 신호(심볼) 수 | baud |
| 베어러 속도 | 데이터 + 동기·제어 비트까지 포함한 속도 | bps |
| 통신 용량 | 채널로 **오류 없이** 보낼 수 있는 최대 속도 | bps |

$$\text{bps} = \text{baud} \times \log_2 M \quad (M: \text{심볼 하나가 가질 수 있는 상태 수})$$

통신 용량의 이론적 상한은 섀넌 공식 $$C = B\log_2(1 + S/N)$$으로, 대역폭 B와 신호 대 잡음비가 클수록 커진다.

## 3. 전송 방식

### 통신 회선 이용 방식

| 방식 | 방향 | 동시 송수신 | 예 |
| --- | --- | --- | --- |
| 단방향 (simplex) | 한쪽으로만 | 불가 | 라디오, TV 방송 |
| 반이중 (half-duplex) | 양방향 | **불가** (번갈아) | 무전기 |
| 전이중 (full-duplex) | 양방향 | 가능 | 전화 |

### 직렬과 병렬

- **직렬 전송**: 한 회선으로 비트를 하나씩. 회선 비용이 적어 원거리에 적합
- **병렬 전송**: 여러 회선으로 여러 비트를 동시에. 빠르지만 회선이 많아 근거리(컴퓨터 내부 버스, 프린터 포트)용

### 비동기식과 동기식

| | 비동기식 | 동기식 |
| --- | --- | --- |
| 단위 | **문자** 단위 | **블록(프레임)** 단위 |
| 동기 방법 | 문자마다 시작 비트와 정지 비트 | 별도 동기 문자나 클록 신호 |
| 효율 | 오버헤드가 커서 낮음 | 높음, 고속 전송에 적합 |

## 4. 부호화와 신호 변환

### 정보 부호

정보 부호화는 사람이 쓰는 정보를 전송 가능한 신호로 바꾸는 것이다.

| 코드 | 비트 | 비고 |
| --- | --- | --- |
| BCD | 6비트 | 초기 코드 |
| ASCII | 7비트 (+ 패리티 1비트) | 미국 표준, 데이터 통신의 기본 |
| EBCDIC | 8비트 | IBM이 만든 확장 BCD, 대형 컴퓨터 |

### 정보와 신호의 네 가지 조합

| 원래 정보 | 전송 신호 | 방식 | 장치 |
| --- | --- | --- | --- |
| 디지털 | 디지털 | **베이스밴드 전송**: 직류 펄스를 변조 없이 그대로 | 근거리 LAN, 컴퓨터-단말 |
| 아날로그 | 디지털 | **펄스 부호 변조(PCM)**: 표본화 → 양자화 → 부호화 | 코덱 |
| 디지털 | 아날로그 | **브로드밴드 전송(디지털 변조)**: ASK, FSK, PSK | 모뎀 |
| 아날로그 | 아날로그 | **아날로그 변조**: AM, FM, PM | 라디오, TV |

> 베이스밴드는 직류 성분 때문에 거리가 멀어지면 신호가 약해지고 왜곡되어 **장거리에 적합하지 않다.** 컴퓨터의 디지털 데이터를 아날로그 전화망으로 보내려면 모뎀이 디지털 신호를 아날로그 반송파에 실어야 한다.
{: .prompt-info }

### 다중화

하나의 고속 회선에 여러 신호를 겹쳐 보내는 것. 장치는 **다중화기(MUX)**.

| 방식 | 나누는 대상 |
| --- | --- |
| 주파수 분할 (FDM) | 주파수 대역을 나눠 각 채널에 할당, 사이에 보호 대역 |
| 시분할 (TDM) | 시간 슬롯을 나눠 할당. 동기식(고정 슬롯)과 비동기식(통계적, 데이터 있는 채널만) |
| 코드 분할 (CDM) | 채널마다 다른 코드를 곱해 같은 시간, 같은 주파수에 섞어 보냄 |

## 5. 정보통신 시스템의 구성

정보통신 시스템은 지리적으로 떨어진 정보원과 목적지 사이에서 정보를 전송하고 처리하는 시스템이다.

```text
[정보 전송 시스템]                                         [정보 처리 시스템]
 단말장치(DTE) ── 신호변환장치(DCE) ── 통신회선 ── 신호변환장치 ── 통신제어장치 ── 컴퓨터(CPU, 기억장치, 입출력)
```

| 구성 요소 | 역할 |
| --- | --- |
| 데이터 단말장치 (DTE) | 데이터의 입출력. 키보드, 모니터, 프린터, 스마트폰 |
| 신호 변환장치 (DCE) | 신호를 회선에 맞게 변환. 아날로그 회선은 **모뎀**, 디지털 회선은 **DSU** |
| 통신 회선 | 데이터가 실제로 이동하는 경로 |
| 통신 제어장치 (CCU) | 컴퓨터와 회선 사이에서 오류 제어, 흐름 제어, 데이터를 컴퓨터가 처리하기 좋은 형식으로 변환 |
| 통신 소프트웨어 | 웹 브라우저, 단말 제어 소프트웨어 등 |

## 6. 프로토콜과 표준화

**프로토콜**: 통신하려는 개체 사이에서 무엇을, 어떻게, 언제 통신할지 정한 규약 (구문, 의미, 타이밍).

- 회사마다 다른 프로토콜을 써서 호환성 문제가 생김 → CCITT(현 ITU-T)가 통합을 권고하고, ISO가 **OSI 참조 모델**을 발표(1984)
- 현재 인터넷에서는 **TCP/IP**를 주로 쓴다

| 구분 | 특징 | 예 |
| --- | --- | --- |
| 공식 표준화 | 정부나 공인 기구가 정함. 국제-지역-국가 단위가 위아래로 연결 | ITU(국제), ETSI(유럽), ATIS·TIA(미국), ARIB(일본), TTA(한국) |
| 사실 표준화 | 업체나 포럼, 컨소시엄이 만들고 시장에서 채택 | 미국 중심. 최근에는 공식 기구와 협력 |

## 7. OSI 7계층

하위 계층(1~3)은 통신망 안에서의 **전달 기능**, 상위 계층(4~7)은 그 경로를 이용한 **정보 교환 절차**를 맡는다.

| 계층 | 역할 | 데이터 단위 |
| --- | --- | --- |
| 7 응용 | 사용자가 네트워크에 접근하게 함 (전자우편, 파일 전송, 분산 정보 서비스) | 메시지 |
| 6 표현 | 코드 변환, 암호화, 압축 → 응용 프로세스가 데이터 표현 방식에 신경 쓰지 않게 함 (구문 독립성) | 메시지 |
| 5 세션 | 응용 프로세스 사이의 대화(세션) 설정·관리·해제, 동기점 삽입 | 메시지 |
| 4 전송 | 종단 간(end-to-end) 신뢰성 있는 전송, 오류 복구와 흐름 제어 | 세그먼트 |
| 3 네트워크 | 경로 설정(라우팅)과 패킷 전달, 네트워크 연결 설정·유지·해제 | 패킷 |
| 2 데이터 링크 | 인접 노드 사이의 신뢰성 있는 전송: 프레이밍, 오류 검출, 흐름 제어 | 프레임 |
| 1 물리 | 케이블 형태와 핀 배치, 전압 같은 **기계적·전기적·기능적·절차적** 특성. 구조 없는 비트열 전송 | 비트 |

> **(중요!!)** 데이터 링크 계층은 **이웃한 두 노드** 사이, 전송 계층은 **양 끝 호스트** 사이의 신뢰성을 책임진다. 둘 다 오류 제어와 흐름 제어를 하지만 범위가 다르다.

## 최종 핵심 정리

1. 정보통신은 컴퓨터의 정보처리 기술과 통신 기술의 결합이다
2. bps는 초당 비트 수, baud는 초당 신호 변화 수이며 bps = baud × log₂M이다
3. 반이중은 양방향이지만 동시에 보낼 수 없고, 전이중은 동시에 송수신한다
4. 비동기식은 문자마다 시작·정지 비트를 붙이고, 동기식은 블록 단위로 보내 효율이 높다
5. 베이스밴드는 디지털을 그대로, PCM은 아날로그를 디지털로, 모뎀은 디지털을 아날로그로 바꾼다
6. 다중화는 주파수, 시간, 코드를 나눠 한 회선에 여러 신호를 싣는다
7. 정보통신 시스템은 DTE, DCE(모뎀·DSU), 통신회선, 통신제어장치, 컴퓨터로 구성된다
8. OSI 하위 3계층은 망 내부 전달, 상위 4계층은 종단 간 정보 교환을 맡는다
