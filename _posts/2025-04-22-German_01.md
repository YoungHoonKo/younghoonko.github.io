## 1. 발음

### 모음

| 철자 | 발음 | 예 |
| --- | --- | --- |
| a | [aː] 길게 / [a] 짧게 | Abend, Haar / alt, Wasser |
| e | [eː] / [ɛ] / 끝에서 약한 [ə] | Tee / Bett / Name |
| i, ie | [iː] / [ɪ] | Kino, sie / immer |
| o | [oː] / [ɔ] | Ofen, Sohn / oft, Sonne |
| u | [uː] / [ʊ] | du / Mutter |
| ä | [ɛː] ≈ "애" | Käse, Mädchen |
| ö | [øː] ≈ 입술을 "오"로 둥글게 하고 "에" | schön, möchten |
| ü | [yː] ≈ 입술을 "우"로 하고 "이" | über, fünf |
| ei, ai | [aɪ] "아이" | Eis, mein, Mai |
| eu, äu | [ɔʏ] "오이" | heute, Deutsch, Verkäufer |
| au | [aʊ] "아우" | Auto, Baum |

- 모음 뒤에 자음이 하나면 대체로 길고(Tag), 둘 이상이면 짧다(Bett). 모음 뒤의 h는 소리 없이 모음을 길게 한다(wohnen, fahren)

### 자음

| 철자 | 발음 | 예 |
| --- | --- | --- |
| 단어 끝의 b, d, g | [p], [t], [k] (무성음) | gelb, Kind, Tag |
| s + 모음 | [z] ≈ "ㅈ" | Salz, Sonntag, sind |
| ss, ß | [s] | essen, Fuß |
| sch | [ʃ] "슈" | Schule, schön |
| tsch | [tʃ] "취" | Deutsch, Tschüs |
| a, o, u, au + ch | [x] 목구멍 "흐" | Buch, Nacht, auch |
| e, i, 자음 + ch | [ç] "히" | ich, Milch, richtig |
| w | [v] | wo, wie, was |
| v | 대부분 [f], 외래어는 [v] | Vater / Vase, Klavier |
| j | [j] "이" | ja, jung |
| z, tz, ds, ts | [ts] "츠" | Zeit, jetzt, abends |
| -tion | [tsjoːn] | Nation, Station |
| qu | [kv] | Quelle |
| ng, nk | [ŋ], [ŋk] | singen, Bank |
| st, sp (어두) | [ʃt], [ʃp] | Stadt, sprechen |

> **(중요!!)** 한국인이 가장 많이 틀리는 것: **w는 [v]**(wo = "보"), **s + 모음은 [z]**, **ch는 앞 모음에 따라 "흐"와 "히"**로 갈린다. ich는 "이히", Buch는 "부흐".
{: .prompt-warning }

### 단어 강세

독일어 고유어는 대부분 **첫음절**에 강세가 온다: héißen, lérnen, Thómas, Mónika, Wíedersehen. 외래어와 -isch 형용사, 일부 부사는 다르다: ja·pá·nisch, i·ta·lié·nisch, wo·hér.

## 2. 명사와 관사

### 명사의 성·수·격

- 성: 남성(der), 여성(die), 중성(das). 명사는 **항상 대문자**로 쓴다
- 복수의 정관사는 성과 상관없이 die. 복수로만 쓰는 명사도 있다: die Eltern(부모), die Leute(사람들), die Ferien(방학)
- 격: 1격(Nominativ, ~는), 2격(Genitiv, ~의), 3격(Dativ, ~에게), 4격(Akkusativ, ~을)

성은 외워야 하지만 어미로 짐작할 수 있다.

| 성 | 어미 | 예 |
| --- | --- | --- |
| 남성 | -er, -ent, -ig, -ich, -ar, -or, -ier | Vater, König, Autor |
| 여성 | -e, -ung, -heit, -keit, -schaft, -ion, -ei, -in | Übung, Gesundheit, Station, Bäckerei |
| 중성 | -um, -chen, -ment, -o | Studium, Mädchen, Auto |

Mädchen(소녀)은 뜻은 여성이지만 **-chen 때문에 중성**(das Mädchen)이다.

### 관사의 격변화

정관사

| 격 | 남성 | 여성 | 중성 | 복수 |
| --- | --- | --- | --- | --- |
| 1격 | der | die | das | die |
| 2격 | des | der | des | der |
| 3격 | dem | der | dem | den |
| 4격 | den | die | das | die |

부정관사 (복수 없음) / 부정의 kein (복수 있음)

| 격 | 남성 | 여성 | 중성 | kein 복수 |
| --- | --- | --- | --- | --- |
| 1격 | ein / kein | eine / keine | ein / kein | keine |
| 2격 | eines / keines | einer / keiner | eines / keines | keiner |
| 3격 | einem / keinem | einer / keiner | einem / keinem | keinen |
| 4격 | einen / keinen | eine / keine | ein / kein | keine |

외우는 요령: 1격과 4격은 **남성만 다르고**(der → den, ein → einen) 나머지는 같다. 직업, 국적, 전공 앞에서는 관사를 생략한다: Ich bin Student.

## 3. 인칭대명사와 현재 인칭변화

### 규칙 동사: wohnen (살다), 어간 wohn-

| 인칭 | 대명사 | 어미 | wohnen | arbeiten |
| --- | --- | --- | --- | --- |
| 1인칭 단수 | ich | -e | wohne | arbeite |
| 2인칭 단수 (친칭) | du | -st | wohnst | arbeit**e**st |
| 3인칭 단수 | er / sie / es | -t | wohnt | arbeit**e**t |
| 1인칭 복수 | wir | -en | wohnen | arbeiten |
| 2인칭 복수 (친칭) | ihr | -t | wohnt | arbeit**e**t |
| 3인칭 복수 / 존칭 | sie / Sie | -en | wohnen | arbeiten |

- 어간이 **-t, -d로 끝나면** du, er, ihr에서 발음을 위해 e를 넣는다: arbeitest, antwortet, kostet
- 어간이 **-s, -ß, -z로 끝나면** du에서 s를 하나만: du heißt
- 존칭 Sie는 항상 대문자이고 3인칭 복수와 같은 형태

### 불규칙 동사: sein, haben

| | sein (이다) | haben (가지다) |
| --- | --- | --- |
| ich | bin | habe |
| du | bist | hast |
| er/sie/es | ist | hat |
| wir | sind | haben |
| ihr | seid | habt |
| sie/Sie | sind | haben |

### W-의문사

| 의문사 | 뜻 | 예 |
| --- | --- | --- |
| was | 무엇 | Was machst du hier? |
| wer | 누구 | Wer ist das? |
| wie | 어떻게 | Wie heißen Sie? Wie geht es dir? |
| wo | 어디에 | Wo wohnst du? |
| woher | 어디에서 | Woher kommen Sie? |

- W-의문문: 의문사 + **동사(2번째 자리)** + 주어 ...?
- 예·아니오 의문문: **동사가 맨 앞**: Wohnst du in Bonn?
- 평서문도 동사는 항상 **두 번째 자리**: Aber Dino wohnt in Bonn.

## 4. 중간고사 연습문제 풀이

아래 답은 문법 규칙으로 직접 풀어 본 것이다. V번처럼 정해진 답이 없는 문항은 예시 답이다.

### I. 알맞은 의문사

| 문제 | 답 |
| --- | --- |
| ( ) sind Sie von Beruf? | **Was** |
| Ich komme aus Korea. Bitte, ( ) kommen Sie? | **woher** |
| ( ) machst du hier? Ich lerne Deutsch. | **Was** |
| Ich heiße Miran Kim. Bitte, ( ) heißen Sie? | **wie** |
| ( ) wohnst du? Ich wohne in Seoul. | **Wo** |

### II. 현재 인칭변화

| 문제 | 답 |
| --- | --- |
| Ich ( ) Techniker. (sein) | bin |
| ( ) du in Busan? Nein, ich ( ) in Seoul. (wohnen, arbeiten) | Wohnst / arbeite |
| Frau Kim ( ) auf Deutsch. (antworten) | antwortet |
| Wo ( ) ihr denn? (wohnen) | wohnt |
| Was ( ) er? (studieren) | studiert |
| Ihr ( ) Student und Studentin. (sein) | seid |
| Wie ( ) es dir? (gehen) | geht |
| Mein Name ( ) Mina Kang. (sein) | ist |
| Er ( ) einen Apfel. (kaufen) | kauft |
| Wie ( ) er? (heißen) | heißt |
| Ihr ( ) einen Sohn. (haben) | habt |
| Wie viel ( ) das Auto? (kosten) | kostet |
| ( ) Sie eine Tochter? Ja, ich ( ) eine Tochter und ( ) Sohn. Sie ( ) heute nicht. (haben, kommen) | Haben / habe / einen / kommen |
| ( ) Sie Deutsch? (lernen) | Lernen |

### III. 문장 만들기

1. Monika wohnt nicht in Bonn, aber Dino wohnt in Bonn.
2. Was machen Sie? Arbeiten Sie hier?
3. Du lernst Deutsch, aber wir lernen Englisch.
4. Ich bin Cheolsu Kim. (또는 Ich heiße Cheolsu Kim.)
5. Petra wohnt in Bonn.
6. Ihr kommt aus den Niederlanden. Wir kommen aus der Schweiz.

6번처럼 나라 이름에 관사가 붙는 경우(die Niederlande 복수, die Schweiz 여성) aus 뒤에서 **3격**(den, der)이 된다.

### IV. 국적의 짝

| 문제 | 답 |
| --- | --- |
| Ich bin Franzose, du bist ( ). | Französin |
| Er ist Chinese, und sie ist ( ). | Chinesin |
| Helena ist Griechin. Hektor ist auch ( ). | Grieche |
| Frau Ito ist Japanerin. Herr Ito ist auch ( ). | Japaner |
| Ich komme aus der Türkei. Aschim ist auch ( ). | Türke |

여성형은 대부분 **-in**을 붙이고, -e로 끝나는 남성형은 e를 빼고 -in(Franzose → Französin, Chinese → Chinesin).

### V. 질문에 답하기 (예시)

- Wie geht es Ihnen? → Danke, gut.
- Was studiert er? Jura? → Nein, er studiert Informatik.
- Wie heißt du? → Ich heiße Younghoon.
- Wo wohnst du? → Ich wohne in Seoul.
- Sind Sie Deutscher? → Nein, ich bin Koreaner.

## 최종 핵심 정리

1. w는 [v], s + 모음은 [z], 단어 끝의 b·d·g는 [p]·[t]·[k]로 발음한다
2. ch는 a·o·u·au 뒤에서 "흐", e·i·자음 뒤에서 "히"이고, ei는 "아이", eu는 "오이", ie는 긴 "이"다
3. 고유어의 강세는 대부분 첫음절에 온다
4. 명사는 대문자로 쓰고 성·수·격을 가지며, 어미로 성을 짐작할 수 있지만 -chen은 항상 중성이다
5. 관사의 1격과 4격은 남성만 다르다(der/den, ein/einen)
6. 규칙 동사 현재 어미는 -e, -st, -t, -en, -t, -en이고, 어간이 -t·-d로 끝나면 e를 넣는다
7. sein은 bin, bist, ist, sind, seid, sind, haben은 du hast, er hat이 불규칙이다
8. 평서문과 W-의문문에서 동사는 두 번째 자리, 예·아니오 의문문에서는 맨 앞에 온다
