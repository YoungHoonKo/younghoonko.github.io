## 1. 절대주의 (15장)

| 특징 | 내용 |
| --- | --- |
| 정치 이념 | **왕권신수설** |
| 통치 기구 | 관료제, 상비군, 통일된 재정 |
| 경제 정책 | **중상주의** |
| 성격 | 근대 국민국가가 아닌 **왕조 국가**. 봉건적 요소와 부르주아적 요소가 혼재 |

### 중상주의

1. 중금주의: 금과 은의 축적
2. 무역차액정책: 수출 증대, 수입 억제
3. 중공주의: 수출 산업 보호와 육성
4. 식민지 정책: 원료 공급지이자 판매 시장

한계는 자유로운 경제 발전을 막고 대외 전쟁을 부추긴 것, 의의는 초기 자본주의를 보호하고 키운 것이다.

### 나라별 절대왕정

| 나라 | 전개 |
| --- | --- |
| 에스파냐 | 이사벨과 페르난도의 결혼(1469) → 카를 5세 → 펠리페 2세. 가톨릭 중심의 경직된 정책 → 네덜란드 독립(1581), **무적함대 패배(1588)** 로 쇠퇴 |
| 프랑스 | 앙리 4세의 **낭트 칙령(1598)** → 리슐리외(국가 이성) → 루이 14세와 콜베르의 중상주의, 베르사유 궁전 → 침략전쟁과 **낭트 칙령 철회(1685)** 로 쇠퇴 |
| 프로이센 | 30년 전쟁과 베스트팔렌 조약이 독일 통일을 방해 → 프리드리히 2세의 **계몽 전제군주** 정치, 오스트리아 왕위계승 전쟁과 7년 전쟁 |
| 러시아 | 표트르 대제의 서구화와 상트페테르부르크 천도 → 예카테리나 2세의 폴란드 분할과 남하 |

## 2. 영국의 혁명 (16장)

### 튜더 왕조의 절대왕정

- 장미전쟁(1455~1485)으로 봉건 세력 약화 → 헨리 7세 → 헨리 8세의 종교개혁 → **엘리자베스 1세**(국교회 확립, 무적함대 격파)
- 영국 절대왕정은 **헌정 전통과 의회를 존중**했다는 점이 대륙과 다르다
- 1차 인클로저와 모직물 공업으로 **젠트리**가 성장 → 하원과 치안판사로 활동, 청교도 신앙

### 스튜어트 왕조와 두 혁명

```text
제임스 1세: 왕권신수설, 의회 승인 없는 과세, 청교도 압박 (메이플라워호 1620)
 → 찰스 1세: 권리청원 승인(1628) 후 11년간 의회 미소집
 → 스코틀랜드 전쟁 비용 때문에 의회 소집(1640) → 대간의서(1641)
 → 왕당파 vs 의회파 내전(1642) → 크롬웰의 철기군, 네이즈비 전투(1645)
 → 찰스 1세 처형(1649), 공화정 → 크롬웰의 호국경 독재, 항해조례(1651)
 → 왕정복고(1660): 찰스 2세 → 심사령(1673), 인신보호법(1679), 토리 vs 휘그
 → 제임스 2세의 가톨릭 부활 정책
 → 명예혁명(1688): 윌리엄과 메리, 권리장전(1689)
```

> **(중요!!)** 명예혁명으로 **의회 우위의 입헌정치**가 확립되었다. 하노버 왕조의 조지 1세 때부터 책임내각제의 관습이 생겼고, 명예혁명은 미국혁명과 프랑스 혁명에 영향을 주었다.
{: .prompt-warning }

## 3. 미국혁명 (17장)

- 영국의 **건전한 방임정책(salutary neglect)** 아래 식민지는 넓은 자치를 누림
- 7년 전쟁(1756~63) 비용 때문에 정책 전환: 설탕법(1764), **인지법(1765)**, 타운센드법(1767)
- 보스턴 학살(1770) → **보스턴 차 사건(1773)** → 참을 수 없는 법(1774) → 1차 대륙회의 → 렉싱턴·콩코드(1775) → **독립선언(1776.7.4)** → 사라토가(1777) → 요크타운(1781) → 파리조약(1783)
- 연합규약(1777 제정, 1781 발효)으로는 13개 국가의 연합에 불과 → 헌법제정회의(1787): **3권분립의 공화제 헌법** → 워싱턴 초대 대통령(1789) → 권리장전(수정헌법 10개조, 1791)

한계: 인디언과 흑인은 고려하지 않았고 사회혁명으로서의 성격이 약했다.

## 4. 프랑스 혁명 (18장)

배경: 1·2신분의 특권과 3신분(시민계급, 농민, 상퀼로트)의 불만, 왕실 재정 악화, 흉작, 계몽사상, 미국혁명.

| 단계 | 주요 사건 |
| --- | --- |
| 국민제헌의회 (1789~91) | 삼부회 → 국민의회, 테니스코트 서약 → **바스티유 습격(1789.7.14)** → 봉건제 폐지 선언(8.4, 봉건 공납은 유상 폐지) → **인권선언(8.26)** → 교회 재산 몰수, 길드 폐지 → 국왕 도주 미수(1791.6) → 1791년 헌법: 유산계급만 선거권을 갖는 입헌군주제 |
| 입법의회 (1791~92) | 지롱드파 주도, 오스트리아·프로이센에 선전포고(1792.4), 왕궁 습격과 왕권 정지 |
| 국민공회 (1792~95) | 1공화정 선포, 루이 16세 처형(1793.1) → 지롱드파 숙청과 산악파 집권(1793.6) → **로베스피에르의 공포정치**, 봉건 공납 무상 폐지, 최고가격제 → **테르미도르 반동(1794.7)** |
| 총재정부 (1795~) | 1795년 헌법: 제한선거, 양원제 → 유산계급의 승리 |

> 프랑스 혁명은 부르주아 혁명이면서, 도시와 농촌의 민중이 적극 참여한 **민중혁명**이었고, 보편적 **국민주권**을 확립했다.
{: .prompt-info }

## 5. 빈 체제와 자유주의 (19장)

- **빈 회의(1814~15)**: 메테르니히 주도, **정통주의**와 보상주의 원칙 → 신성동맹, 4국(5국) 동맹으로 자유주의와 민족주의 억압
- 동요: 라틴아메리카 독립(볼리바르, 먼로주의 1823), 그리스 독립(1829)

| 혁명 | 원인 | 결과 |
| --- | --- | --- |
| 7월 혁명 (1830) | 샤를 10세의 반동 정치 | 루이 필리프의 입헌군주정, 벨기에 독립 |
| 2월 혁명 (1848) | 제한 선거권, 7월 왕정의 보수화, 경제 위기 | 2공화정, 루이 나폴레옹 대통령. 빈 3월 혁명으로 **메테르니히 몰락**, 프랑크푸르트 국민의회 |

### 영국의 점진적 개혁

- 심사령 폐지(1828), 가톨릭 해방령(1829) → **1차 선거법 개정(1832)**: 부패 선거구 폐지
- **차티스트 운동(1838~48)**: 인민헌장(성년 남자 보통선거, 비밀투표, 의원 재산 자격 철폐 등 6개조). 실패했지만 노동자 최초의 정치 운동으로 이후 선거법 개정(1867, 1884)에 영향
- 곡물법 폐지(1846), 항해법 폐지(1849) → **자유방임주의** 확립

## 6. 민족주의와 통일 (20장)

| 나라 | 과정 |
| --- | --- |
| 프랑스 | 루이 나폴레옹의 쿠데타 → **2제정(1852~70)**, 보나파르티즘 → 보불전쟁 패배 → 파리 코뮌(1871) → 3공화정 헌법(1875), 블랑제·드레퓌스 사건을 넘어 공화정 정착 |
| 이탈리아 | 카르보나리, 청년이탈리아당 실패 → 사르데냐의 **카보우르**(외교와 산업) + **가리발디**(남부 점령) → 이탈리아 왕국(1861) → 베네치아(1866), 로마(1870) |
| 독일 | 관세동맹(오스트리아 배제) → 자유주의 통일 실패(프랑크푸르트 국민의회) → **비스마르크의 철혈정책** → 대오스트리아 전쟁, 대프랑스 전쟁(엠스 전보) → **독일제국(1871)** |
| 미국 | 영미전쟁, 먼로주의 → 서부 개척 → 남(농업, 노예제, 자유무역) vs 북(공업, 보호무역) → **남북전쟁(1861~65)**, 노예해방령(1863.1.1) |
| 러시아 | 데카브리스트의 난 진압, 크림전쟁 패배 → 알렉산드르 2세의 **농노해방령(1861)**, 젬스트보 → 암살 후 반동화 |

## 7. 제국주의와 1차 세계대전 (21장)

- **고전적 제국주의**(1870년대~20세기 초): 2차 산업혁명 이후 원료, 상품 시장, **잉여자본 투자처**를 찾아 아프리카와 아시아를 분할

### 동맹 체제의 변화

| 시기 | 체제 |
| --- | --- |
| 비스마르크 | **프랑스 고립**: 삼제협약(1873), 삼국동맹(1882, 독일·오스트리아·이탈리아), 독러 재보장조약(1887) |
| 빌헬름 2세 | 비스마르크 실각(1890), 재보장조약 파기 → 세계정책, 해군법(1898), 3B 정책 |
| 결과 | **삼국협상**: 러불동맹(1894), 영불협상(1904), 영러협상(1907) |

- 위기: 모로코 사건(1905, 1911), 오스트리아의 보스니아 합병(1908), 발칸전쟁(1912, 1913) → "유럽의 화약고"
- 발발: **사라예보 사건(1914.6.28)** → 오스트리아의 대세르비아 선전포고(7.28) → 러시아 총동원(7.30) → 독일의 대러(8.1)·대불(8.3) 선전포고, 벨기에 침공 → 영국 참전(8.4)
- 성격: 슐리펜 계획 실패로 **장기 참호전**, 전 국민이 동원된 **총력전**, 선전전
- 미국 참전(1917.4, 무제한 잠수함 작전이 계기) → 러시아 이탈(브레스트-리토프스크 조약, 1918.3) → 킬 군항 반란, 빌헬름 2세 퇴위 → **휴전(1918.11.11)**
- 영향: 행정부 우위, 여성 지위 향상, **유럽 우월주의의 붕괴**

## 8. 베르사유 체제와 전체주의 (22장)

- 파리 강화회의(1919.1), 윌슨의 **14개조**(민족자결) → 비밀조약 때문에 한계
- **베르사유 조약(1919.6.28)**: 독일의 식민지 상실, 군비 제한, 알자스-로렌 반환, 배상금
- **국제연맹(1920)**: 미국 불참, 소련과 독일은 처음에 제외, 군사 제재 수단 없음
- 1차 대전 이후 민주주의 확산: 보통선거, 노동자 정치 참여, **복지국가 개념**

### 대공황과 뉴딜

- 검은 목요일(1929.10.24) → 세계 공황
- 루스벨트의 **뉴딜**: 1단계(1933~35) 구제와 회복(농업조정법, 국가산업부흥법), 2단계(1935~39) 개혁(와그너법의 단결권·단체교섭권, 사회보장법, 공정노동기준법)
- 의미: **자유방임주의에서 벗어나** 정부가 공공복지를 지향

### 전체주의

| | 이탈리아 파시즘 | 독일 나치즘 |
| --- | --- | --- |
| 배경 | 전승국이지만 영토 요구(피우메) 좌절, 인플레이션과 실업 | 영토 상실과 배상금, 바이마르 의회민주주의의 취약성, 대공황 |
| 전개 | 무솔리니의 파시스트당(1919) → 로마 진군(1922.10) → 일당독재 | 히틀러와 나치스 |
| 이념 | 국가 지상주의, "팽창하지 않는 국가는 쇠퇴한다" | 민족주의와 반공주의 |

## 최종 핵심 정리

1. 절대주의는 왕권신수설, 관료제와 상비군, 중상주의를 갖춘 왕조 국가였다
2. 영국은 청교도혁명과 명예혁명을 거쳐 권리장전으로 의회 우위의 입헌정치를 세웠다
3. 미국혁명은 7년 전쟁 이후 영국의 과세에 대한 저항에서 시작해 3권분립 공화국을 만들었다
4. 프랑스 혁명은 입헌군주제, 공화정과 공포정치, 테르미도르 반동을 거쳐 국민주권을 확립했다
5. 빈 체제는 정통주의로 자유주의를 억눌렀지만 1830년과 1848년 혁명으로 무너졌다
