## 1. 추정 (6장)

### 점추정

- **불편성**: $$E[\hat{\theta}] = \theta$$. 예: $$E[\bar{X}] = \mu$$, $$E[S^2] = \sigma^2$$
- **효율성**: 불편추정량 중 분산이 작을수록 좋다
- **일치성**: $$n \to \infty$$일 때 $$\hat{\theta} \to \theta$$ (대수의 법칙)

### 구간추정

모분산 $$\sigma^2$$을 알 때, $$\mu$$의 $$100(1-\alpha)\%$$ 신뢰구간:

$$\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\; \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)$$

$$z_{\alpha/2}\,\sigma/\sqrt{n}$$을 **오차한계**라고 한다.

**예제**: 50ml로 표기된 화장품 25개의 평균이 49.05ml, $$\sigma = 2.21$$일 때

$$49.05 \pm 1.96 \times \frac{2.21}{\sqrt{25}} = (48.18,\; 49.92)$$

신뢰구간이 50을 포함하지 않으므로, 평균 용량이 50ml라고 보기 어렵다.

> **(중요!!)** 95% 신뢰구간은 "모평균이 이 구간에 있을 확률이 95%"가 아니다. 모평균은 고정된 값이고, **같은 방법으로 신뢰구간을 100번 만들면 약 95개가 모평균을 포함한다**는 뜻이다.

## 2. 가설검정

| 용어 | 뜻 |
| --- | --- |
| 귀무가설 $$H_0$$ | 기존 주장, "차이가 없다" |
| 대립가설 $$H_1$$ | 입증하고 싶은 주장 |
| 검정통계량 | $$H_0$$이 참일 때 분포를 아는 통계량. 예: $$Z = \dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$$ |
| 기각역 | $$H_0$$을 기각하는 검정통계량의 범위 |
| 유의수준 $$\alpha$$ | 제1종 오류 확률의 상한 |
| p-값 | $$H_0$$이 참일 때 관측값만큼 또는 더 극단적인 값이 나올 확률 |

| | $$H_0$$ 참 | $$H_0$$ 거짓 |
| --- | --- | --- |
| $$H_0$$ 기각 | **제1종 오류** ($$\alpha$$) | 옳은 결정 (검정력 $$1-\beta$$) |
| $$H_0$$ 채택 | 옳은 결정 | **제2종 오류** ($$\beta$$) |

$$\text{p-값} \le \alpha \;\Rightarrow\; H_0 \text{ 기각}$$

양측검정이면 기각역이 $$\lvert Z \rvert \ge z_{\alpha/2}$$, 단측이면 $$Z \ge z_\alpha$$ 또는 $$Z \le -z_\alpha$$다. 신뢰구간은 $$H_0$$이 채택되는 구간과 같으므로 단측검정에는 단측 신뢰구간이 대응한다.

> **$$H_0$$을 기각하지 못했다고 $$H_0$$이 참이라고 증명된 것은 아니다.** 증거가 부족하다는 뜻일 뿐이다. 그래서 결론은 "차이가 있다고 할 수 없다"로 쓴다.

## 3. 검정력과 표본크기

$$H_0: \mu \le 48$$ vs $$H_1: \mu > 48$$, $$\sigma = 6$$, $$\alpha = 0.05$$일 때 대립가설 아래의 평균을 $$\mu_1$$이라 하면

$$\gamma(\mu_1) = P\left(Z \ge \frac{\mu_0 - \mu_1}{\sigma/\sqrt{n}} + z_\alpha\right)$$

- $$n$$이 고정이면 $$\mu_1 - \mu_0$$이 클수록 검정력이 커진다
- $$\mu_1$$이 고정이면 $$n$$이 클수록 검정력이 커진다

$$\mu_1 = 51$$에서 검정력 0.8 이상이 되는 $$n$$은

$$n \ge \left(\frac{(z_\alpha + z_\beta)\sigma}{\mu_1 - \mu_0}\right)^2 = \left(\frac{(1.645 + 0.842) \times 6}{3}\right)^2 \approx 24.7 \;\Rightarrow\; n = 25$$

```python
from scipy import stats
za, zb = stats.norm.ppf(0.95), stats.norm.ppf(0.80)
print(((za + zb) * 6 / 3) ** 2)                               # 24.73
print(1 - stats.norm.cdf((48 - 51) / (6 / 25 ** 0.5) + za))  # n=25일 때 검정력 0.804
```

## 4. 일표본 t-검정 (7장)

모분산을 모르면 $$\sigma$$ 대신 $$S$$를 쓰고, 정규모집단에서

$$T = \frac{\bar{X} - \mu_0}{S/\sqrt{n}} \sim t(n-1), \qquad \text{신뢰구간: } \bar{X} \pm t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}$$

### 정규성 검정과 비모수 대안

1. **Shapiro-Wilk 검정**($$H_0$$: 정규분포를 따른다)과 QQ-plot으로 정규성 확인
2. p-값 > $$\alpha$$ → t-검정 사용
3. p-값 $$\le \alpha$$이고 표본이 작으면 → **윌콕슨 부호순위 검정**(비모수)

교재 예제: `mtcars`의 6기통 차 7대 연비 `c(21.0, 21.0, 21.4, 18.1, 19.2, 17.8, 19.7)`의 Shapiro 검정은 W = 0.899, p = 0.325로 정규성을 기각하지 않는다.

### 일표본 분산 추론

$$\frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$$

## 5. 이표본 평균 비교 (8장)

| 상황 | 방법 | 검정통계량 / 비고 |
| --- | --- | --- |
| 독립, 등분산 | **등분산 t-검정** | $$T = \dfrac{\bar{X}-\bar{Y}}{S_p\sqrt{1/n_1 + 1/n_2}} \sim t(n_1+n_2-2)$$ |
| 등분산 확인 | **F-검정** | $$F = S_1^2/S_2^2 \sim F(n_1-1, n_2-1)$$ |
| 독립, 이분산 | **Welch t-검정** | 자유도를 근사 (R `t.test`의 기본값) |
| 정규성 X, 소표본 | **윌콕슨 순위합 검정** (Mann-Whitney) | 비모수 |
| 같은 대상을 두 번 측정 | **쌍체 t-검정** | $$d_i = A_i - B_i$$로 일표본 t-검정 |

합동분산:

$$S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1+n_2-2}$$

### 쌍체 비교

간호사 A와 B가 같은 환자 12명의 심장 신호를 쟀다. 사람마다 차이가 크므로 **차이 $$d_i$$** 로 분석해 개인 효과를 없앤다. 약효 비교라면 잔여효과(carryover)를 막기 위해 투약 순서를 랜덤하게 정한다.

```python
from scipy import stats
A = [4.8, 5.6, 6.0, 6.4, 6.5, 6.6, 6.8, 7.0, 7.0, 7.2, 7.4, 7.6]
B = [5.8, 6.1, 7.7, 7.8, 7.6, 8.1, 8.0, 8.1, 6.6, 8.1, 9.5, 9.6]
print(stats.ttest_rel(A, B))   # t = -6.024, df = 11, p = 8.63e-05
```

평균 차이 -1.175, p < 0.05이므로 두 간호사의 측정이 같다고 보기 어렵다. R 실습 보고서는 기존 글 "04. One sample t-test report"와 "05. Two samples t-test report"에 있다.

## 최종 핵심 정리

1. 좋은 추정량은 불편성, 효율성, 일치성을 가진다
2. 신뢰구간은 같은 방법을 반복했을 때 모수를 포함하는 비율이 1-α라는 뜻이다
3. p-값이 유의수준 이하이면 귀무가설을 기각하며, 기각하지 못한 것은 귀무가설의 증명이 아니다
4. 제1종 오류는 α, 제2종 오류는 β이고, 검정력 1-β는 표본크기와 효과 크기가 클수록 커진다
5. 검정력 0.8, α=0.05, 효과 3, σ=6인 단측검정에는 표본 25개가 필요하다
6. 모분산을 모르면 t분포를 쓰고, 정규성이 의심되는 소표본에는 윌콕슨 검정을 쓴다
7. 이표본 비교는 F-검정으로 등분산을 확인한 뒤 등분산 t 또는 Welch t를 고른다
8. 같은 대상을 두 번 측정한 자료는 차이를 구해 일표본 문제로 바꾸는 쌍체 t-검정을 쓴다
