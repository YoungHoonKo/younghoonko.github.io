## 1. 게르만족과 프랑크 왕국 (7장)

### 게르만 사회

- 귀족, 자유민, 해방민, 노예로 구성. 중앙정부 없이 전쟁이 사회를 규정
- **종사제(comitatus)**: 친족을 넘어선 전사와 주군의 계약관계 → 중세 **주종제의 이념**으로 이어짐
- 신명재판(시죄법)과 선서로 판결. 개인의 자유와 최소한의 정부라는 전통

### 대이동 (375년~)

- 원인: 훈족의 이동, 인구 증가와 토지 부족, 로마 문화에 대한 동경, 로마의 쇠퇴
- 서고트(알라릭), 반달(가이세릭), 동고트(테오도릭), **프랑크(클로비스)**

### 프랑크 왕국이 살아남은 이유

1. 단거리 이동으로 본거지를 유지
2. 다른 부족과 달리 **아리우스파가 아닌 가톨릭으로 개종**
3. 안전한 지리적 위치

| 인물 | 교회와의 관계 |
| --- | --- |
| 클로비스 | 메로빙 왕조, 가톨릭과 공식 결합 |
| 카를 마르텔 | 이슬람 침입 격퇴(투르-푸아티에), 교회와 제휴 진전 |
| 피핀 3세 | 카롤링 왕조, 교황에게 영토 기증 |
| 카를 대제 | 800년 서로마 황제 대관 → 기독교를 매개로 한 유럽 질서 완성. 동서교회 분열과 교권·제권 분쟁의 씨앗 |

- **카롤링 르네상스**: 알퀸 등 학자 초빙, 궁정학교와 수도원 지원. 창조적 업적은 약했지만 고전학 부활의 기반

## 2. 봉건제 (8장)

- 봉건제(feudalism)는 근대 역사가가 만든 모호한 용어. 어원은 군사적 봉사의 대가로 받는 **봉토(feudum)**
- 배경: 프랑크 왕국의 분열(**베르됭 조약 843, 메르센 조약 870** → 이탈리아·프랑스·독일의 기틀)과 이슬람·마자르·바이킹의 침입
- 체계적으로 설계된 제도가 아니라 **각 지역에서 자생적으로** 생긴 안전보장 체제

| | 주종제 (Vassalage) | 장원제 (Manorial System) |
| --- | --- | --- |
| 관계 | 주군과 봉신 (지배층끼리) | 영주와 농노 |
| 매개 | 봉토 | 장원의 토지 |
| 기원 | 게르만 종사제 + 로마 피보호제 + 카롤링 베네피키움 | 로마 말기 콜로누스, 몰락한 게르만 자유민 |
| 성격 | **쌍무적 계약**. 봉신은 여러 주군을 섬길 수 있음 | 인신적 지배·예속. 부역과 현물지대 |

> 농노는 노예가 아니다. 가족을 이루고, 관습에 따라 **토지 보유권과 상속권**을 보장받았으며 공동체에서 발언권이 있었다.

## 3. 교회 세력의 신장과 서임권 투쟁 (9장)

- 신장 배경: 로마 행정을 대신한 교회(레오 1세, 그레고리우스 1세), 이교도 개종, 토지 기증으로 대토지 소유
- 타락: 성직자 결혼과 성직 상속, **성직매매(simony)**, 귀족이 좌우하는 교황 선출, 평신도(영주)의 교회 지배
- 개혁: **클뤼니 수도원**(10세기 초) → 개혁 교황들(레오 9세의 추기경단, 니콜라스 2세의 교황 선출 개혁) → **그레고리우스 7세**

### 서임권 투쟁

```text
밀라노 주교 선출 문제: 그레고리우스 7세 vs 하인리히 4세
 → 교황의 황제 파문 → 카노사의 굴욕 (1077)
 → 내란, 황제의 반격, 교황의 망명과 사망
 → 보름스 협약 (1122): 하인리히 5세 vs 칼릭스투스 2세
```

- 보름스 협약: 국왕은 주교 서임권(반지와 지팡이)을 포기하지만, 주교는 국왕의 봉신이 된다
- 결과: 프랑크 이래의 **속권 우월 전통이 사라졌지만 교권 우월이 확립된 것도 아니다** → 중세는 교권과 속권이 견제하고 제휴하는 사회

## 4. 십자군과 중세 도시 (10장)

### 십자군 (1096~1270/72)

- 원인: 셀주크 튀르크의 예루살렘 점령, 비잔티움 황제 알렉시우스 콤네누스의 구원 요청(1095), 우르바누스 2세의 **클레르몽 공의회**
- 1차(1096): 예루살렘 탈환 / 3차: 사자심왕 리처드와 살라딘의 화평 / 4차(1204): 베네치아 상인과 기사들이 **콘스탄티노폴리스를 공격**해 라틴 제국 수립
- 1291년 아크레 함락으로 실패. 이유: 통일된 지휘체계 없음, 장기화, 정치·경제적 동기 우선

| 영향 | 내용 |
| --- | --- |
| 교황 | 권위 쇠퇴 |
| 봉건 영주 | 몰락 → 왕권 강화 |
| 도시와 상업 | 동방무역 활성화, 장원제 붕괴, 자본가 등장 |

### 중세 도시와 대학

- 농업기술 혁신과 인구 증가 → 상업 부활 → 영주의 성곽 주변에 도시 형성
- 특허장으로 **자치권** 획득. 이때의 자유는 개인이 아닌 **집단적 자유**
- 길드: 상인 길드 → 수공업자 길드. 처음엔 상호부조였지만 점차 **배타적 단체**가 되어 자유경쟁을 억제
- 도시 동맹: 롬바르디아 동맹, **한자 동맹**
- 대학(12세기 말~13세기 초): 볼로냐, 파리, 살라망카. **universitas**는 공통 목적의 집단, 즉 길드라는 뜻

## 5. 14세기의 위기 (11장)

| 사건 | 내용 |
| --- | --- |
| 흑사병 (1347~1351) | 유럽 인구의 약 1/3 감소. 이미 있던 사회 문제를 첨예화 |
| 백년전쟁 (1337~1453) | 프랑스 내 영국령, 플랑드르 모직물, 왕위 계승 문제. 봉건적 전쟁에서 **민족국가 간 전쟁**으로 변모. 잔 다르크 |
| 장원제 붕괴 | 인구 감소 → 임금 상승 → 영주의 부역 강화(동유럽은 성공: 재판 농노제) → 서유럽은 부역 금납화, 화폐지대 |
| 도시 봉기 | 플랑드르 봉기, 피렌체 치옴피 봉기(1378) |
| 초기 자본주의 | 메디치·푸거 가문, **선대제(putting-out system)**, 복식부기 |

### 교회의 쇠퇴

- **아나니 사건**(1303, 보니파키우스 8세 vs 필리프 4세) → **아비뇽 유수**(1309~1376) → **대분열**(1378~1417, 콘스탄츠 공의회로 수습)
- 위클리프(영국): 교회의 부 비판, 면벌부 반대 / 후스(보헤미아): 성경 중심 신앙
- 영국: 존 왕의 **대헌장**(1215), 에드워드 1세의 모범의회 → 입헌정치의 기초. 프랑스: 필리프 2세, 루이 9세, 필리프 4세로 왕권 강화

## 6. 르네상스 (12장)

- 부르크하르트 『이탈리아의 르네상스 문화』: 그리스·로마 고전의 부흥과 **인간 중심주의**, 중세의 황혼이자 근대의 여명
- 이탈리아에서 시작한 이유: 고전 문화가 직접적인 유산, 지리적 위치, 도시의 경제적 번영

| | 이탈리아 르네상스 | 북부 유럽 르네상스 |
| --- | --- | --- |
| 성격 | 도시적, 세속적, 귀족적 | 종교적, 사회 비판적 |
| 대표 | 단테, 페트라르카(최초의 인문주의자), 보카치오 / 레오나르도, 미켈란젤로, 라파엘로 | 에라스뮈스 『우신예찬』, 토머스 모어 『유토피아』 / 반에이크, 뒤러, 브뤼헐 |
| 사상 | 인문주의(고전 교양 교육) | **기독교적 인문주의**(원시 기독교로의 복귀) |

## 7. 대항해시대 (13장)

- 동기: 르네상스의 진취적 세계관, 콘스탄티노폴리스 함락(1453)으로 동방무역 위축, 사제왕 요한 전설, 『동방견문록』
- 조건: 나침반과 조선술, 토스카넬리의 지구 구형설, **중앙집권 국가의 자금 지원**

| 국가 | 인물과 사건 |
| --- | --- |
| 포르투갈 | 엔히크 왕자 → 디아스 희망봉(1488) → 바스쿠 다가마 인도 캘리컷(1498) → 카브랄 브라질(1500) |
| 에스파냐 | 콜럼버스(1492) → 발보아 태평양 → 마젤란 선단 세계 일주(1519~1522) → 코르테스(아스테카), 피사로(잉카) |

- 결과: **가격혁명**(포토시 은 유입 → 인플레이션, 실질임금 하락), **상업혁명**(동인도회사, 주식회사), 무역 중심이 지중해에서 대서양으로 이동, 대서양 노예무역, 유럽 주도의 세계사 성립

## 8. 종교개혁 (14장)

### 배경

- 종교: 아비뇽 유수와 대분열로 권위 하락, 면벌부 판매(테첼, 푸거 가문)
- 정치: 민족의식 성장, 교황을 외국 세력으로 간주
- 경제: 교회의 막대한 토지와 십일조

### 세 갈래의 프로테스탄트

| | 루터 | 칼뱅 | 영국국교회 |
| --- | --- | --- | --- |
| 계기 | 95개조 반박문 (1517) | 제네바 망명, 『기독교 강요』(1536) | 헨리 8세의 이혼 문제 |
| 핵심 교리 | **신앙과 은총으로만 구원(의인설)**, 성경 중심, 만인사제설 | **예정설**: 직업 활동과 금욕적 생활로 은총을 증명 | 수장령(1534), 통일령(1559), 39개조(1571) |
| 결과 | 아우크스부르크 화의(1555): 영주가 신앙을 정함 | 위그노, 장로파, 청교도, 고이센 | 교리는 프로테스탄트, 의식은 가톨릭 |

- 루터는 농민 봉기의 진압을 촉구했고, 주로 제후와 자유도시의 지지를 받았다
- 칼뱅의 교리는 **근대적 직업관과 생활윤리** 형성에 기여 (베버의 프로테스탄트 윤리론과 연결)

### 가톨릭 종교개혁

- 종교재판소(1542), **트리엔트 공의회**(1545~1563, 교리 재확인과 면벌부 판매 금지), **예수회**(1540, 로욜라)
- 영향: 위그노 전쟁, 네덜란드 독립전쟁, 30년 전쟁 → 기독교 세계의 통일이 깨지고 **세속 군주 중심의 개별 국가**가 등장

## 최종 핵심 정리

1. 프랑크 왕국은 가톨릭으로 개종해 교회와 제휴했고, 카를 대제의 대관으로 기독교 유럽 질서가 완성되었다
2. 봉건제는 지배층 간의 쌍무적 주종제와 영주·농노 간의 장원제라는 두 축으로 이루어진다
3. 보름스 협약 이후 중세는 교권도 속권도 일방적으로 우월하지 않은, 서로 견제하는 사회가 되었다
4. 십자군은 실패했지만 교황권과 봉건 영주를 약화시키고 도시와 상업을 발달시켰다
