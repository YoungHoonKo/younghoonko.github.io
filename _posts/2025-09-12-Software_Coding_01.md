## 1. 프로그램과 프로그래밍

| 용어 | 뜻 |
| --- | --- |
| 프로그램 | 컴퓨터가 수행할 작업을 미리 작성해 둔 **명령어의 집합** |
| 프로그래밍 | 사람이 컴퓨터에게 무엇을 어떻게 할지 지시하는 **과정** |
| 소스 코드 | 프로그래밍 언어로 작성한 텍스트 |
| 알고리즘 | 문제를 해결하는 방법과 절차 |
| IDE | Integrated Development Environment, 편집·실행·디버깅을 한곳에서 하는 도구 (VS Code 등) |

흐름: **알고리즘 → 소스 코드 → 기계가 실행할 수 있는 형태로 번역 → 실행**

### 파이썬과 인터프리터

- 1991년 귀도 반 로섬이 발표
- 파이썬 코드는 **인터프리터**가 실행한다. C처럼 미리 전체를 실행 파일로 컴파일해 두지 않고, 실행할 때 번역한다
- 정확히는 CPython이 소스 코드를 먼저 **바이트코드**(.pyc)로 바꾸고, 가상 머신이 그 바이트코드를 한 줄씩 해석해 실행한다

## 2. 키워드, 주석, 함수

### 키워드

소스 코드에서 특별한 의미를 가진 예약어. **변수명·함수명으로 쓸 수 없다.** 예: `if`, `for`, `while`, `def`, `class`, `return`, `True`

```python
import keyword
print(len(keyword.kwlist))   # 이 버전의 키워드 개수
```

실행 결과(파이썬 3.13)

```text
35
```

### 주석 (시험에 나옴)

- `#` 뒤의 내용은 실행에 영향을 주지 않는다. 코드를 설명하거나 메모할 때 쓴다
- 코드 위·아래 줄에 써도 되고, 코드와 같은 줄에 쓸 때는 **코드의 오른쪽**에 쓴다. `#`부터 줄 끝까지가 주석이라 왼쪽에 쓰면 코드까지 주석이 된다

```python
# 이 줄 전체가 주석
print("hello")   # 코드 오른쪽 주석
```

### 함수

특정 기능을 하는 코드 묶음에 이름을 붙여, 필요할 때 **호출해서 재사용**하는 단위. `print`, `input`, `int`도 함수다. 자주 쓰는 기능을 부품처럼 모듈화한다.

### 들여쓰기

파이썬은 들여쓰기로 코드 블록을 구분한다. 줄을 강제로 맞춰야 하고, 어긋나면 `IndentationError`가 난다.

## 3. 데이터 단위

| 단위 | 크기 | 2의 거듭제곱 |
| --- | --- | --- |
| 1 Byte | 8 bit | 2^0 B |
| 1 KB | 1,024 B | 2^10 B |
| 1 MB | 1,024 KB = 1,048,576 B | 2^20 B |
| 1 GB | 1,024 MB | 2^30 B |
| 1 TB | 1,024 GB | 2^40 B |
| 1 PB | 1,024 TB | 2^50 B |
| 1 EB | 1,024 PB | 2^60 B |
| 1 ZB | 1,024 EB | 2^70 B |
| 1 YB | 1,024 ZB | 2^80 B |

- 엄밀히 1,024 단위는 KiB, MiB처럼 쓰는 이진 접두사이고, 저장 장치 제조사는 1,000 단위를 쓴다. 그래서 "1TB" 디스크가 운영체제에서 약 931GB로 보인다

## 4. print의 여러 출력 방식 (2주차 실습)

```python
print("Great Python", "hello")
print(1 + 2 + 3)
print(3.14 * 5 ** 2)
print(1, 2, 3, '#apple', 5, 'banana')    # 숫자와 문자 섞어서
print(1, 2, 3, sep=', ')                 # sep = separator

pay = 10000
print("Hourly wage is %d won" % pay)             # C 스타일
print("Hourly wage is", pay, "won")              # 쉼표
print(f"Hourly wage is {pay} won")               # f-string
print("Hourly wage is {} won".format(pay))       # format
```

실행 결과

```text
Great Python hello
6
78.5
1 2 3 #apple 5 banana
1, 2, 3
Hourly wage is 10000 won
Hourly wage is 10000 won
Hourly wage is 10000 won
Hourly wage is 10000 won
```

- 쉼표로 나열하면 사이에 **공백 하나**가 자동으로 들어간다. `sep`으로 바꿀 수 있다
- 문자열 안의 `#apple`은 따옴표 안이라 주석이 아니다
- `5 ** 2`는 거듭제곱이 곱셈보다 먼저라 3.14 × 25 = 78.5

## 최종 핵심 정리

1. 프로그램은 명령어의 집합, 프로그래밍은 그것을 만드는 과정, 소스 코드는 그 결과 텍스트다
2. 알고리즘(해결 절차) → 소스 코드 → 번역 → 실행 순서로 프로그램이 동작한다
3. 파이썬은 1991년 귀도 반 로섬이 만든 인터프리터 언어이고, CPython은 바이트코드로 바꿔 실행한다
4. 키워드는 변수·함수 이름으로 쓸 수 없다(파이썬 3.13 기준 35개)
5. 주석은 `#`부터 줄 끝까지이며, 코드와 같은 줄에 쓸 때는 코드 오른쪽에 둔다
6. 함수는 이름 붙인 코드 묶음으로, 호출해서 재사용한다
7. 1KB = 1,024B 등 이진 단위는 2의 10제곱씩 커진다
8. `print`는 쉼표(공백 구분), `%`, `format`, f-string 네 방식 모두 같은 결과를 낼 수 있다
