## 1. 확률 (4장)

### 확률의 공리

1. 모든 사건 $$A$$에 대해 $$P(A) \ge 0$$
2. 표본공간 전체의 확률은 $$P(S) = 1$$
3. 서로 배반인 $$A_1, A_2, \dots$$에 대해 $$P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots$$

여기서 덧셈 규칙 $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$와 여사건 $$P(A^c) = 1 - P(A)$$가 나온다.

### 조건부 확률과 독립

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \qquad P(A \cap B) = P(B)\,P(A \mid B) \;(\text{곱의 규칙})$$

$$A, B \text{ 독립} \iff P(A \cap B) = P(A)P(B) \iff P(A \mid B) = P(A)$$

> **(중요!!)** 배반과 독립은 다르다. 확률이 0이 아닌 두 사건이 배반이면 $$P(A \cap B) = 0 \ne P(A)P(B)$$이므로 **오히려 독립이 아니다.** 한쪽이 일어나면 다른 쪽은 절대 안 일어난다는 정보를 주기 때문이다.
{: .prompt-danger }

### 전확률 공식과 베이즈 정리

표본공간이 배반사건 $$B_1, \dots, B_k$$로 나뉠 때

$$P(A) = \sum_{j=1}^{k} P(B_j)P(A \mid B_j), \qquad P(B_i \mid A) = \frac{P(B_i)P(A \mid B_i)}{\sum_{j} P(B_j)P(A \mid B_j)}$$

$$P(B_i)$$는 **사전확률**, $$P(B_i \mid A)$$는 결과 $$A$$를 본 뒤의 **사후확률**이다.

### 예제: 이진 채널

보내는 신호의 30%가 0, 70%가 1이고, 제대로 받을 확률이 99%일 때, **0을 받았다면 원래 0이었을 확률**은?

$$P(S_0 \mid R_0) = \frac{(0.3)(0.99)}{(0.3)(0.99) + (0.7)(0.01)} = \frac{0.297}{0.304} \approx 0.977$$

```python
p = 0.3 * 0.99 / (0.3 * 0.99 + 0.7 * 0.01)
print(p)   # 0.9769736842105263
```

1을 보냈는데 0으로 잘못 받는 경우(0.7 × 0.01 = 0.007)가 분모에 들어가서 99%보다 조금 낮아진다. 사전확률이 작은 쪽일수록 이 효과가 커진다 (희귀병 검사의 양성 예측도가 낮은 이유).

## 2. 확률변수와 기댓값

| | 이산형 | 연속형 |
| --- | --- | --- |
| 확률함수 | 확률질량함수 $$p(x) = P(X=x)$$ | 확률밀도함수 $$f(x)$$, $$P(a \le X \le b) = \int_a^b f(x)dx$$ |
| 평균 | $$\mu = \sum x\,p(x)$$ | $$\mu = \int x f(x) dx$$ |
| 분산 | $$\sigma^2 = \sum (x-\mu)^2 p(x)$$ | $$\sigma^2 = \int (x-\mu)^2 f(x) dx$$ |

자주 쓰는 성질:

$$E[aX+b] = aE[X]+b, \qquad Var(aX+b) = a^2 Var(X), \qquad Var(X) = E[X^2] - (E[X])^2$$

$$Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y), \qquad \rho = \frac{Cov(X,Y)}{\sigma_X \sigma_Y}$$

$$X$$와 $$Y$$가 독립이면 $$Cov(X,Y)=0$$이지만, **공분산이 0이라고 독립인 것은 아니다.**

## 3. 이산 분포 (5장)

| 분포 | 상황 | 확률함수 | 평균 | 분산 |
| --- | --- | --- | --- | --- |
| 베르누이 $$B(1,p)$$ | 성공/실패 1회 | $$p^x(1-p)^{1-x}$$ | $$p$$ | $$p(1-p)$$ |
| 이항 $$B(n,p)$$ | 독립 베르누이 $$n$$회 중 성공 수 | $$\binom{n}{x}p^x(1-p)^{n-x}$$ | $$np$$ | $$np(1-p)$$ |

이항분포는 베르누이 확률변수 $$n$$개의 합이므로, 평균과 분산도 각각 $$n$$배가 된다.

R 함수 이름 규칙: `d`(확률·밀도), `p`(누적확률), `q`(분위수), `r`(난수) + 분포 이름. 예: `dbinom`, `pnorm`, `qt`, `rchisq`.

## 4. 연속 분포

### 정규분포

$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \qquad Z = \frac{X-\mu}{\sigma} \sim N(0,1)$$

- 평균을 중심으로 대칭, 평균 = 중앙값 = 최빈값
- 68-95-99.7 규칙: $$\mu \pm 1\sigma, 2\sigma, 3\sigma$$ 안에 각각 약 68%, 95%, 99.7%
- 양측 5%의 경계는 $$z_{0.025} = 1.96$$

### 정규분포에서 나오는 분포

| 분포 | 정의 | 쓰임 |
| --- | --- | --- |
| 카이제곱 $$\chi^2(k)$$ | $$Z_1^2 + \cdots + Z_k^2$$ | 분산 추론, 적합도·독립성 검정 |
| $$t(k)$$ | $$\dfrac{Z}{\sqrt{V/k}}$$, $$V \sim \chi^2(k)$$ | 모분산을 모를 때 평균 추론 |
| $$F(k_1,k_2)$$ | $$\dfrac{V_1/k_1}{V_2/k_2}$$ | 두 분산의 비, 분산분석, 회귀 적합도 |

$$t$$분포는 정규분포보다 꼬리가 두껍고, 자유도가 커질수록 표준정규분포에 가까워진다.

## 5. 표본분포와 중심극한정리

$$X_1, \dots, X_n$$이 평균 $$\mu$$, 분산 $$\sigma^2$$인 분포에서 독립으로 뽑은 표본이면

$$E[\bar{X}] = \mu, \qquad Var(\bar{X}) = \frac{\sigma^2}{n}, \qquad SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}$$

정규모집단이면 다음도 정확히 성립한다.

$$\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1), \qquad \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

> **중심극한정리(CLT)**: 모집단이 어떤 분포든, $$n$$이 충분히 크면 $$\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}$$은 근사적으로 $$N(0,1)$$을 따른다.
{: .prompt-info }

- 그래서 모집단 분포를 몰라도 평균에 대한 추론이 가능하다
- 이항분포도 베르누이의 합이므로 $$n$$이 크면 정규근사가 된다 (보통 $$np > 5$$, $$n(1-p) > 5$$)
- R 시뮬레이션은 기존 실습 글 "03. Statistics(Central limit theorem)"에서 B(3, 1/6) 표본으로 n = 3, 10, 30을 비교했다
