## 1. 변수

**데이터를 담는 이름 붙은 그릇**이다. 값을 한 곳에서만 바꾸면 그 변수를 쓰는 모든 코드에 반영되므로 재사용성과 유지보수가 좋아진다.

```python
pay = 10500        # 시급
hour = 18.5
total = pay * hour
print(total)
```

실행 결과

```text
194250.0
```

- 정수 × 실수 = **실수**

### 이름 규칙

- 영문자, 숫자, **밑줄(_)** 만 사용 (한글도 되지만 권장하지 않음)
- 숫자로 시작할 수 없고, 공백·특수문자(`-`, `@`, `!` 등)는 안 됨
- 키워드는 사용 불가, 대소문자 구분
- 의미 있는 이름을 쓴다. 참/거짓을 담는 변수는 `is_adult`처럼 `is_`로 시작하면 읽기 좋다
- 변수는 쓰기 전에 값을 넣어(초기화) 둬야 한다. 아니면 `NameError`

## 2. 자료형과 형 변환

| 자료형 | 예 | 변환 함수 |
| --- | --- | --- |
| 정수 `int` | 10, −3 | `int()` |
| 실수 `float` | 3.14, 18.5 | `float()` |
| 문자열 `str` | 'Alex', "100" | `str()` |
| 불리언 `bool` | True, False | `bool()` |

파이썬은 **동적 타이핑**이다. 변수에 자료형을 선언하지 않고, 같은 변수에 다른 자료형 값을 다시 넣을 수 있다.

```python
var = '100'
print(var * 2)      # 문자열 반복
var = int(var)
print(var * 2)      # 정수 곱셈
var = float(var)
print(var * 2)
var = str(var)
print(var * 2)      # '100.0' 반복

samsung = '345.65'
samsung = str(int(float(samsung)))
print(samsung * 3)
```

실행 결과

```text
100100
200
200.0
100.0100.0
345345345
```

- `int('345.65')`는 `ValueError`가 난다. 소수점이 있는 문자열은 `float`로 먼저 바꾼 뒤 `int`로 바꿔야 한다

### int()는 버림, round()는 반올림

> **(중요!!)** 실수를 정수로 바꾸면 소수점 이하는 **무조건 버린다** (시험 출제: 5827 × 0.03)
{: .prompt-warning }

```python
print(int(5827 * 0.03), 5827 * 0.03)
print(int(18.5), int(-18.5))
print(round(18.5), round(19.5))
```

실행 결과

```text
174 174.81
18 -18
18 20
```

- `int()`는 **0 쪽으로 자른다**(음수 −18.5 → −18)
- `round()`는 학교에서 배운 반올림과 다르다. 딱 .5일 때는 **짝수 쪽**으로 보낸다(은행가 반올림). 18.5 → 18, 19.5 → 20. 많은 값을 반올림할 때 한쪽으로 치우치지 않게 하려는 규칙이다
- `float`는 유효 숫자 약 15~16자리까지 정확하다

## 3. 서식 문자로 출력하기

| 서식 | 뜻 |
| --- | --- |
| `%d` | 정수 (실수를 넣으면 소수점 버림) |
| `%f` | 실수 (기본 소수점 6자리) |
| `%.1f` | 소수점 첫째 자리까지 |
| `%6.1f` | 전체 6칸, 소수점 첫째 자리, 남는 칸은 왼쪽 공백 |
| `%4d` | 전체 4칸 정수 |
| `%s` | 문자열 |
| `%%` | `%` 문자 자체 |

```python
humanCount = 205
finger = 18.5
totalFinger = humanCount * finger
print("Total Fingers = %f" % totalFinger)
print("Total Fingers = %d" % totalFinger)

print("%6.1f" % 3.14)
print("%5d-%5d-%5d" % (12345, 1234, 12345))
print("%5d" % 1234567)                 # 칸보다 길면 그대로 다 출력
print("%5.1f:%5.1f:%5.3f" % (1.23, 123.2, 12345.1234))
print("할인률은 %d%%입니다." % 5)
```

실행 결과

```text
Total Fingers = 3792.500000
Total Fingers = 3792
   3.1
12345- 1234-12345
1234567
  1.2:123.2:12345.123
할인률은 5%입니다.
```

### 시험 문제 유형

```python
print('%dwon, %.1fhour' % (1, 3.456))
print('%dwon, %.1fhour' % (100, 345.456))
print('%4dwon, %6.1fhour' % (1, 3.456))
print('%4dwon, %6.1fhour' % (100, 345.456))
```

실행 결과

```text
1won, 3.5hour
100won, 345.5hour
   1won,    3.5hour
 100won,  345.5hour
```

- 폭을 주면 숫자 길이가 달라도 **세로로 줄이 맞는다**

## 4. 제어 문자 (이스케이프 문자)

> **(중요!!)** 제어 문자 출력 결과 분석은 무조건 시험에 나온다
{: .prompt-warning }

| 문자 | 의미 |
| --- | --- |
| `\n` | 줄바꿈 |
| `\t` | 탭: **다음 탭 위치(보통 8칸 단위)** 까지 이동 |
| `\\` | 백슬래시 한 개 |
| `\'`, `\"` | 따옴표 |

```python
print("1\t, 12\t, 123\t, 1234")
print("123\n456")
print('1\t, 12\n123\t, 1234\n')
print('\'1\'\t, \'12\'\n\'123\'\t, \'1234\'\n')
print("hello\\it's me")
```

실행 결과

```text
1       , 12    , 123   , 1234
123
456
1       , 12
123     , 1234

'1'     , '12'
'123'   , '1234'

hello\it's me
```

- `\t`는 "공백 4개"가 아니다. 다음 8의 배수 칸으로 건너뛰므로 `1` 뒤에는 공백 7개, `123` 뒤에는 5개가 생긴다. 그래서 길이가 다른 값도 열이 맞는다
- 문자열 끝의 `\n` + `print`가 붙이는 줄바꿈 = **빈 줄 하나**
- 큰따옴표 문자열 안의 작은따옴표 `it's`는 이스케이프 없이 쓸 수 있다

## 5. input()

```python
count = input()                 # 항상 문자열로 받음
num = int(input())              # 정수로 쓰려면 변환
r = float(input())
print('r = %f, area = %f' % (r, 3.14 * r * r))
```

`input()`은 무엇을 입력하든 **문자열**을 돌려준다. 계산하려면 `int()`, `float()`로 바꿔야 한다.

## 6. 과제 2: 직사각형 넓이

> **과제 2**: 가로(Length)와 세로(Width)를 실수로 입력받아 넓이(Area)를 구하고, 세 값을 소수점 첫째 자리까지 차례대로 출력하라. 예) `Length = 10.0    Width = 5.0     Area = 50.0`
{: .prompt-info }

```python
length = float(input("Length = "))
width = float(input("Width = "))
area = length * width       # 실수 * 실수 = 실수

print("Length = %.1f\t Width = %.1f\t Area = %.1f" % (length, width, area))
```

실행 결과 (입력 10, 5)

```text
Length = 10
Width = 5
Length = 10.0	 Width = 5.0	 Area = 50.0
```

검토하면서 확인한 점

- 입력 10.25, 4를 넣으면 `Length = 10.2`가 나온다. 10.25는 2진수로 정확히 표현되는 "딱 절반" 값이라 `%.1f`도 짝수 쪽(10.2)으로 반올림한다. 출력은 반올림된 값이지만 넓이 계산(41.0)에는 원래 값이 쓰인다
- `\t` 뒤에 공백을 하나 더 넣어서 탭 위치에 따라 간격이 조금씩 달라질 수 있다. 예시처럼 정확한 간격이 필요하면 `%-12s` 같은 고정 폭 서식이 더 안정적이다

---

### 강의 자료 및 정리 노트에서 정정한 부분 정리

| 위치 | 원래 | 정정 | 이유 |
| --- | --- | --- | --- |
| 3주차 노트 | `\t` = 공백 4개 | 다음 탭 위치(8칸 단위)까지 이동 | 실행 결과의 공백 수가 7, 6, 5로 다름 |
| 중간 대비 노트 | 변수명에 "특수문자 사용 가능" | 밑줄(_)만 가능 | `my-var = 1`은 SyntaxError |
| 중간 대비 노트 | "반올림은 round" | `round`는 .5에서 짝수 쪽으로 | `round(18.5)` = 18 |
| 3주차 실습 주석 | `%d`에 실수를 넣으면 "반올림이 아닌 버림" | 맞음. 단, 음수도 0 쪽으로 자름 | `int(-18.5)` = −18 |

## 최종 핵심 정리

1. 변수는 데이터를 담는 이름이고, 이름에는 영문·숫자·밑줄만 쓰며 숫자로 시작할 수 없다
2. 자료형은 int, float, str, bool이고, 파이썬은 동적 타이핑이라 같은 변수에 다른 자료형을 넣을 수 있다
3. `int()`는 소수점 이하를 버리므로 `int(5827 * 0.03)` = 174, `int(18.5)` = 18
4. `round()`는 .5에서 짝수 쪽으로 반올림해 `round(18.5)` = 18, `round(19.5)` = 20
5. `%6.1f`는 전체 6칸·소수 첫째 자리, `%4d`는 4칸 정수, `%%`는 `%` 문자
6. `\t`는 다음 8칸 단위 위치로 이동하고, 끝의 `\n`과 print의 줄바꿈이 겹치면 빈 줄이 생긴다
7. `input()`은 항상 문자열을 돌려주므로 계산 전에 `int()`, `float()`로 변환한다
8. 과제 2는 넓이를 실수로 계산해 `%.1f`로 출력했고, 10.25처럼 딱 절반인 값은 10.2로 표시된다
