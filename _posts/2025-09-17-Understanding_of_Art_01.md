## 2. 형식(Form)과 내용(Content)

| 구분 | 뜻 | 하위 요소 |
| --- | --- | --- |
| 비주얼 폼 | 눈에 보이는 모습. 보자마자 느끼는 시각적 특징 | 조형 요소(formal elements), 구성(composition), 재료(material) |
| 콘텐츠 | 작품이 담은 의미, 주제, 메시지 | 주제(subject matter), 맥락, 상징 |

- 폼과 콘텐츠는 구분해서 말할 수 있어야 한다
- 둘 다 **아는 만큼 보인다.** 조형 요소의 이름과 효과를 알아야 폼을 설명할 수 있고, 시대·문화 맥락을 알아야 콘텐츠가 보인다

### 창작

- 과정: 주변을 **인식** → 그것에 **반응** → 인식과 반응의 결과를 **표현**
- 오늘날 창의성은 **혁신**(새로운 것)과 **자기표현**(작가 개인의 스타일)으로 본다. 무엇을 혁신이라 보는지는 시대·문화에 따라 달라진다
- 예: 아프리카의 가면극(마스커레이드)은 그 문화에서 예술이지만, 서양의 미술관 기준으로는 예술로 분류되지 않기도 했다

## 3. 비주얼 아트의 범주

| 범주 | 특징 |
| --- | --- |
| 순수 미술(Fine Art) | 서양에서 만든 범주. 감상을 위해 다듬어졌고 실용성이 없음. 미술관에서 가치를 인정받음. 보는 법을 알아야 감상하기 쉬움 |
| 대중 예술(Popular Culture) | 영화, 만화, 책 등. 싸고 접근성이 높고 상업적 |
| 공예(Craft) | 실용적. 이미지보다 **물건(오브젝트)** 을 만듦 |
| 팝아트 | 대중문화의 이미지(캠벨 수프 캔 등)를 순수 미술로 옮김. 순수 미술에 속함. 대표 작가 앤디 워홀 |

## 4. 스타일

스타일은 **예술적 표현의 방식(manner)** 이다. 같은 대상도 작가, 시대, 문명마다 표현하는 방식이 다르다. 스타일을 볼 때는 작품을 최대한 **객관적으로 묘사**하는 것이 출발점이다.

| 스타일 | 특징 | 예 |
| --- | --- | --- |
| 자연주의(Naturalistic) | 보자마자 무엇인지 알 수 있음. 명암, 그러데이션, 원근법 사용 | |
| 이상주의(Idealistic) | 특정 시대·문화의 이상에 맞춰 다듬음 | 고대 조각상 |
| 고전(Classical) | 정돈, 균형, 비례가 맞음 | 보티첼리, 「비너스의 탄생」 |
| 표현적(Expressive) | 격한 감정, 긴급함(urgency), 즉흥성(spontaneity). 두꺼운 물감과 질감 | 칸딘스키 |
| 초현실(Surreal) | 기이한 이미지와 재료를 섞어 익숙한 것을 낯설게 | 달리, 「기억의 지속」(1931) |
| 추상(Abstract) | 현실에서 출발해 왜곡·해부·확대 → 한눈에 알아볼 수 없음 | |

- 대문자 C의 Classical은 기원전 5세기 고대 그리스의 고전기를 말하고, 그 뒤 그것을 본받은 양식은 소문자 c로 쓴다
- **달리의 그림은 추상이 아니다.** 시계가 녹아내리는 기이한 장면이지만 대상이 무엇인지 한눈에 알아볼 수 있고 명암·원근이 사실적이라 표현 방식은 자연주의적이다(시험 함정)
- 하나의 작품이 여러 스타일을 함께 가질 수 있다. 보티첼리의 비너스는 고전적이면서 이상적이고, 신성을 상상하게 하는 기능도 한다
- 시험 유형: 그림을 보여 주고 그 스타일을 가장 잘 나타내는 예를 고르기 → **작품, 연도, 작가 이름을 외워 둘 것**

## 5. 비교 연습: 고흐와 고갱

같은 장소를 그린 두 사람의 그림을 놓고 공통점과 차이점을 말하는 연습을 했다.

| 구분 | 고흐 | 고갱 |
| --- | --- | --- |
| 화면 | 풍경 중심, 태양이 주인공, 사람 얼굴은 안 보임 | 인물 중심, 밝은 옷의 여인이 주인공 |
| 색 | 밝고 부드러운 느낌 | 보색 대비가 강함 |
| 선 | | 배경은 가로선, 인물과 술병은 세로선이 강조됨 |
| 화가 | 목사를 꿈꿨고 탄광 지역에서 살았으며, 보이는 대로 그려야 한다고 봄 | 은행원(증권 중개인)이었다가 그림에 전념, 상상하는 대로 그려야 한다고 봄 |

- 그림 속 파란 술병은 19세기에 유행한 술 **압생트**
- 비교할 때는 "좋다/나쁘다"가 아니라 **작가가 무엇을 선택했는지**(대상, 색, 선, 구도)를 말해야 한다

## 최종 핵심 정리

1. 예술은 의식, 관습, 신성, 추모, 찬양, 저항, 기록, 교육, 즐거움 등 여러 기능을 가지며 한 작품이 여러 기능을 함께 가질 수 있다
2. 모나리자는 기록(초상), 뱅크시 그래피티는 저항, 사탕 더미 작품은 추모, 천지창조는 신성의 상상
3. 비주얼 폼은 조형 요소·구성·재료, 콘텐츠는 의미·주제이고 둘은 구분해서 설명한다
4. 오늘날 창의성은 혁신과 자기표현이며, 무엇이 예술인지는 문화에 따라 다르다
5. 순수 미술은 감상용, 대중 예술은 상업적·접근성, 공예는 실용적 물건, 팝아트는 대중 이미지를 순수 미술로 옮긴 것
6. 스타일은 표현 방식이며 자연주의, 이상주의, 고전, 표현적, 초현실, 추상으로 나눈다
7. 달리의 초현실 회화는 알아볼 수 있으므로 추상이 아니다
8. 작품을 비교할 때는 작가의 선택(대상, 색, 선, 구도)을 객관적으로 묘사한다
