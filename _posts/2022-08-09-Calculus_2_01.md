## 1. 극좌표 (과제 1차)

$$x = r\cos\theta, \quad y = r\sin\theta, \qquad r^2 = x^2 + y^2, \quad \tan\theta = \frac{y}{x}$$

- 예: $$(r, \theta) = (2, \pi/3) \Rightarrow (x, y) = (1, \sqrt{3})$$
- 직교 → 극: $$(x,y) = (-1, 1)$$이면 $$r = \sqrt{2}$$, 2사분면이므로 $$\theta = 3\pi/4$$ (arctan만 쓰면 $$-\pi/4$$로 잘못 나옴)
- 극방정식 → 직교방정식: $$r = 2\cos\theta$$는 양변에 r을 곱해 $$x^2 + y^2 = 2x$$, 즉 중심 (1, 0), 반지름 1인 원

### 극곡선의 넓이와 길이

$$A = \frac{1}{2}\int_\alpha^\beta r^2\,d\theta, \qquad L = \int_\alpha^\beta \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$$

심장형 $$r = 1 + \cos\theta$$ $$(0 \le \theta \le 2\pi)$$: $$A = \dfrac{3\pi}{2}$$, $$L = 8$$.

> 극곡선 넓이는 $$\frac{1}{2}r^2 d\theta$$(부채꼴)를 더한 것이다. 곡선이 같은 영역을 두 번 그리는 구간(예: $$r = \cos 2\theta$$의 잎)을 넣으면 넓이가 두 배로 계산되므로 θ 범위를 먼저 확인한다.
{: .prompt-warning }

### 매개변수 곡선

$$x = f(t)$$, $$y = g(t)$$에서 t를 소거하면 직교방정식이 된다. 예: $$x = \cos t$$, $$y = \sin t$$ → $$x^2 + y^2 = 1$$.

$$L = \int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt$$

성망형 $$x = \cos^3 t$$, $$y = \sin^3 t$$의 전체 길이는 $$4\displaystyle\int_0^{\pi/2} 3\sin t\cos t\,dt = 6$$.

## 2. 이변수 함수와 편미분 (과제 1차)

### 극한

$$(x, y) \to (a, b)$$의 극한은 **모든 경로**에서 같은 값이어야 존재한다. 두 경로에서 값이 다르면 극한이 없다.

$$\lim_{(x,y)\to(0,0)}\frac{xy}{x^2 + y^2}: \quad y = 0 \text{이면 } 0, \quad y = x \text{이면 } \frac{1}{2} \;\Rightarrow\; \text{존재하지 않음}$$

### 편도함수

$$f_x(a,b) = \lim_{h \to 0}\frac{f(a+h, b) - f(a,b)}{h}$$

다른 변수를 상수로 보고 미분한다. **클레로 정리**: 이계 편도함수가 연속이면 $$f_{xy} = f_{yx}$$.

### 극값과 안장점

임계점 ($$f_x = f_y = 0$$)에서 판별식 $$D = f_{xx}f_{yy} - f_{xy}^2$$

| 조건 | 결과 |
| --- | --- |
| $$D > 0$$, $$f_{xx} > 0$$ | 극소 |
| $$D > 0$$, $$f_{xx} < 0$$ | 극대 |
| $$D < 0$$ | **안장점** (한 방향으로는 극대, 다른 방향으로는 극소) |
| $$D = 0$$ | 판정 불가 |

**예제**: $$f(x,y) = x^3 - 3x + y^2$$. $$f_x = 3x^2 - 3 = 0$$, $$f_y = 2y = 0$$이므로 임계점은 $$(\pm 1, 0)$$. $$D = (6x)(2) - 0 = 12x$$.

- $$(1, 0)$$: $$D = 12 > 0$$, $$f_{xx} = 6 > 0$$ → 극소 $$f = -2$$
- $$(-1, 0)$$: $$D = -12 < 0$$ → 안장점

## 3. 이중적분 (과제 2차)

### 반복적분

직사각형 영역에서는 **푸비니 정리**로 순서를 바꿔도 같다.

$$\iint_{[0,1]\times[0,2]}(x + 2y)\,dA = \int_0^1\int_0^2 (x + 2y)\,dy\,dx = \int_0^1 (2x + 4)\,dx = 5$$

### 적분 순서 바꾸기

안쪽 적분이 초등함수로 안 될 때 쓴다. 영역을 그려서 경계를 다시 읽는다.

$$\int_0^1\int_x^1 e^{y^2}\,dy\,dx = \int_0^1\int_0^y e^{y^2}\,dx\,dy = \int_0^1 ye^{y^2}\,dy = \frac{e - 1}{2}$$

$$e^{y^2}$$은 y로 바로 적분할 수 없지만, 순서를 바꾸면 x 적분이 먼저 되어 $$y$$가 곱해지고 치환이 가능해진다.

### 극좌표 이중적분

$$\iint_R f(x,y)\,dA = \int_\alpha^\beta\int_{r_1}^{r_2} f(r\cos\theta, r\sin\theta)\,r\,dr\,d\theta$$

$$\iint_{x^2+y^2\le 1} e^{-(x^2+y^2)}\,dA = \int_0^{2\pi}\int_0^1 e^{-r^2}r\,dr\,d\theta = \pi\left(1 - \frac{1}{e}\right)$$

> **(중요!!)** 극좌표로 바꿀 때 $$dA = r\,dr\,d\theta$$의 **r을 빠뜨리지 않는다.** 이 r이 없으면 위 적분은 치환도 안 된다.

## 4. 삼중적분과 좌표 변환 (과제 3차)

| 좌표계 | 변환 | 부피 요소 |
| --- | --- | --- |
| 직교 | $$(x, y, z)$$ | $$dx\,dy\,dz$$ |
| 원기둥 | $$x = r\cos\theta$$, $$y = r\sin\theta$$, $$z = z$$ | $$r\,dz\,dr\,d\theta$$ |
| 구면 | $$x = \rho\sin\phi\cos\theta$$, $$y = \rho\sin\phi\sin\theta$$, $$z = \rho\cos\phi$$ | $$\rho^2\sin\phi\,d\rho\,d\phi\,d\theta$$ |

- 구면좌표에서 $$\phi$$는 **z축과 이루는 각** ($$0 \le \phi \le \pi$$), $$\theta$$는 xy평면에서 x축과 이루는 각 ($$0 \le \theta \le 2\pi$$)
- 원기둥좌표는 $$x^2 + y^2$$이 들어간 영역(원기둥, 포물면), 구면좌표는 $$x^2 + y^2 + z^2$$이 들어간 영역(구, 원뿔)에 쓴다

**예제**: 반지름 a인 구의 부피

$$\int_0^{2\pi}\int_0^{\pi}\int_0^{a}\rho^2\sin\phi\,d\rho\,d\phi\,d\theta = 2\pi \cdot 2 \cdot \frac{a^3}{3} = \frac{4}{3}\pi a^3$$

일반적인 변수변환에서는 부피 요소에 **야코비안**의 절댓값 $$\left\lvert\dfrac{\partial(x,y,z)}{\partial(u,v,w)}\right\rvert$$을 곱한다. 원기둥의 r과 구면의 $$\rho^2\sin\phi$$가 바로 그 야코비안이다.

```python
import sympy as sp
x, y, r, th, rho, ph, a = sp.symbols('x y r theta rho phi a', positive=True)
print(sp.integrate(sp.integrate(x + 2*y, (y, 0, 2)), (x, 0, 1)))                 # 5
print(sp.integrate(y * sp.exp(y**2), (y, 0, 1)))                                # E/2 - 1/2
print(sp.integrate(sp.integrate(sp.exp(-r**2) * r, (r, 0, 1)), (th, 0, 2*sp.pi)))  # pi(1 - 1/e)
print(sp.integrate(rho**2 * sp.sin(ph), (rho, 0, a), (ph, 0, sp.pi), (th, 0, 2*sp.pi)))  # 4*pi*a**3/3
```

## 최종 핵심 정리

1. 직교 → 극좌표 변환에서 θ는 점이 있는 사분면을 확인해 정한다
2. 극곡선의 넓이는 ½∫r²dθ, 길이는 ∫√(r² + r'²)dθ다
3. 이변수 함수의 극한은 두 경로에서 값이 다르면 존재하지 않는다
4. 이계 편도함수가 연속이면 fxy = fyx (클레로 정리)
5. 판별식 D < 0인 임계점은 안장점이다
6. 안쪽 적분이 안 되면 영역을 다시 그려 적분 순서를 바꾼다
7. 극좌표 이중적분의 넓이 요소는 r dr dθ다
8. 원기둥좌표의 부피 요소는 r dz dr dθ, 구면좌표는 ρ² sinφ dρ dφ dθ다
