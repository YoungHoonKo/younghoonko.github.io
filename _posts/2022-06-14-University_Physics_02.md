## 1. 토크와 정적 평형 (12장)

$$\tau = rF\sin\phi = \vec{r} \times \vec{F}$$

$$\phi$$는 $$\vec{r}$$과 $$\vec{F}$$ 사이 각도다. 렌치 문제처럼 각도가 주어지면 **힘에 수직인 팔의 길이**가 어느 쪽인지 먼저 확인한다.

| 평형 | 조건 |
| --- | --- |
| 정적 평형 | 정지 상태 |
| 동적 평형 | 등속 운동 |
| 필요충분조건 | $$\sum \vec{F} = 0$$ **그리고** $$\sum \vec{\tau} = 0$$ (아무 점에 대해서나) |

> 토크의 기준점은 마음대로 골라도 된다. **모르는 힘이 작용하는 점**을 기준으로 잡으면 그 힘의 토크가 0이 되어 미지수가 줄어든다.

## 2. 만유인력 (13장)

| 인물 | 기여 |
| --- | --- |
| 코페르니쿠스 (1473~1543) | 지동설 |
| 티코 브라헤 (1546~1601) | 정밀한 행성 관측 |
| 케플러 (1571~1630) | 화성 궤도 분석 → 세 법칙 |
| 뉴턴 | 『자연철학의 수학적 원리』(1687), 만유인력 |
| 캐번디시 (1798) | 비틀림 저울로 G 측정 |

$$F = G\frac{m_1 m_2}{r^2}, \qquad G = 6.673 \times 10^{-11}\ \text{N·m}^2/\text{kg}^2$$

케플러 법칙: (1) 타원 궤도, (2) **면적 속도 일정**(각운동량 보존), (3) $$T^2 \propto a^3$$.

### 지구 밀도와 탈출속도

지표에서 $$mg = G\dfrac{M_E m}{R_E^2}$$이므로 $$M_E = \dfrac{gR_E^2}{G} \approx 5.98 \times 10^{24}\text{kg}$$.

$$\rho_E = \frac{M_E}{\frac{4}{3}\pi R_E^3} \approx 5.5 \times 10^3\ \text{kg/m}^3, \qquad v_{esc} = \sqrt{\frac{2GM_E}{R_E}} \approx 11.2\ \text{km/s}$$

지구 평균 밀도가 지각 암석(약 2.7×10³)의 두 배 정도이므로 **내부에 밀도가 큰 핵**이 있다는 것을 알 수 있다. 높이 h에서의 중력가속도는 $$g(h) = \dfrac{GM_E}{(R_E + h)^2}$$로 줄어든다.

## 3. 유체역학 (14장)

### 압력

$$P = \frac{F}{A}\ (\text{Pa} = \text{N/m}^2), \qquad P = P_0 + \rho g h$$

**예제**: 수심 5m의 물에 의한 압력은 $$\rho g h = 1000 \times 9.8 \times 5 = 4.9 \times 10^4\ \text{Pa}$$. 같은 깊이면 용기 모양과 관계없이 압력이 같다.

### 부력

$$B = \rho_{f} V_{sub} g$$

($$\rho_f$$: 유체 밀도, $$V_{sub}$$: 잠긴 부피) 아르키메데스 원리: 부력은 물체가 밀어낸 유체의 무게와 같다.

**예제**: 공기 중 7.84N, 물속 6.84N인 금속

$$B = 7.84 - 6.84 = 1.00\text{N}, \quad V = \frac{B}{\rho_w g} = 1.02 \times 10^{-4}\text{m}^3, \quad \rho = \frac{7.84}{gV} = 7.84 \times 10^3\ \text{kg/m}^3$$

밀도로 보아 철이다.

**예제**: 바닷물(1.03×10³)에 뜬 얼음(0.917×10³)은 $$\dfrac{V_{sub}}{V} = \dfrac{\rho_{ice}}{\rho_{sea}} = 0.890$$, 즉 **89%가 물에 잠기고 11%만 보인다.**

## 4. 진동 (15장)

용수철의 복원력 $$F = -kx$$에서

$$m\frac{d^2x}{dt^2} = -kx \;\Rightarrow\; x(t) = A\cos(\omega t + \phi), \qquad \omega = \sqrt{\frac{k}{m}}, \qquad T = \frac{2\pi}{\omega}$$

$$v_{max} = \omega A, \qquad a_{max} = \omega^2 A, \qquad E = \frac{1}{2}kA^2 = \frac{1}{2}mv^2 + \frac{1}{2}kx^2$$

> 주기는 **진폭과 무관**하다. 진폭을 키우면 더 멀리 가지만 그만큼 더 빨리 움직여서 한 번 왕복하는 시간은 같다.
{: .prompt-warning }

**예제 1**: $$k = 5.0\ \text{N/m}$$, $$m = 200\text{g}$$, $$A = 5.0\text{cm}$$, $$t = 0$$에서 최대 변위

| 양 | 값 |
| --- | --- |
| $$\omega$$ | $$\sqrt{5.0/0.2} = 5.0\ \text{rad/s}$$ |
| $$T$$ | $$2\pi/5.0 = 1.26\text{s}$$ |
| $$v_{max}$$ | $$5.0 \times 0.05 = 0.25\ \text{m/s}$$ |
| $$a_{max}$$ | $$25 \times 0.05 = 1.25\ \text{m/s}^2$$ |
| $$x(t)$$ | $$0.050\cos(5.0t)\ \text{m}$$ |

**예제 2**: $$k = 20.0\ \text{N/m}$$, $$m = 0.50\text{kg}$$, $$A = 3.0\text{cm}$$

$$E = \frac{1}{2}(20)(0.03)^2 = 9.0 \times 10^{-3}\text{J}, \qquad v_{max} = \sqrt{40} \times 0.03 = 0.190\ \text{m/s}$$

$$x = 2.0\text{cm}$$에서 $$U = \frac{1}{2}kx^2 = 4.0 \times 10^{-3}\text{J}$$, $$K = E - U = 5.0 \times 10^{-3}\text{J}$$.

## 5. 파동 (16장)

| 종류 | 진동 방향 | 예 |
| --- | --- | --- |
| 횡파 | 진행 방향에 수직 | 줄의 파동, 전자기파, 물결파 |
| 종파 | 진행 방향과 나란함 | 음파, 용수철을 밀고 당기는 파동 |

### 진행파

$$y = f(x)$$ 모양이 속력 v로 +x 방향으로 가면 $$y(x,t) = f(x - vt)$$. 사인파는

$$y(x,t) = A\sin(kx - \omega t + \phi), \qquad k = \frac{2\pi}{\lambda}, \quad \omega = 2\pi f, \quad v = \lambda f = \frac{\omega}{k}$$

**예제**: $$A = 15\text{cm}$$, $$\lambda = 40\text{cm}$$, $$f = 8.0\text{Hz}$$, $$t = 0$$, $$x = 0$$에서 $$y = 15\text{cm}$$

$$k = \frac{2\pi}{40} = 0.157\ \text{rad/cm}, \quad \omega = 50.3\ \text{rad/s}, \quad T = 0.125\text{s}, \quad v = 320\ \text{cm/s}$$

$$15 = 15\sin\phi$$에서 $$\phi = \pi/2$$이므로 $$y = 15\cos(0.157x - 50.3t)\ \text{cm}$$.

### 줄의 파동 속력

$$v = \sqrt{\frac{T}{\mu}}, \qquad \mu = \frac{m}{L}$$

**예제**: 길이 6.0m, 질량 0.30kg인 줄에 2.0kg 추를 도르래로 매달면 $$T = 19.6\text{N}$$, $$\mu = 0.05\ \text{kg/m}$$, $$v = 19.8\ \text{m/s}$$.

## 6. 정상파와 소리 (17장)

반대 방향으로 진행하는 같은 파동 $$y_1 = A\sin(kx - \omega t)$$, $$y_2 = A\sin(kx + \omega t)$$를 더하면

$$y = 2A\sin(kx)\cos(\omega t)$$

위치마다 진폭이 $$2A\sin kx$$로 고정되어 **마디**($$\sin kx = 0$$, $$x = n\lambda/2$$)와 **배**($$x = (2n+1)\lambda/4$$)가 생긴다.

| 경계 | 파장 | 진동수 |
| --- | --- | --- |
| 양끝 고정 줄, 양끝 열린 관 | $$\lambda_n = 2L/n$$ | $$f_n = n\dfrac{v}{2L}$$, n = 1, 2, 3, … |
| 한쪽 닫힌 관 | $$\lambda_n = 4L/n$$ | $$f_n = n\dfrac{v}{4L}$$, **n = 1, 3, 5, …** (홀수 배음만) |

### 도플러 효과

$$f' = f\,\frac{v + v_o}{v - v_s}$$

$$v_o$$는 관측자가 음원 쪽으로, $$v_s$$는 음원이 관측자 쪽으로 움직일 때 양수다. 13주차 과제처럼 구급차가 차를 **추월한 뒤**에는 음원이 멀어지고 관측자는 음원을 따라가므로 $$f' = f\dfrac{v - v_o}{v + v_s}$$가 되어 진동수가 낮아진다.

## 최종 핵심 정리

1. 정적 평형은 알짜 힘과 알짜 토크가 모두 0이어야 하며, 기준점은 미지의 힘이 작용하는 점으로 잡는다
2. 만유인력은 거리 제곱에 반비례하고, 지표 중력가속도로 지구 질량과 평균 밀도를 구할 수 있다
3. 지구 탈출속도는 √(2GM/R) ≈ 11.2 km/s다
4. 유체 속 압력은 P0 + ρgh로 깊이에만 의존한다
5. 부력은 밀어낸 유체의 무게이며, 뜬 물체의 잠긴 비율은 두 밀도의 비다
6. 단순조화운동의 주기는 2π√(m/k)로 진폭과 무관하고 vmax = ωA, amax = ω²A다
7. 진행파는 A sin(kx − ωt + φ)로 쓰며 v = λf = ω/k, 줄에서는 √(T/μ)다
8. 한쪽 닫힌 관은 홀수 배음만 생기고, 도플러 효과는 음원과 관측자가 가까워질 때 진동수가 높아진다
