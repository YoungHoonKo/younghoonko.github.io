## 1. 극한과 연속

$$\lim_{x \to 0}\frac{\sin x}{x} = 1, \qquad \lim_{n \to \infty}\left(1 + \frac{1}{n}\right)^n = e$$

$$f$$가 $$a$$에서 연속 $$\iff$$ $$\displaystyle\lim_{x \to a} f(x) = f(a)$$ (극한이 존재하고, 함숫값이 있고, 둘이 같다).

### 중간값 정리

$$f$$가 $$[a,b]$$에서 연속이고 $$f(a)$$와 $$f(b)$$의 부호가 다르면, $$(a,b)$$에 $$f(c) = 0$$인 c가 **적어도 하나** 있다. 기출의 "3차방정식이 1과 2 사이에서 적어도 하나의 실근을 갖는가"는 양끝 함숫값의 부호만 확인하면 된다.

## 2. 미분

$$f'(a) = \lim_{h \to 0}\frac{f(a+h) - f(a)}{h}$$

### 기출 참/거짓 함정

| 명제 | 참/거짓 | 반례 |
| --- | --- | --- |
| 연속이면 미분가능하다 | **거짓** | $$f(x) = \lvert x \rvert$$는 0에서 연속이지만 뾰족해서 미분 불가 |
| 미분가능하면 연속이다 | 참 | |
| $$f'(c)$$가 정의되지 않는 점에서는 극값이 없다 | **거짓** | $$\lvert x \rvert$$는 0에서 미분 불가지만 최솟값 |
| $$f''(c) = 0$$이면 c에서 변곡점이다 | **거짓** | $$x^4$$는 $$f''(0) = 0$$이지만 오목볼록이 바뀌지 않음 |

> **(중요!!)** 극값 후보(임계점)는 $$f'(c) = 0$$인 점 **그리고** $$f'(c)$$가 없는 점이다. 변곡점은 $$f''$$의 **부호가 바뀌는** 점이다.
{: .prompt-danger }

### 미분 공식

| 함수 | 도함수 |
| --- | --- |
| $$x^n$$ | $$nx^{n-1}$$ |
| $$e^x$$, $$a^x$$ | $$e^x$$, $$a^x\ln a$$ |
| $$\ln x$$, $$\log_a x$$ | $$\dfrac{1}{x}$$, $$\dfrac{1}{x\ln a}$$ |
| $$\sin x$$, $$\cos x$$, $$\tan x$$ | $$\cos x$$, $$-\sin x$$, $$\sec^2 x$$ |
| $$\sin^{-1}x$$, $$\tan^{-1}x$$ | $$\dfrac{1}{\sqrt{1-x^2}}$$, $$\dfrac{1}{1+x^2}$$ |
| $$\sinh x$$, $$\cosh x$$ | $$\cosh x$$, $$\sinh x$$ (부호 변화 없음) |

연쇄법칙: $$\dfrac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$$. 기출의 $$\sin(\sin x)$$ 꼴은 $$\cos(\sin x)\cos x$$.

### 로그 미분

지수와 밑에 모두 x가 있으면 양변에 로그를 취한다.

$$y = x^x \;\Rightarrow\; \ln y = x\ln x \;\Rightarrow\; \frac{y'}{y} = \ln x + 1 \;\Rightarrow\; y' = x^x(\ln x + 1)$$

### 구간별 함수의 미분가능성

$$x = a$$에서 나뉜 함수가 모든 곳에서 미분가능하려면 (1) 두 식의 함숫값이 같고(연속), (2) 두 식의 도함수 값이 같아야 한다. 두 조건으로 미지수 a, b 두 개를 푼다.

## 3. 미분의 응용

### 평균값 정리

$$f$$가 $$[a,b]$$에서 연속, $$(a,b)$$에서 미분가능이면 $$f'(c) = \dfrac{f(b) - f(a)}{b - a}$$인 $$c \in (a,b)$$가 있다.

**예제**: $$f(x) = x^3 - x$$, $$[-1, 2]$$

$$\frac{f(2) - f(-1)}{3} = \frac{6 - 0}{3} = 2 = 3c^2 - 1 \;\Rightarrow\; c = \pm 1$$

c는 **열린 구간 (-1, 2) 안**이어야 하므로 $$c = 1$$만 답이다.

### 선형 근사

$$f(x) \approx f(a) + f'(a)(x - a)$$

$$\sqrt{4.1} \approx 2 + \dfrac{1}{2\sqrt{4}}(0.1) = 2.025$$ (실제 2.02485)

### 관련 변화율

높이 50m 탑을 향해 속력 v로 걸어갈 때, 탑까지 거리 x에서 탑 꼭대기를 보는 각 $$\theta = \tan^{-1}(50/x)$$.

$$\frac{d\theta}{dt} = \frac{-50}{x^2 + 2500}\frac{dx}{dt} = \frac{50v}{x^2 + 2500}, \qquad x = 100\text{m에서 } \frac{d\theta}{dt} = \frac{v}{250}\ \text{rad/s}$$

($$dx/dt = -v$$, 거리가 줄어드니 음수)

### 로피탈 정리

$$\frac{0}{0}$$ 또는 $$\frac{\infty}{\infty}$$ 꼴이면 $$\displaystyle\lim\frac{f}{g} = \lim\frac{f'}{g'}$$.

$$\lim_{x \to 0}\frac{1 - \cos x}{x^2} = \lim_{x \to 0}\frac{\sin x}{2x} = \frac{1}{2}$$

$$0 \cdot \infty$$나 $$1^\infty$$ 꼴은 분수로 바꾸거나 로그를 취해 위 꼴로 만든 뒤 쓴다.

## 4. 그래프 분석

### 절차

1. 정의역, 수직 점근선(분모 = 0), 수평 점근선($$x \to \pm\infty$$)
2. $$f'$$의 부호 → 증가·감소, 극값
3. $$f''$$의 부호 → 오목·볼록, 변곡점

### 예제 1 (2019 중간 유형): $$f(x) = \dfrac{x}{x^2 - 4}$$

$$f'(x) = -\frac{x^2 + 4}{(x^2 - 4)^2} < 0, \qquad f''(x) = \frac{2x(x^2 + 12)}{(x^2 - 4)^3}$$

| 항목 | 결과 |
| --- | --- |
| 점근선 | 수직 $$x = \pm 2$$, 수평 $$y = 0$$ |
| 증감 | 정의역 전체에서 감소 → **극값 없음** |
| 위로 볼록 ($$f'' < 0$$) | $$(-\infty, -2)$$, $$(0, 2)$$ |
| 변곡점 | $$(0, 0)$$ ($$f''$$의 부호가 바뀌고 0이 정의역 안) |

### 예제 2 (2021 기말 유형): $$f(x) = \dfrac{1}{x^2 + 4x}$$

$$f'(x) = -\frac{2(x+2)}{x^2(x+4)^2}, \qquad f''(x) = \frac{2(3x^2 + 12x + 16)}{x^3(x+4)^3}$$

| 항목 | 결과 |
| --- | --- |
| 점근선 | 수직 $$x = 0, -4$$, 수평 $$y = 0$$ |
| 증가 | $$(-\infty, -4) \cup (-4, -2)$$ |
| 아래로 볼록 ($$f'' > 0$$) | $$(-\infty, -4)$$, $$(0, \infty)$$ |
| 변곡점 | **없음**: $$3x^2 + 12x + 16$$은 판별식이 음수라 항상 양수, $$f''$$의 부호는 점근선에서만 바뀜 |

> 부호가 바뀌는 곳이 **점근선(정의되지 않는 점)** 이면 변곡점이 아니다. 변곡점은 그래프 위의 점이어야 한다.
{: .prompt-warning }

```python
import sympy as sp
x = sp.symbols('x')
for f in [x / (x**2 - 4), 1 / (x**2 + 4*x)]:
    print(sp.factor(sp.diff(f, x)), sp.factor(sp.diff(f, x, 2)))
```

## 최종 핵심 정리

1. 연속은 극한값과 함숫값이 같다는 뜻이고, 중간값 정리로 근의 존재를 보일 수 있다
2. 미분가능하면 연속이지만 연속이라고 미분가능하지는 않다 (절댓값 함수 반례)
3. 극값 후보는 f' = 0인 점과 f'이 없는 점이다
4. f'' = 0이어도 부호가 바뀌지 않으면 변곡점이 아니다 (x⁴)
5. 지수와 밑에 모두 변수가 있으면 로그 미분을 쓴다
6. 평균값 정리의 c는 열린 구간 안에 있어야 한다
7. 0/0, ∞/∞ 꼴은 로피탈 정리로, 다른 부정형은 변형한 뒤 적용한다
8. 그래프는 점근선, f'의 부호, f''의 부호 순서로 분석하고, 점근선에서의 부호 변화는 변곡점이 아니다
