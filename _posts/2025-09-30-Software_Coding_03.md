## 1. 산술 연산자

| 연산자 | 뜻 | `9 ? 2` | 결과 자료형 |
| --- | --- | --- | --- |
| `/` | 나눗셈 | 4.5 | **항상 float** |
| `//` | 몫 | 4 | 정수끼리면 int |
| `%` | 나머지 | 1 | 정수끼리면 int |
| `**` | 거듭제곱 | 81 | |

> **(중요!!)** `/`의 결과는 나누어떨어져도 실수다. `9 / 3`의 답은 3이 아니라 **3.0** (4라고 쓰면 오답, 4.0이라 써야 함)
{: .prompt-warning }

- `6 % 8` = 6: 나누는 수보다 작으면 몫은 0, 나머지는 자기 자신
- **나머지가 0이면 배수**다. 홀짝 판별(`n % 2`), 3의 배수 판별(`n % 3 == 0`)에 쓴다
- 음수의 몫과 나머지: `-7 // 2` = −4, `-7 % 2` = 1. `//`는 **아래쪽(−∞ 방향)으로 내림**이라 `int(-3.5)`(= −3)와 다르다

## 2. 우선순위

| 순위 | 연산자 |
| --- | --- |
| 1 (높음) | `()` |
| 2 | `**` (오른쪽부터 계산) |
| 3 | 단항 `+x`, `-x` |
| 4 | `*`, `/`, `//`, `%` (같은 순위, 왼쪽부터) |
| 5 | `+`, `-` (같은 순위, 왼쪽부터) |
| 6 | 비교 `<`, `<=`, `>`, `>=`, `==`, `!=` (모두 같은 순위) |
| 7 | `not` |
| 8 | `and` |
| 9 (낮음) | `or` |

대입 `=`, `+=`는 연산자가 아니라 **문장(statement)** 이라 맨 마지막에 일어난다.

```python
print(2 + 3 * 4)          # 14
print((2 + 3) * 4)        # 20
print(2 * 3 ** 2)         # 18
print((2 * 3) ** 2)       # 36
print(8 / 4 * 2)          # 4.0  왼쪽부터
print(8 * 2 / 4)          # 4.0
print(-3 ** 2)            # -9   ** 먼저, 그다음 부호
print((-3) ** 2)          # 9
print(10 - 6 / 2)         # 7.0
print(20 % 6 * 2)         # 4
print(25 // 2 ** 2)       # 6
print(6 + 2**2 * 3**2)    # 42
print(6 % 2**3 // 3 + 1)  # 3
print((5 + 3) * 2**(4-2)) # 32
```

모두 실행 결과와 주석이 같다.

- `-3 ** 2`는 −(3²) = −9. 거듭제곱이 단항 마이너스보다 먼저다
- `6 % 2**3 // 3 + 1` = 6 % 8 // 3 + 1 = (6 % 8) // 3 + 1 = 6 // 3 + 1 = 3. `%`와 `//`는 같은 순위라 **왼쪽부터**
- `8 / 4 * 2`처럼 같은 순위는 왼쪽에서 오른쪽. 곱셈이 나눗셈보다 먼저인 것이 아니다

## 4. 비교와 논리

```python
print('%d > %d ? %s' % (6, 5, 6 > 5))
print(True and False, False or True, not (2**3 > 4))
print((5 > (1+2+3)) and (14 > 2**3))
print(int(True), int(False))
print(bool(0), bool(1), bool(2), bool(-2))
print(2*False + 5*True)
```

실행 결과

```text
6 > 5 ? True
False True False
False
1 0
False True True True
5
```

- 숫자 0만 거짓이고, 음수를 포함한 나머지 숫자는 모두 참
- `True`는 1, `False`는 0으로 계산된다

### 비교 연산자는 모두 같은 순위, 그리고 연쇄 비교

```python
print(1 < 2 == 2)      # (1 < 2) and (2 == 2)
print((1 < 2) == 2)    # True == 2
print(8 < 13 < 19)
```

실행 결과

```text
True
False
True
```

- 파이썬은 `a < b == c`를 `(a < b) and (b == c)`로 해석한다(연쇄 비교). C 언어처럼 `==`가 `<`보다 낮은 순위인 것이 아니다
- 그래서 `8 < hour < 19`처럼 범위를 수학식 그대로 쓸 수 있다

## 5. True = 1을 이용한 조건 계산

if문을 배우기 전 실습에서는 비교 결과(True/False)를 곱해서 조건을 표현했다. 교수님이 선호한 방식이라 시험에도 나왔다.

```python
# 택시 요금: 기본 3,000원, 2km 초과분은 km당 500원
distance = 1
print(3000 + (distance - 2) * 500 * (distance > 2))

# 커피: 그란데면 잔당 500원 추가
cups, price, size = 3, 3000, 'Grande'
pay = cups * (price + 500 * (size == 'Grande'))
print(pay)

# BMI 판정
weight, height = 70, 170
bmi = weight / (height / 100) ** 2
out = 18.5 <= bmi < 25
print("BMI is %.2f" % bmi, 'Good' * out + 'Bad' * (not out))
```

실행 결과

```text
3000
10500
BMI is 24.22 Good
```

- distance = 1이면 `(1 - 2) * 500 * False` = −500 × 0 = 0이라 음수 요금이 생기지 않는다
- 문자열 × True는 문자열 그대로, × False는 빈 문자열

## 6. 과제 3: 학점 산출

> **과제 3**: 성적을 입력받아 90점 이상이면 A, 80점 이상 90점 미만이면 B, 80점 미만이면 C를 출력하라. (힌트: 4장 BMI 예제)
{: .prompt-info }

```python
score = float(input("Enter your score: "))
grade = "A" * (score >= 90) + "B" * ((score >= 80) and (score < 90)) + "C" * (score < 80)
print("Your grade is %s" % grade)
```

경계값으로 실행한 결과

| 입력 | 95 | 90 | 89.9 | 80 | 79.5 |
| --- | --- | --- | --- | --- | --- |
| 출력 | A | A | B | B | C |

- 세 조건이 겹치지 않고 빈틈도 없어서 항상 글자 하나만 붙는다
- `(score >= 80) and (score < 90)`은 `80 <= score < 90`으로 줄일 수 있다

## 7. 과제 4-2: 3의 배수이면서 5의 배수

> **과제 4-2**: 정수를 입력받아 3의 배수이면서 5의 배수이면 True, 아니면 False를 출력하라.
{: .prompt-info }

```python
num = int(input("숫자를 입력하세요: "))
print(num % 3 == 0 and num % 5 == 0)
```

| 입력 | 15 | 30 | 0 | −45 | 10 | 9 |
| --- | --- | --- | --- | --- | --- | --- |
| 출력 | True | True | True | True | False | False |

- 0과 음수 −45도 15의 배수라서 True. 3과 5의 공배수 = 15의 배수이므로 `num % 15 == 0`과 같다

### 강의 자료 및 정리 노트에서 정정한 부분 정리

| 위치 | 원래 | 정정 | 이유 |
| --- | --- | --- | --- |
| 4주차 노트 | 곱셈 → 나눗셈 → 덧셈 → 뺄셈 순 | `*`, `/`는 같은 순위, `+`, `-`도 같은 순위, 같은 순위는 왼쪽부터 | `8 / 4 * 2` = 4.0 |
| 4주차 노트 | 같다·같지 않다가 다른 비교 연산자보다 순위가 낮다 | 파이썬은 비교 연산자 6개가 모두 같은 순위(연쇄 비교) | `1 < 2 == 2`가 True |
| 4주차 노트 | 논리 연산자가 순위가 제일 낮다 / 대입이 가장 낮다 | 표현식 안에서는 `or`가 가장 낮고, 대입은 연산자가 아닌 문장 | 파이썬 문법 |
| 4주차 실습 주석 | `9/3`은 "나머지도 같이 보여줌" | 나머지가 아니라 실수 몫(3.0) | `/`는 실수 나눗셈 |

## 최종 핵심 정리

1. `/`는 항상 실수(9 / 3 = 3.0), `//`는 몫, `%`는 나머지, `**`는 거듭제곱
2. 나머지가 0이면 배수이고, 홀짝·배수 판별에 `%`를 쓴다
3. 우선순위: 괄호 > `**` > 단항 `-` > `* / // %` > `+ -` > 비교 > `not` > `and` > `or`
4. `-3 ** 2` = −9, `6 % 2**3 // 3 + 1` = 3처럼 같은 순위는 왼쪽부터 계산한다
5. 복합 대입 `x += 5`는 `x = x + 5`와 같고, 10 → 15 → 30 예제가 시험에 나왔다
6. 파이썬의 비교 연산자는 모두 같은 순위이고 `8 < x < 19`처럼 연쇄해서 쓸 수 있다
7. True = 1, False = 0이라 조건을 곱해서 요금·학점을 if 없이 계산할 수 있다
8. 과제 3은 경계값 90, 80에서 A, B로 맞게 나오고, 과제 4-2는 15의 배수 판별과 같다
