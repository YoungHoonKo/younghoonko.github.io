## 1. 단위와 차원 (1장)

- SI 기본 단위: 길이 m, 질량 kg, 시간 s
- 차원 분석: 식의 양변은 차원이 같아야 한다. $$[L]$$, $$[M]$$, $$[T]$$로 표시

**예제**: $$x = \frac{1}{2}at^2$$은 $$[L] = [L/T^2][T^2] = [L]$$이므로 차원이 맞다.

**예제**: 반지름 $$r$$인 원을 속력 $$v$$로 도는 입자의 가속도가 $$a \propto r^n v^m$$이면

$$[L T^{-2}] = [L]^n [L T^{-1}]^m = [L^{n+m} T^{-m}] \;\Rightarrow\; m = 2,\; n = -1 \;\Rightarrow\; a = \frac{v^2}{r}$$

> 차원 분석은 무차원 상수($$\frac{1}{2}$$, $$2\pi$$ 등)는 알려 주지 못한다. 식이 틀렸음은 보여 줄 수 있지만 맞았음을 증명하지는 못한다.
{: .prompt-info }

단위 변환은 1이 되는 비율을 곱한다: $$75\ \text{mi/h} \times \dfrac{1609\ \text{m}}{1\ \text{mi}} \times \dfrac{1\ \text{h}}{3600\ \text{s}} \approx 33.5\ \text{m/s}$$.

## 2. 1차원 운동 (2장)

| 양 | 정의 |
| --- | --- |
| 변위 | $$\Delta x = x_f - x_i$$ (방향 있음) |
| 평균 속도 | $$\bar{v} = \Delta x / \Delta t$$ |
| 평균 속력 | 이동 거리 / 시간 (항상 0 이상) |
| 순간 속도 | $$v = dx/dt$$ (위치-시간 그래프의 접선 기울기) |
| 가속도 | $$a = dv/dt = d^2x/dt^2$$ |

### 등가속도 운동

$$v = v_0 + at, \qquad x = x_0 + v_0 t + \frac{1}{2}at^2, \qquad v^2 = v_0^2 + 2a(x - x_0), \qquad x - x_0 = \frac{v_0 + v}{2}t$$

자유낙하는 $$a = -g = -9.8\ \text{m/s}^2$$인 등가속도 운동이다.

> 출발점으로 돌아오면 변위는 0이므로 **평균 속도는 0**이지만, 평균 속력은 0이 아니다.
{: .prompt-warning }

## 3. 벡터 (3장)

$$\vec{A} = A_x\hat{i} + A_y\hat{j} + A_z\hat{k}, \qquad A_x = A\cos\theta,\; A_y = A\sin\theta, \qquad A = \sqrt{A_x^2 + A_y^2}$$

- 벡터 합은 성분끼리 더한다
- 내적: $$\vec{A} \cdot \vec{B} = AB\cos\theta = A_xB_x + A_yB_y + A_zB_z$$ → 사이각 계산에 사용

**예제**: $$\vec{A} = 3\hat{i} + 4\hat{j} + 5\hat{k}$$, $$\vec{B} = -2\hat{i} + 4\hat{k}$$이면

$$\vec{A}\cdot\vec{B} = -6 + 0 + 20 = 14, \qquad \cos\theta = \frac{14}{\sqrt{50}\sqrt{20}} = \frac{14}{31.62} \;\Rightarrow\; \theta \approx 63.7°$$

## 4. 2차원 운동과 원운동 (4장)

- 포물선 운동: 수평은 등속 $$x = v_0\cos\theta\, t$$, 수직은 등가속도 $$y = v_0\sin\theta\, t - \frac{1}{2}gt^2$$
- 수평 도달 거리 $$R = \dfrac{v_0^2\sin 2\theta}{g}$$ → 45°에서 최대
- **등속 원운동**: 속력은 일정하지만 방향이 바뀌므로 가속도가 있다

$$a_c = \frac{v^2}{r} = \omega^2 r, \qquad T = \frac{2\pi r}{v}$$

구심가속도는 항상 원의 중심을 향한다. 과제의 "원형 트랙을 일정한 구심가속도로 도는 주자의 일주 시간"은 $$v = \sqrt{a_c r}$$을 구한 뒤 $$T = 2\pi r / v$$로 풀었다.

## 5. 뉴턴의 법칙과 마찰 (5~6장)

| 법칙 | 내용 |
| --- | --- |
| 1법칙 (관성) | 알짜 힘이 0이면 속도가 변하지 않는다 |
| 2법칙 | $$\sum \vec{F} = m\vec{a}$$ |
| 3법칙 (작용-반작용) | $$\vec{F}_{12} = -\vec{F}_{21}$$, 서로 **다른 물체**에 작용 |

### 풀이 순서

1. 물체 하나씩 **자유물체도**를 그린다 (중력, 수직항력, 장력, 마찰력)
2. 좌표축을 정하고 성분별로 $$\sum F_x = ma_x$$, $$\sum F_y = ma_y$$
3. 평형이면 $$a = 0$$, 줄로 연결되면 가속도 크기가 같다

### 마찰력

$$f_s \le \mu_s n, \qquad f_k = \mu_k n$$

- 정지마찰은 미는 힘만큼 커지다가 최댓값 $$\mu_s n$$을 넘으면 미끄러진다 → 과제처럼 "적어도 150N은 가해야 움직인다"면 $$\mu_s = 150/n$$
- 보통 $$\mu_k < \mu_s$$

### 원운동의 힘

구심력은 새로운 힘이 아니라 **중심 방향 알짜 힘**의 이름이다: $$\sum F_r = m\dfrac{v^2}{r}$$.

## 6. 일과 에너지 (7~8장)

$$W = \vec{F}\cdot\Delta\vec{r} = F\Delta r\cos\theta, \qquad W_{net} = \Delta K = \frac{1}{2}mv_f^2 - \frac{1}{2}mv_i^2$$

| 에너지 | 식 |
| --- | --- |
| 운동에너지 | $$K = \frac{1}{2}mv^2$$ |
| 중력 위치에너지 | $$U_g = mgy$$ |
| 탄성 위치에너지 | $$U_s = \frac{1}{2}kx^2$$ |

- 보존력(중력, 탄성력)만 일하면 $$K_i + U_i = K_f + U_f$$
- 마찰이 있으면 $$\Delta E_{mech} = -f_k d$$ (열로 전환)
- 일률 $$P = dW/dt = \vec{F}\cdot\vec{v}$$

## 7. 운동량과 충돌 (9장)

$$\vec{p} = m\vec{v}, \qquad \vec{I} = \int \vec{F}\,dt = \Delta\vec{p}, \qquad \bar{F} = \frac{\Delta p}{\Delta t}$$

**예제 (8주차 과제 유형)**: 45 m/s로 날아온 공을 반대 방향 70 m/s로 쳐 냈다면 속도 변화는 115 m/s다. 방향이 바뀌므로 **두 속력을 더한다**. 평균 힘은 $$m \times 115 / \Delta t$$.

외력이 없으면 계의 운동량이 보존된다: $$\sum \vec{p}_i = \sum \vec{p}_f$$.

| 충돌 | 운동량 | 운동에너지 |
| --- | --- | --- |
| 탄성 | 보존 | 보존 |
| 비탄성 | 보존 | 감소 |
| 완전 비탄성 | 보존 | 최대로 감소 (붙어서 함께 움직임) |

### 탄동 진자

총알(m)이 나무토막(M)에 박힌 뒤 높이 h만큼 올라가면, 충돌은 완전 비탄성(운동량 보존), 올라가는 과정은 역학적 에너지 보존이다.

$$mv_1 = (m + M)v_2, \qquad \frac{1}{2}(m+M)v_2^2 = (m+M)gh \;\Rightarrow\; v_1 = \frac{m + M}{m}\sqrt{2gh}$$

> **(중요!!)** 충돌 순간에 에너지 보존을 쓰면 안 된다. 박히는 과정에서 운동에너지 대부분이 열로 빠져나간다. **충돌은 운동량, 그 뒤는 에너지**로 단계를 나눈다.
{: .prompt-danger }

### 2차원 충돌

교차로에서 서쪽으로 가던 차와 남쪽으로 가던 차가 붙으면 x, y 성분을 따로 보존시킨다.

$$m_A v_A = (m_A + m_B)v_f\cos\theta, \qquad m_B v_B = (m_A + m_B)v_f\sin\theta$$

### 질량 중심

$$x_{cm} = \frac{\sum m_i x_i}{\sum m_i}, \qquad x_{cm} = \frac{1}{M}\int x\,dm$$

**예제**: 직선 위 0m에 2kg, 3m에 3kg, 7m에 5kg이면 $$x_{cm} = (0 + 9 + 35)/10 = 4.4\text{m}$$. 균일한 막대의 질량 중심은 적분하면 정중앙이다.

## 최종 핵심 정리

1. 차원 분석으로 식의 차원을 확인하고 비례 관계의 지수를 정할 수 있다
2. 등가속도 운동은 v = v0 + at, x = v0t + ½at², v² = v0² + 2aΔx로 푼다
3. 평균 속도는 변위, 평균 속력은 이동 거리로 계산한다
4. 등속 원운동의 가속도는 중심을 향하고 크기는 v²/r이다
5. 뉴턴 법칙은 물체마다 자유물체도를 그리고 성분별로 ΣF = ma를 세운다
6. 정지마찰은 최댓값 μsn까지 커지고, 운동마찰은 μkn으로 일정하다
7. 보존력만 일하면 역학적 에너지가 보존되고, 마찰은 역학적 에너지를 열로 바꾼다
8. 충돌은 운동량 보존으로, 충돌 뒤의 운동은 에너지 보존으로 단계를 나눠 푼다
