## 1. 조형 요소 (Formal Elements)

비주얼 아트의 기본 요소: 선, 빛과 명도, 색, 질감과 패턴, 형태와 양감, 공간, 시간과 움직임, 우연성·즉흥성

### 선 (Line)

선은 **움직이는 점**이다.

| 선의 방향 | 느낌 |
| --- | --- |
| 수평선 | 평온, 조용함, 정적 |
| 수직선 | 열망, 중력을 거스르는 느낌 |
| 사선(diagonal) | 움직임(날아가는 나무, 뛰는 동물) |
| 곡선·구불한 선(meandering) | 흐르는 움직임 |

| 선의 종류 | 특징 |
| --- | --- |
| 아웃라인 | **일정한 굵기**로 형태의 바깥을 그림 → 평면적(2차원) |
| 컨투어 라인 | **굵기가 변하며** 형태의 바깥을 그림 → 입체감(3차원) |
| 제스처 라인 | 움직이는 순간을 빠르게 포착 |
| 암시된 선(implied line) | 실제로 그려지지 않았지만 시선, 손짓, 총구 방향 등이 만드는 선 |
| 해칭·크로스 해칭 | 평행선 간격으로 명도를 표현. 겹칠수록 어두움 |

- 선은 감정이나 추상적인 개념(엉뚱함 whimsy, 활기 vigor, 세련 refinement)도 전달한다
- 수업 질문: 폴 클레 그림 가운데의 원은 굵기가 변하므로 아웃라인이 아니라 **컨투어 라인**

### 빛과 명도 (Light and Value)

- 빛: 자연광(해, 달, 번개, 불), 인공광(네온, 레이저)
- **명도(value)** = 밝고 어두운 정도. tone이라고도 한다
- 흰색을 섞으면 **tint**, 검은색을 섞으면 **shade**
- 명암을 넣어 평면을 입체로 보이게 하는 것 = shading(modeling)

### 색 (Color)

> **(중요!!)** 색의 세 속성은 무조건 외우기. 색을 보여 주고 어느 쪽이 명도·채도가 높은지 묻는 문제가 나온다
{: .prompt-warning }

| 속성 | 뜻 |
| --- | --- |
| 색상(hue) | 색의 이름(빨강, 파랑 …) |
| 명도(value) | 밝고 어두운 정도 |
| 채도(intensity) | 색의 선명한 정도. 흰색·검은색은 명도는 있지만 **채도가 없다** |

| 색 관계 | 뜻 |
| --- | --- |
| 원색 | 빨강, 노랑, 파랑 (섞어서 만들 수 없음) |
| 2차색 | 원색 + 원색 (주황, 초록, 보라) |
| 3차색 | 원색 + 이웃한 2차색 (빨강주황 등) |
| 유사색 | 색상환에서 이웃한 색 → 조화로움 |
| 보색 | 색상환에서 정반대 색(빨강–초록, 파랑–주황, 노랑–보라) → 대비가 강하고, 섞으면 탁해짐 |
| 중립색 | 색상이 거의 느껴지지 않는 색(크림, 베이지, 탠, 회색) |

- 따뜻한 색(빨강·주황·노랑)은 **앞으로 나와** 보이고, 차가운 색(파랑·초록·보라)은 **뒤로 물러나** 보인다
- **가산 혼합(빛, RGB)**: 빛이 없으면 검정, 모두 합치면 흰색. 모니터
- **감산 혼합(안료)**: 흰색이 모든 빛을 반사하고, 많이 섞을수록 검정에 가까워짐. 인쇄 잉크(CMY)
- 안료(pigment)는 색이 있는 가루이고, 기름이나 아크릴 폴리머와 섞어 물감이 된다
- 고흐는 빨강–초록 **보색 대비**, 몬드리안은 원색(빨강, 파랑, 노랑)과 흰색·검정만으로 기하학적 구성
- 같은 색도 주변 색이나 빛, 눈의 피로에 따라 다르게 보인다

### 질감과 패턴

- **질감**: 표면의 촉각적·시각적 특징. 실제로 만져지는 **촉각적 질감**, 그림으로 만든 착시인 **시각적 질감**
- **임파스토**: 물감을 두껍게 쌓아 올리는 기법(고흐)
- **패턴**: 형태의 반복. 자연 패턴(나뭇결, 파도: 비슷하지만 똑같지 않음), 기하학적 패턴(일정한 간격)

### 형태와 양감

- 형태(shape)는 2차원, 양감(volume)은 3차원
- 규칙적 → 기하학적(원, 사각형, 삼각형), 불규칙적 → 유기적·생물형(biomorphic)

### 공간과 원근법

평평한 면에 깊이가 있는 것처럼 보이게 하는 방법

| 원근법 | 방법 | 판별 |
| --- | --- | --- |
| 대기 원근법 | 가까운 것은 선명하게, 먼 것은 흐리고 푸르게 | |
| 1점 원근법 | 모든 평행선이 소실점 하나로 모임 | 관람자에게 **면**이 가장 가까움 |
| 2점 원근법 | 소실점 2개 | **모서리**가 가장 가까움 |
| 3점 원근법 | 소실점 3개 | **꼭짓점**이 가장 가까움 |
| 단축법(foreshortening) | 앞으로 튀어나오거나 누운 대상을 짧게 줄여 그림 | |

- 소실점은 눈높이인 **수평선** 위에 있다. 라파엘로 「아테네 학당」의 소실점은 가운데 플라톤과 아리스토텔레스 사이
- 소실점이 화면 밖에 있어 안 보일 수도 있다. 이때는 면·모서리·꼭짓점 중 무엇이 가장 가까운지로 판별(응용 문제)
- 등각 투영(isometric), 사선 투영(oblique)은 이런 것이 있다는 정도만

### 시간과 움직임, 우연성

- 시간: 관람자가 작품을 이해하는 데 걸리는 시간 / 움직임: 평면에서도 반복과 리듬으로 표현
- 큰 조각·건축은 관람자가 **돌아다녀야** 전체가 드러난다
- 작가는 개성을 위해 **우연성(chance)**, **즉흥성(improvisation, spontaneity)** 을 일부러 허용하기도 한다

### 적용: 시간의 흐름을 표현한 세 작품

| 작품 | 방법 |
| --- | --- |
| 모네, 「인상, 해돋이」(1872, 인상주의) | 아웃라인 없이 **붓질 자체가 색이자 형태**. 유사색과 명도 조절로 빛이 움직이는 찰나를 포착 |
| 달리, 「기억의 지속」(1931, 초현실주의) | 사실적인 명암·원근 공간 속에 녹아내리는 시계 → 시간이 멈추거나 늘어진 듯한 느낌 |
| 보초니, 「공간 속 연속성의 독특한 형태」(1913, 미래주의) | 다리·허벅지 뒤쪽의 양감을 날개처럼 과장 → 앞으로 나아가는 운동감 |

## 2. 구성 원리 (Principles of Composition)

조형 요소들이 작품 안에서 **어떻게 배치되는지**. 평면 작품에서는 구성(design)이라고도 한다.

### 균형 (Balance)

핵심은 **시각적 무게(visual weight)**. 무엇이 무겁게 보이는지는 절대적이지 않고 주변 요소와의 관계로 정해진다.

| 균형 | 특징 |
| --- | --- |
| 대칭 균형 | 중심축을 기준으로 양쪽이 같거나 거의 같음 |
| 비대칭 균형 | 양쪽이 다르지만 시각적 무게가 비슷함(예: 한쪽은 작지만 어둡고, 한쪽은 크지만 밝음) |
| 방사형 균형 | 모든 요소가 중심점에서 바깥으로 퍼짐 |

시험: 처음 보는 그림을 주고 어떤 균형인지 묻는다.

### 리듬 (Rhythm)

**반복**이 핵심. 요소가 떨어져서 여러 번 나와야 리듬이 생긴다.

| 리듬 | 특징 | 예 |
| --- | --- | --- |
| 규칙 리듬 | 같은 요소가 일정한 간격으로 반복 | |
| 랜덤 리듬 | 비슷한 요소가 규칙 없이 반복 | |
| 교차 리듬 | 서로 다른 요소가 번갈아 반복 (중요) | 폴 클레, 「노란 새가 있는 풍경」(1923): 은빛 곡선 형태와 노란 새들의 배열 |
| 흐르는 리듬 | 요소들이 흐름과 움직임을 만듦 | 고흐, 「별이 빛나는 밤」(1889) |

### 규모와 비율

- **규모(scale)**: 실제 일반적인 크기와 비교해 크거나 작음. "스케일이 크다"
- **비율(proportion)**: 작품 안에서 한 부분과 다른 부분(또는 전체)의 크기 관계. "8등신"

### 강조와 종속

- 가장 먼저 시선이 가는 곳이 강조, 그곳이 작고 분명하면 **초점(focal point)**
- 종속(subordination): 일부러 시각적 힘을 빼서 강조를 돋보이게 함. 둘은 서로 보완 관계
- 레오나르도 다 빈치, 「최후의 만찬」: 1점 원근법의 모든 선이 예수의 머리(소실점)로 모이고, 뒤의 창문이 머리를 감싸 강조
- 고야, 「1808년 5월 3일」(1814): 흰 셔츠·노란 바지, 팔을 벌린 제스처, 강한 명암 대비로 왼쪽 희생자를 강조하고, 얼굴이 보이지 않는 오른쪽 군인들은 어둡게 종속시켜 비인간적으로 보이게 함. 총구 방향이 암시된 선이 되어 시선을 희생자에게 보낸다

### 통일과 다양

- **통일(unity)**: 전체를 하나로 묶음(반복되는 패턴, 비슷한 색, 일관된 구도)
- **다양(variety)**: 차이와 변화로 단조로움을 피함
- 둘은 반대처럼 보이지만 모든 작품에 함께 있다
- 마티스, 「오세아니아의 기억」(1953): 색 종류와 모양 자체의 차이는 **다양**, 그 모양을 몇 가지 무리로 정리해 반복하고 색을 반복해 등장시킨 방식은 **통일**. 레몬색 도형만 반복 없이 혼자 있다

## 3. 미술관 글쓰기 과제

> **과제(25%)**: 지정 미술관에서 작품 하나를 골라 최소 1시간 관찰하고, 수업에서 배운 조형 언어로 **형식과 구성**을 분석하는 글을 써라. 조사(리서치) 과제가 아니며, 큰 그림에서 세부로, 구체적인 언어로 써야 한다.
{: .prompt-info }

선택한 작품: 김원, 「제목 미상」, 1954, 캔버스에 유채, 102 × 177.7cm, 국립현대미술관

분석의 뼈대

| 항목 | 관찰 |
| --- | --- |
| 선 | 산의 능선, 물의 반사면, 구름이 모두 **수평**으로 이어져 화면 전체가 고요하고 정적 |
| 형태 | 자연을 세밀하게 묘사하지 않고 크고 단순한 면으로 정리 |
| 색 | 가운데 태양 주변의 주황·노랑이 유일한 따뜻한 빛, 산과 땅은 회색·갈색 |
| 명도 | 아래(산, 땅)는 어둡고 위(물, 하늘)로 갈수록 밝아짐 → 원근법보다 밝기 차이로 깊이를 만듦 |
| 질감 | 산과 땅은 거칠고 마른 붓질, 하늘과 물은 매끈함 |
| 공간 | 멀수록 산의 경계가 흐려지는 **대기 원근법** |
| 균형 | 오른쪽의 어두운 산과 왼쪽의 넓고 밝은 하늘이 시각적 무게를 맞춘 **비대칭 균형** |
| 강조 | 크기는 작지만 명도·색·위치가 모이는 **태양이 초점** |
| 리듬 | 반복되는 능선, 물결, 가로 구름이 부드러운 리듬 |
| 통일과 다양 | 수평 방향과 절제된 색이 통일, 태양 주변의 색 번짐과 영역별 질감 차이가 다양 |

처음 작품 앞에서 메모할 때는 리듬·통일·비율을 "잘 모르겠다"로 비워 두었는데, 위 정리처럼 **조형 요소 → 구성 원리 순서로 하나씩 질문**하니 빈칸이 채워졌다. 과제 공지에서 강조한 "이 작품의 주요 조형 요소는 무엇이고, 주요 구성 원리는 무엇인가"라는 질문이 실제로 가장 도움이 됐다.

## 최종 핵심 정리

1. 선은 움직이는 점이며 수평은 평온, 수직은 열망, 사선은 움직임, 곡선은 흐름을 준다
2. 아웃라인은 일정한 굵기(평면), 컨투어 라인은 굵기가 변함(입체), 암시된 선은 시선·제스처가 만든다
3. 색의 세 속성은 색상·명도·채도이고, 흰색과 검은색은 채도가 없다
4. 빛은 가산 혼합(RGB, 모두 합치면 흰색), 안료는 감산 혼합(섞을수록 검정)
5. 1·2·3점 원근법은 관람자에게 가장 가까운 것이 면·모서리·꼭짓점인지로 판별한다
6. 균형은 시각적 무게로 판단하며 대칭, 비대칭, 방사형이 있다
7. 리듬은 반복에서 생기며 규칙, 랜덤, 교차(클레), 흐르는(고흐) 리듬이 있다
8. 강조는 초점을 만들고 종속은 그것을 돋보이게 하며, 통일과 다양은 모든 작품에 함께 있다(마티스)
