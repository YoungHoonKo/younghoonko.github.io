## 1. 매체 (Mediums)

재료(material)는 **작가가 생각을 전달하기 위한 물리적 몸체**다. 작품을 볼 때 무엇으로 만들었는지 먼저 본다.

- 예: 데미언 허스트가 18세기 실제 해골을 쓴 이유는 **바니타스**(17세기 북유럽에서 유행한, 삶은 영원하지 않다는 상징 장르)와 연결된다
- **지지체(support)**: 그림이 올라가는 바탕(종이, 캔버스, 나무, 벽)

### 드로잉

| 재료 | 특징 |
| --- | --- |
| 연필 | 단단할수록 가는 선 |
| 목탄(charcoal) | 어둡고 깊은 명암 |
| 분필·파스텔 | |
| 은필(silverpoint) | 매우 섬세하고 정확한 선 |
| 잉크 | 가장 널리 쓰는 **습식** 재료. 붓·펜 모두 가능 |

위 넷은 건식(dry), 잉크는 습식(wet). **잉크는 회화가 아니라 드로잉 매체**로 분류한다(선으로 그리기 때문, 중요).

### 판화

하나의 판으로 같은 이미지를 여러 장 찍는다.

| 방식 | 뜻 | 판 |
| --- | --- | --- |
| 볼록판(relief) | 튀어나온 부분에 잉크 | 주로 목판 |
| 오목판(intaglio) | 파인 홈에 잉크 → 정교한 선과 명암 | 주로 금속판 (에칭, 드라이포인트, 애쿼틴트 등) |
| 평판(lithography) | 물과 기름이 밀어내는 성질 이용 | 돌·금속판 |
| 공판(실크스크린) | 구멍으로 잉크를 통과 | 앤디 워홀: 작업실을 "공장"이라 부르며 대량 생산 방식으로 제작 |

### 회화

회화 물감 = **안료(pigment, 색 가루) + 바인더(binder, 묶어 주는 매질)**

| 매체 | 바인더·특징 |
| --- | --- |
| 프레스코 | 젖은 석회 위에 안료를 칠해 벽과 하나가 됨. 빨리 말라 빨리 그려야 함. 미켈란젤로 천장화 |
| 템페라 | **달걀노른자**. 빨리 마르고 날카롭고 섬세한 선 |
| 수채화 | 물. 주로 종이 |
| 과슈 | 수채 물감 + 불투명하게 만드는 첨가물(분필 가루 등) |
| 유화 | 기름. 광택과 강한 색, 섬세한 표현. 「모나리자」는 나무판에 그린 유화 |
| 아크릴 | 빨리 마르고 어떤 지지체에도 가능, 평평하고 선명한 색. 데이비드 호크니 |
| 스프레이·에어브러시 | 스프레이 페인트는 빨리 마르고 넓은 면에 좋지만 세밀하기 어려움, 에어브러시는 넓은 면과 디테일 모두 가능. 뱅크시는 스프레이로 디테일을 그리는 실력 |

### 섬유

태피스트리(색실로 짠 직물), 퀼트(조각을 꿰맨 것), 러그, 자수. 예: 청나라 궁정의 용 자수(비단 지지체)

### 조각(3D)

| 용어 | 뜻 |
| --- | --- |
| 환조(free-standing) | 사방에서 볼 수 있음 |
| 부조(relief) | 한 면에서만 보도록 바탕에서 튀어나오게 깎음 |
| 장소 특정(site-specific) | 특정 장소를 위해 만들어 그 공간이 감상의 일부. 옮기면 의미가 사라짐 |
| 키네틱 | 실제 움직임이 작품의 일부 |

| 기법 | 과정 |
| --- | --- |
| 깎기(carving) | 재료를 **빼는** 과정(돌, 나무). 카라라 대리석은 흰 대리석으로 유명 |
| 빚기(modeling) | 점토 등을 누르고 늘려 **더하는** 과정. 달항아리는 위·아래를 따로 빚어 붙임 |
| 주조(casting) | 밀랍 모형 → 점토로 감싸고 가열해 밀랍을 녹여 빼냄(로스트 왁스) → 빈자리에 청동을 부음. 속이 빈 얇은 청동상 |
| 조립(assembling) | 여러 오브젝트를 모아 한 작품(아상블라주), 여러 매체를 섞음(혼합 매체) |

### 설치, 퍼포먼스, 기술 기반 매체

- 설치: 특정 장소에 여러 매체를 배치해 완성, 보통 일정 기간 후 철거
- 퍼포먼스: **사람의 몸**이 주된 매체. 지시문 자체가 작품이 되기도 함
- 다게레오타입: 최초로 상업화된 사진 기법(은판)
- 포토몽타주: 기존 사진을 조합해 새로운 이미지
- 영상: 1960년대 소니 휴대용 비디오카메라가 나오자 백남준이 작품에 사용
- 윌리엄 켄트리지: 목탄 드로잉을 그리고 지우며 한 장씩 촬영해 애니메이션으로 만듦

## 2. 의미 읽기 (Deriving Meaning)

- **도상학(iconography)**: 형상·상징이 무엇을 뜻하는지 연구. 배우지 않으면 모름 → 외우기
- 예: 미국 백악관과 의사당은 그리스 신전(민주주의)과 로마 판테온의 돔(힘)을 본뜬 양식으로 미국의 이상을 표현
- **맥락(context)**: 작품이 만들어진 시대·문화·원래 용도. 의미는 작가 의도대로만 읽히지 않고 시대에 따라 바뀔 수 있다

### 미술 비평 이론

| 이론 | 핵심 |
| --- | --- |
| 형식주의(Formalism) | 클레먼트 그린버그. 매체의 본질에 충실해야 함(회화는 평면답게). 붓질 없이 물감을 흘린 모리스 루이스 「푸른 베일」 |
| 이데올로기 비평(마르크스주의) | 예술의 정치·경제적 측면. 중립적인 작품도 정치적으로 읽을 수 있음 |
| 정신분석 비평 | 프로이트. 작품에 작가의 욕망·감정·꿈이 드러남 |
| 구조주의 | 작품을 이루는 부분들 사이의 관계(구조)를 봐야 이해 |
| 포스트모더니즘 | 거대 서사는 없고 작은 이야기들, 짜깁기(브리콜라주), 복수성, 역설. 모더니즘의 확실성 대신 주체성과 애매함 |

- 게르하르트 리히터 「1977년 10월 18일」 연작은 사진이 아니라 **그림**인데, 초점이 없고 흑백이라 신문 사진처럼 보인다
- 신디 셔먼 「무제 영화 스틸」: 존재하지 않는 영화의 한 장면처럼 작가가 여러 인물을 연기해 찍음 → 원본 없는 복사본, 보드리야르의 **시뮬라크르**

## 3. 예술 만들기, 쓰기, 보존하기

- 예술가 교육: 견습생 → 길드(같은 직업 집단) → 르네상스 무렵의 아카데미(고전과 인문학) → 대학
- 문화마다 예술가는 평범한 사람, 숙련된 장인, 재능 있는 개인, 성직자 등 다른 역할. 발리에서는 모두가 일상적으로 예술을 만든다
- **후원**: 메디치 가문처럼 부와 권력을 가진 개인 → 오늘날은 기업
- **시장**: 경매는 이미 팔린 작품을 되파는 곳이라 작가에게 돌아가는 이익이 거의 없다
- **공공미술 제도(Percent for Art)**: 건물을 지을 때 예산의 일부를 미술품에 쓰게 하는 제도. 한국은 일정 규모(수업 설명: 연면적 1만㎡) 이상의 건축물에 미술작품을 설치하도록 문화예술진흥법 시행령에서 정한다
- 갤러리는 기본적으로 상업 화랑이지만, 미술관 안의 "갤러리"는 전시실을 뜻한다

### 보존되지 않는 예술

- 전쟁·분쟁, **성상 파괴(iconoclasm)**, 다른 문명(아즈텍, 잉카, 마야)의 유산 파괴
- 의식이나 행사를 위해 일시적으로 만든 작품
- **작가가 일부러 영구적인 오브젝트를 남기지 않는 작품**(시험): 미술관이 요리 도구를 소장하고 음식을 만들어 나누는 퍼포먼스처럼, 작품 대신 **계약서·지시문**을 소장하기도 한다

## 4. 예배를 위한 신과 궁전 (Deities and Palaces for Worship)

| 범주 | 뜻 | 미술에서의 모습 |
| --- | --- | --- |
| 애니미즘 | 자연물에 영혼이 있다고 믿음 | 빌렌도르프의 비너스(풍요와 다산) |
| 다신교 | 여러 신 | 그리스 신은 **인간의 모습**(인간 중심 사고), 이집트 신은 동물 또는 인간+동물(소 = 하토르 여신) |
| 범신론 | 모든 곳에 신이 있음 | 힌두교: 많은 신이 하나의 브라만의 화신(아바타)으로 여겨짐(중요). 로마 판테온 = 모든 신에게 바친 신전 |
| 불교 | | 초기에는 부처를 사람 모습으로 그리지 않음. 스투파(사리탑) → 오늘날 석탑. 머리 위 육계(지혜), 미간의 백호, 긴 귓불(왕족 출신), 연꽃 자세. 보살은 깨달음을 얻고도 중생을 구하려 남은 존재 |
| 유일신교 | 하나의 신 | 유대교(구약), 기독교, 이슬람(7세기 무함마드, 신 알라를 형상화하지 않음) |

### 신전 건축

- **그리스 신전**: 기둥 위에 보를 얹는 **기둥–상인방(post and lintel)** 구조. 계단이 기단 역할을 하며 가운데가 살짝 솟아 있어 처져 보이는 착시를 보정하고, 모서리 기둥은 더 굵고 간격이 좁으며 바깥 기둥은 안쪽으로 기울어 있다. 모두 반듯하고 높아 보이게 하려는 계산
- **이집트 신전**: 신이 산다고 믿어 왕족·귀족의 집을 본떠 지었고, 영원하길 바라며 화강암과 석회암 같은 단단한 돌을 썼다

### 강의 자료 및 정리 노트에서 정정한 부분 정리

| 위치 | 원래 | 정정 | 이유 |
| --- | --- | --- | --- |
| 6주차 필기 | 프리 스탠딩 = 부조, 릴리프 = 판조, 장조 | 프리 스탠딩 = **환조**, 릴리프 = **부조**, 장소 특정(site-specific) | 용어 |

| 7주차 필기 | Permoance | Performance | 철자 |

## 최종 핵심 정리

1. 재료는 작가의 생각을 전달하는 몸체이고, 드로잉 재료 중 잉크는 습식이지만 회화가 아니라 드로잉으로 분류한다
2. 판화는 볼록판(목판), 오목판(금속판), 평판(물과 기름), 공판(실크스크린)으로 나뉜다
3. 회화 물감은 안료 + 바인더이고, 프레스코는 젖은 석회, 템페라는 달걀노른자, 유화는 기름을 쓴다
4. 조각은 환조·부조·장소 특정으로 보고, 깎기(빼기)·빚기(더하기)·주조(로스트 왁스) 기법이 있다
5. 퍼포먼스는 몸이 매체이며, 일부러 영구적인 오브젝트를 남기지 않는 작품도 있다
6. 의미는 도상학과 맥락으로 읽고, 비평 이론은 형식주의·이데올로기·정신분석·구조주의·포스트모더니즘이 있다
7. 후원은 메디치 같은 개인에서 기업으로 옮겨 왔고, 공공미술 제도는 건축 예산 일부를 미술품에 쓰게 한다
8. 그리스 신은 인간 모습, 이집트 신은 동물 모습이며, 힌두교는 범신론, 그리스 신전은 착시를 보정한 기둥–상인방 구조다
