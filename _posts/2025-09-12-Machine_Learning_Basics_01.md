## 1. AI, ML, DL

> **(중요!!)** 각 항목의 정의, 관계, 차이점 (시험 출제 표시)
{: .prompt-warning }

| 구분 | 정의 | 핵심 | 예 |
| --- | --- | --- | --- |
| 인공지능(AI) | 사람의 지적 능력(학습, 추론, 문제 해결)을 기계가 수행하게 하는 학문·기술 전체 | 지능적 판단 | 자율주행, 챗봇 |
| 머신러닝(ML) | AI의 한 분야. **명시적으로 규칙을 코딩하지 않고 데이터로부터** 스스로 학습 | 데이터 기반 학습 | 스팸 메일 분류 |
| 딥러닝(DL) | ML의 한 분야. 여러 층의 **인공신경망**이 특징까지 스스로 학습 | 다층 신경망 | 이미지·음성 인식 |

관계는 **AI ⊃ ML ⊃ DL**이다.

수업에서 강조한 관점 변화: 예전에는 사람이 프로그램(규칙)을 만들어 데이터를 처리했다면, 머신러닝은 **데이터를 주면 컴퓨터가 규칙(함수)을 만든다.** 그래서 머신러닝은 입력을 출력으로 바꾸는 함수 y = f(x)를 데이터로 근사하는 일로 볼 수 있다.

### 머신러닝 vs 딥러닝

| 항목 | 머신러닝 | 딥러닝 |
| --- | --- | --- |
| 특징 추출 | 사람이 설계(feature engineering) | 신경망이 자동으로 학습 |
| 모델 | 선형 회귀, SVM, 결정 트리 등 | 다층 신경망 |
| 데이터 양 | 적어도 가능 | 많이 필요 |
| 연산 | CPU로도 충분 | GPU(행렬 연산) 필요 |
| 해석 | 비교적 쉬움 | 블랙박스에 가까움 |

## 2. "기계가 생각할 수 있는가"

| 개념 | 내용 |
| --- | --- |
| 튜링 테스트(1950) | 대화만으로 사람과 기계를 구별할 수 없으면 기계가 지능을 가졌다고 보자는 제안 |
| ELIZA(1966) | 심리치료사를 흉내 낸 초기 챗봇. 키워드를 찾아 정해진 문장을 바꿔 돌려주는 **패턴 매칭** 방식 |
| 중국인 방(1980, 존 설) | 중국어를 모르는 사람이 규칙집만 보고 중국어 답을 만들어도 중국어를 **이해**한 것은 아니다 → 기호 조작만으로는 이해가 아니라는 반론 |

ELIZA는 단순한 규칙만으로도 사람들이 "이해받는다"고 느꼈다는 점에서, 튜링 테스트를 통과한 것처럼 보이는 것과 실제로 이해하는 것이 다르다는 중국인 방 논증의 좋은 예가 된다.

## 3. 응용 분야

| 분야 | 핵심 기술 | AI가 하는 일 |
| --- | --- | --- |
| 자율주행 | 카메라·센서 데이터, 이미지 인식 | 도로와 장애물을 인식 → 판단 → 차량 제어 |
| 광고·추천 | 협업 필터링 | 구매 패턴이 비슷한 사용자의 기록으로 상품 추천 |
| 신약·생물학 | AlphaFold | 아미노산 서열로 단백질 구조 예측 |
| 생성형 AI | LLM + 멀티모달 모델 | 문장 요약, 텍스트로 이미지·영상 생성 |

수업에서 든 예: 자율주행은 여러 센서로 주변 데이터를 모아 **최종 결정**을 내리는데, 센서 값과 상황에는 항상 불확실성이 있다. 이 불확실성을 다루는 도구가 확률·통계라서 머신러닝 수업이 확률부터 시작한다.

## 4. 필기체 인식으로 본 머신러닝의 4단계

> **(중요!!)** 필기체 인식의 4단계를 순서대로 (출제 확정 표시)
{: .prompt-warning }

| 단계 | 하는 일 | 예 |
| --- | --- | --- |
| ① 데이터 수집(패턴 입력) | 이미지를 모으고 잡음 제거 등 전처리 | 손글씨 이미지 |
| ② 특징 추출 | 분류에 쓸 수치(특징 벡터)를 만듦 | 획, 윤곽, 픽셀 비율 |
| ③ 분류 | 학습된 모델로 각 부류일 가능성을 계산 | 0~9 각각의 확률 |
| ④ 의사결정(부류 결정) | **사후확률 P(부류 \| 특징)이 가장 큰 부류**를 출력 | "7" |

- 0~9 중 무엇인지 고를 때, 10개 부류의 확률을 모두 계산해서 가장 그럴듯한 것을 답으로 낸다. 이것이 다음 글의 베이즈 분류다
- 좋은 데이터의 조건(필기): 양이 많고, 부류끼리 특징이 **확실히 달라야** 한다

## 5. 특징 벡터 만들기와 차원의 저주

수업 질문: 숫자 이미지를 0과 1로 된 **8 × 8 이진 이미지**로 바꿨을 때 특징을 무엇으로 할 것인가?

| 방법 | 특징 | 차원 | 장단점 |
| --- | --- | --- | --- |
| A. 64칸을 한 줄로 이어 붙임 | 픽셀 값 그대로 | 64 | 정보 손실 없음, 차원이 큼 |
| B. 위·아래 절반에서 1의 비율 | (위쪽 1의 비율, 아래쪽 1의 비율) | 2 | 정보 일부 손실, 훨씬 효율적 |

B는 2차원 벡터 하나로 이미지를 요약한다. 최적화 관점에서는 계산 비용(시간·메모리)이 중요하므로 B처럼 차원을 줄이는 것이 유리할 때가 많다.

### 차원의 저주 (Curse of Dimensionality)

특징이 d개이고 각 특징을 q개 구간으로 나눠 확률표(히스토그램)를 만들면 칸의 수는

$$q^d$$

로 늘어난다.

| 구간 q | 특징 d | 칸 수 |
| --- | --- | --- |
| 10 | 2 | 100 |
| 10 | 10 | 100억 |
| 2 | 64 (8 × 8 픽셀) | 약 1.8 × 10^19 |

- 칸이 많아지면 칸마다 들어가는 데이터가 거의 없어(**희소**) 확률을 제대로 추정할 수 없고, 저장·계산도 불가능해진다
- 그래서 특징 수를 줄이거나(방법 B), 분포를 가정한 모델(가우시안 등)을 쓴다

---

### 강의 자료 및 정리 노트에서 정정한 부분 정리

| 위치 | 원래 | 정정 | 이유 |
| --- | --- | --- | --- |
| 시험 대비 노트 (이산 vs 연속 표) | 이산 = 분류 모델, 연속 = 회귀 모델 / 이산은 차원의 저주, 연속은 선형 모델 | 이산·연속은 **데이터(특징) 값의 성질**이고, 분류·회귀는 **출력**의 종류로 나뉨. 차원의 저주는 연속 특징을 구간으로 나눠 표로 만들 때도 똑같이 생김 | 표가 두 다른 기준을 한 줄에 섞음 |
| 2주차 필기 | "구글 번역기는 모든 단어를 저장해 문맥 손실이 없다" | 현재 번역기는 신경망이 **문맥까지 학습**하는 방식 | 단어 저장 방식이면 오히려 문맥을 잃음 |

## 최종 핵심 정리

1. AI ⊃ ML ⊃ DL이며, ML은 데이터로 규칙(함수)을 학습하고 DL은 다층 신경망으로 특징까지 학습한다
2. ML은 사람이 특징을 설계하고 데이터가 적어도 되며, DL은 대량 데이터와 GPU가 필요하고 해석이 어렵다
3. 튜링 테스트는 대화로 지능을 판단하고, 중국인 방은 기호 조작만으로는 이해가 아니라고 반박한다
4. ELIZA(1966)는 키워드 패턴 매칭 챗봇으로, "그럴듯해 보이는 것"과 "이해"의 차이를 보여 준다
5. 응용: 자율주행(인식 → 판단 → 제어), 추천(협업 필터링), 신약(AlphaFold)
6. 필기체 인식 4단계: 데이터 수집 → 특징 추출 → 분류 → 의사결정(사후확률 최대 부류)
7. 8 × 8 이진 이미지는 64차원 그대로 쓰거나 1의 비율 같은 2차원 특징으로 줄일 수 있다
8. 차원의 저주: 칸 수가 구간 수의 d제곱으로 늘어 데이터가 희소해지고 계산이 불가능해진다
