## 1. 8주차 실습: 순차 탐색과 이진 탐색

> 1~100까지의 데이터 중 46을 순차 탐색과 이진 탐색으로 찾고, 비교 횟수를 출력하시오.
{: .prompt-info }

### 순차 탐색 (Sequential Search)

앞에서부터 하나씩 비교한다. 정렬되어 있지 않아도 쓸 수 있다.

```c
for (int i = 0; i < 100; i++) {
    count++;                       /* 비교 1회 */
    if (num[i] == t) {
        printf("%d의 인덱스값은 %d입니다.\n", t, i);
        break;
    }
}
printf("순차 탐색 비교 횟수: %d\n", count);
```

실행 결과

```text
탐색할 숫자를 입력하세요: 46
46의 인덱스값은 45입니다.
순차 탐색 비교 횟수: 46
```

### 이진 탐색 (Binary Search)

**정렬된 배열**에서 가운데 값과 비교해 탐색 범위를 절반씩 줄인다.

```c
int B_search(int a, int arr[], int size, int *count) {
    int start = 0, end = size - 1;
    *count = 0;
    while (start <= end) {
        (*count)++;
        int mid = (start + end) / 2;
        if (arr[mid] == a) return mid;
        else if (arr[mid] < a) start = mid + 1;   /* 오른쪽 절반 */
        else end = mid - 1;                       /* 왼쪽 절반 */
    }
    return -1;                                     /* 없음 */
}
```

실행 결과

```text
탐색할 숫자를 입력하세요: 46
46의 인덱스 값은 45입니다.
이진 탐색 비교 횟수: 5
```

46을 찾는 과정 (인덱스 기준, 값 = 인덱스 + 1)

| 회차 | start | end | mid | arr[mid] | 판단 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0 | 99 | 49 | 50 | 46 < 50 → 왼쪽 |
| 2 | 0 | 48 | 24 | 25 | 46 > 25 → 오른쪽 |
| 3 | 25 | 48 | 36 | 37 | 46 > 37 → 오른쪽 |
| 4 | 37 | 48 | 42 | 43 | 46 > 43 → 오른쪽 |
| 5 | 43 | 48 | 45 | 46 | 찾음 |

| | 순차 탐색 | 이진 탐색 |
| --- | --- | --- |
| 전제 | 없음 | **정렬**되어 있어야 함 |
| 46 찾기 | 46회 | 5회 |
| 1~100 각각을 찾을 때 최대 | 100회 | 7회 |
| 1~100 각각을 찾을 때 평균 | 50.5회 | 5.80회 |
| 시간 복잡도 | $$O(n)$$ | $$O(\log n)$$ |

이진 탐색의 최대 비교 횟수는 $$\lfloor \log_2 n \rfloor + 1$$이다. $$n = 100$$이면 $$\lfloor 6.64 \rfloor + 1 = 7$$. 위 표의 최대·평균은 1~100을 모두 찾아 보는 코드를 따로 돌려 얻은 값이다.

## 2. 9주차 실습: 반복 횟수 세기와 재귀

> 1. 배열 {4, 5, 6, 4, 8, 9, 10}에서 중복된 데이터를 찾으시오. 반복 횟수를 확인합니다.
> 2. 배열 {1, 2, 3, 4, 5, 6}의 요소들이 유일한지 확인하시오. 반복 횟수를 확인합니다.
> 3. n = 6일 때 n!을 재귀적 방법으로 계산하시오.
> 4. n = 6일 때 n!을 비재귀적 방법으로 계산하시오.
> 5. {0, 1, …}로 구성되는 피보나치 수열의 n번째 요소를 찾으시오. (n = 6)
{: .prompt-info }

### 1번, 2번: 모든 쌍 비교

```c
void checkUnique(int arr[], int size) {
    int count = 0, isUnique = 1;
    for (int i = 0; i < size - 1; i++) {
        for (int j = i + 1; j < size; j++) {
            count++;
            if (arr[i] == arr[j]) {
                printf("중복된 값 발견: %d\n", arr[i]);
                printf("비교 횟수: %d\n", count);
                isUnique = 0;
                break;
            }
        }
        if (!isUnique) break;
    }
    if (isUnique) {
        printf("모든 값이 유일합니다.\n");
        printf("비교 횟수: %d\n", count);
    }
}
```

실행 결과

```text
[1번] {4, 5, 6, 4, 8, 9, 10}
중복된 값: 4
비교 횟수: 3

[2번] {1, 2, 3, 4, 5, 6}
모든 값이 유일합니다.
비교 횟수: 15
```

- 1번: `arr[0] = 4`를 5, 6, 4와 차례로 비교해 3번째에 찾는다
- 2번: 중복이 없으면 모든 쌍을 비교하므로 $$\binom{6}{2} = \frac{6 \cdot 5}{2} = 15$$회
- 일반적으로 $$\frac{n(n-1)}{2}$$회 → $$O(n^2)$$. 배열을 먼저 정렬하면 이웃끼리만 비교하면 되므로 $$O(n \log n)$$으로 줄일 수 있다

### 3번, 4번: 팩토리얼

$$n! = \begin{cases} 1 & n \le 1 \\ n \times (n-1)! & n > 1 \end{cases}$$

```c
/* 재귀 */
int factorial(int n) {
    if (n <= 1) return 1;              /* 기저 조건 */
    return n * factorial(n - 1);       /* 재귀 호출 */
}

/* 비재귀(반복) */
int factorial_iter(int n) {
    int result = 1;
    for (int i = 1; i <= n; i++) result *= i;
    return result;
}
```

실행 결과 (두 방법 모두)

```text
6! = 720
```

재귀 호출은 `factorial(6) → factorial(5) → … → factorial(1)`까지 내려갔다가, 스택에 쌓인 순서의 반대로 `1 → 2 → 6 → 24 → 120 → 720`이 곱해지며 돌아온다.

> **(중요!!)** 재귀 함수에는 반드시 **기저 조건(base case)**이 있어야 한다. 없으면 호출이 끝나지 않아 스택 오버플로가 난다. 또 `int`는 13!부터 넘쳐서(오버플로) 틀린 값이 나온다.
{: .prompt-warning }

### 5번: 피보나치 수열

$$F_0 = 0,\quad F_1 = 1,\quad F_n = F_{n-1} + F_{n-2}$$

```c
int fibonacci(int n) {
    int a = 0, b = 1, next;
    if (n == 0) return 0;
    if (n == 1) return 1;
    for (int i = 2; i <= n; i++) {
        next = a + b;
        a = b;
        b = next;
    }
    return b;
}
```

실행 결과

```text
6번째 피보나치 수: 8
```

수열 0, 1, 1, 2, 3, 5, **8**에서 $$F_6 = 8$$이다. 0번째부터 세는 것에 주의한다.

### 재귀로 짜면 왜 느린가 (보충)

같은 식을 재귀로 그대로 옮기면 `fib(n-1)`과 `fib(n-2)`가 같은 값을 반복해서 계산한다. 호출 횟수를 세어 보면

```c
long calls;
int fib_rec(int n) { calls++; return n < 2 ? n : fib_rec(n - 1) + fib_rec(n - 2); }
```

```text
fib( 6) =      8, 재귀 호출 25회
fib(12) =    144, 재귀 호출 465회
fib(18) =   2584, 재귀 호출 8361회
fib(24) =  46368, 재귀 호출 150049회
fib(30) = 832040, 재귀 호출 2692537회
```

호출 횟수는 $$2F_{n+1} - 1$$로 지수적으로 늘어난다. 반복문 버전은 $$n - 1$$번 덧셈으로 끝나므로 $$O(n)$$이다.

## 3. 하노이 탑 (보충)

강의 자료 마지막에 나온 예제. 원판 n개를 A에서 C로 옮기려면

1. 위의 n-1개를 A → B (C를 거쳐)
2. 가장 큰 원판을 A → C
3. B의 n-1개를 B → C (A를 거쳐)

```c
void hanoi(int n, char from, char via, char to) {
    if (n == 1) { printf("원판 1: %c -> %c\n", from, to); return; }
    hanoi(n - 1, from, to, via);
    printf("원판 %d: %c -> %c\n", n, from, to);
    hanoi(n - 1, via, from, to);
}
```

실행 결과 (`hanoi(3, 'A', 'B', 'C')`)

```text
원판 1: A -> C
원판 2: A -> B
원판 1: C -> B
원판 3: A -> C
원판 1: B -> A
원판 2: B -> C
원판 1: A -> C
이동 횟수: 7
```

이동 횟수 $$T(n) = 2T(n-1) + 1,\ T(1) = 1$$을 풀면 $$T(n) = 2^n - 1$$. 3개면 7번이다.

## 최종 핵심 정리

1. 순차 탐색은 정렬이 필요 없지만 $$O(n)$$이고, 1~100에서 46을 찾는 데 46번 비교한다
2. 이진 탐색은 정렬된 배열에서 범위를 절반씩 줄여 $$O(\log n)$$이고, 46은 5번에 찾는다
3. n개에서 이진 탐색의 최대 비교 횟수는 $$\lfloor \log_2 n \rfloor + 1$$이다
4. 모든 쌍을 비교하는 중복 검사는 $$\frac{n(n-1)}{2}$$회로 $$O(n^2)$$이다
5. 재귀 함수는 기저 조건과 자기 자신을 부르는 재귀 호출로 이루어진다
6. 팩토리얼은 재귀와 반복 모두 6! = 720이고, int는 13!부터 넘친다
7. 피보나치를 그대로 재귀로 짜면 같은 값을 반복 계산해 호출 횟수가 지수적으로 늘어난다
8. 하노이 탑의 이동 횟수는 $$2^n - 1$$이다
