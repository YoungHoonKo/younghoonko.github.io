## 1. 매슬로우의 욕구위계이론

| 단계 | 욕구 | 내용 |
| --- | --- | --- |
| 1 | 생리적 욕구 | 음식, 수면 등 생존 |
| 2 | 안전 욕구 | 신체적·심리적 안전, 안정된 환경 |
| 3 | 사회적 욕구 (애정·소속) | 사랑, 소속감, 우정 |
| 4 | 존경 욕구 | 인정받고 싶은 욕구, 자존감 |
| 5 | 자아실현 욕구 | 잠재력 실현, 창의적 몰입 |

- 하위 욕구가 충족되어야 상위 욕구가 나타나고, 위로 갈수록 충족하기 어렵다
- 수업에서는 1·2단계를 개인의 욕구, 3·4·5단계를 **관계 속에서 생기고 관계를 통해 충족되는 욕구**로 묶었다. 그래서 인간관계가 행복과 성장의 핵심이 된다

> **(중요!!)** 한계: 하위 욕구가 충족되어야만 상위 욕구를 충족할 수 있는 것은 **아닐 수 있다**. 욕구의 순서는 사람과 상황에 따라 바뀌고 겹치며, 서구 개인주의 문화에 편향되어 있고, 자아실현의 개념이 모호하다.

## 2. 정신건강

| 의미 | 정의 |
| --- | --- |
| 좁은 의미 | 정신질환이 없는 상태 |
| 넓은 의미 | 신체적·정신적·사회적 기능을 최대한 발휘할 수 있는 상태 |

| 이론 | 정신건강을 유지하는 방식 |
| --- | --- |
| 프로이트 (정신분석) | 원초아(욕구)와 초자아(규범) 사이에서 자아가 방어기제로 균형을 잡음 |
| 융 (분석심리) | 무의식 속 부정적 측면(그림자)을 이해하고 통합 |
| 로저스 (인본주의) | 자아와 경험이 일치할 때 진정성과 자기 수용이 생김 |
| 소질-스트레스 모형 | 스트레스에 취약한 소질을 가진 사람도 스트레스를 잘 관리하면 건강을 유지 |

## 3. 방어기제

모든 방어기제의 공통점: ① 현실을 왜곡하거나 부정한다 ② **무의식적으로** 작동한다

| 기제 | 설명 | 예시 |
| --- | --- | --- |
| 억압 | 불쾌한 감정이나 기억을 무의식으로 밀어냄 | 거절이 두려워 시도조차 하지 않음 |
| 투사 | 자신의 감정이나 생각을 남의 것으로 돌림 | 내가 상대를 좋아하면서 상대가 나를 좋아한다고 여김 |
| 치환 | 원래 대상 대신 덜 위협적인 대상에게 감정을 돌림 | 좋아하는 사람 대신 다가가기 쉬운 사람에게 고백 |
| 동일시 | 동경하는 대상의 특성을 자기 것으로 받아들임 | 연예인의 말투와 행동을 따라 함 |
| 반동형성 | 실제 감정과 반대로 행동 | 좋아하는 사람에게 오히려 냉정하게 대함 |
| 합리화 | 그럴듯한 이유로 결과를 정당화 | "어차피 잘 안 될 줄 알았어" |

## 4. 부적응적 인간관계

| 대분류 | 유형 | 특징 |
| --- | --- | --- |
| 회피형 | 경시형 | 인간관계를 사소하게 여기고 거리를 둠 |
| | 불안형 | 친밀감을 원하지만 거절이 두려워 피함 |
| 피상형 | 실리형 | 이득을 위해서만 관계 유지 |
| | 유희형 | 즐거움 위주의 가벼운 관계 |
| 미숙형 | 소외형 | 대인 기술 부족으로 소외됨 (단정치 못한 외모, 예의 없는 태도, 배려 부족, 부적절한 언행. 악의는 없음) |
| | 반목형 | 자주 다투고 공격적 |
| 탐닉형 | 의존형 | 타인에게 지나치게 의존 |
| | 지배형 | 타인을 통제하려 함 |

심리장애 유발 요인: 비현실적 욕구와 동기, 경직된 사고와 신념, 대인 기술 부족, 왜곡된 인지와 판단, 감정의 불안정

## 6. 관계를 촉진하는 대화 (10장)

대화는 **말하는 사람의 의도 → 표현된 말 → 듣는 사람의 인식틀**이 맞물리는 톱니바퀴 구조다. 같은 말("내일 발표할 자료가 그게 다야?")도 의도(보충이 필요하다)와 다르게 해석(비난한다)될 수 있다.

### 대화의 걸림돌

| 말하는 사람의 전달 방식 | 듣는 사람의 태도 |
| --- | --- |
| 산만형: 주제 없이 이야기가 계속 옆길로 → 한 주제를 마무리하고 넘어가기 | 다른 일과 비교하기: 상대 말을 내 경험에 비추어 들음 |
| 독점형: 자기 이야기만 길게 → 대화의 키를 상대에게 넘기기 | 지레짐작하기: 내 생각에 맞는 단서만 골라 들음 |
| 과신형: 자기 말만 옳다고 단정 → "저도 잘 모르지만"으로 시작하기 | 듣기 싫은 얘기 걸러내기: 인정하기 싫은 말을 막아 버림 |

- 성격 차이도 걸림돌이 된다. 외향형은 내향형에게 생각할 시간과 정보를 미리 주고, 내향형은 외향형에게 크게 반응하며 정리할 시간을 미리 요청한다
- 비언어적 태도: 강의에서는 커뮤니케이션을 말 10%, 목소리 30%, 표정 60%로 설명했다. 표정, 눈맞춤, 자세, 목소리의 높낮이와 속도가 감정을 더 강하게 전달한다

### 대화 비결

- 잘 듣는 방법: 귀담아듣기, 끊지 않기, 판단하지 않기, 반응하며 듣기, 편안한 분위기
- 경청의 자세: 적당한 거리, 팔짱·다리 꼬기 피하기, 살짝 기울여 마주 보기, 적절한 눈맞춤과 끄덕임
- **열린 질문**: "네 생각을 좀 더 이야기해 줄래?"처럼 상대가 스스로 표현하게 함
- **공감**: 상대의 생각의 틀로 감정과 생각을 이해하고 인정하는 것

| 수준 | 뜻 |
| --- | --- |
| 표면적 공감 | 드러난 감정을 알아줌 |
| 촉진적 공감 | 상대가 표현한 것보다 **더 깊은 내면의 감정**까지 표현해 줌 |

촉진적 공감 공식: **원함** "당신은 ~하기를 원했는데" + **상황** "~하여서" + **감정** "~한 것 같네요"

예: 연락 없이 30분 늦어 친구가 화를 낼 때, "늦을 수도 있지"(공감 없음)나 "미안해"보다 "연락을 못 해서 무시당했다는 생각이 들어 서운했겠구나. 다음에는 걱정하지 않게 신경 쓸게, 미안해"가 가장 공감 수준이 높다.

## 7. 갈등관리 (12장)

- **갈등(葛藤)**: 칡(葛)과 등나무(藤)가 서로 반대 방향으로 감겨 얽힌 모습
- 전통적 관점은 갈등을 싸움과 대립으로 보지만, 현대적 관점은 갈등을 **풀어 가는 과정**과 기회로 본다
- 사람마다 다르기 때문에 갈등은 피할 수 없다 → 해결이 아니라 **관리**의 대상
- 원인: 차이에 대한 이해 부족, 의사소통 능력의 한계

### 토마스-킬만 갈등관리 5유형

두 축: **공격성**(자기 관심을 충족하려는 정도)과 **협조성**(타인의 관심을 충족하려는 정도)

| 유형 | 공격성 | 협조성 | 특징과 한계 |
| --- | --- | --- | --- |
| 경쟁형 | 높음 | 낮음 | 자기 목표만 추구. 상대의 참여 기회를 빼앗음 |
| 회피형 | 낮음 | 낮음 | 피하거나 보류. 해결되지 않고 신뢰가 약해짐 |
| 순응형 | 낮음 | 높음 | 상대에게 맞춤. 욕구 불만이 쌓임 |
| 타협형 | 중간 | 중간 | 서로 일부 양보. 미해결된 불만이 남을 수 있음 |
| 협력형 | 높음 | 높음 | 서로의 이익을 모두 중시해 윈-윈 |

### 갈등관리 전략

1. 서로의 **드러난 욕구와 드러나지 않은 욕구**를 파악한다
2. 긍정적으로 접근한다 (상대의 의도를 먼저 인정)
3. 두 사람의 입장을 명확히 한다
4. 윈-윈을 목표로 기준을 제시하고 동의를 끌어낸다
5. 여러 해결책을 만들어 합의해서 고른다

솔직하되 공격적이지 않게, 상대가 무엇을 할 수 있는지가 아니라 **내가 무엇을 할 수 있는지**에 집중한다.

## 최종 핵심 정리

1. 매슬로우는 생리, 안전, 사회적, 존경, 자아실현 순서로 욕구가 나타난다고 했지만 순서가 고정되지 않을 수 있다는 한계가 있다
2. 정신건강은 좁게는 질환이 없는 상태, 넓게는 신체·정신·사회적 기능을 최대로 발휘하는 상태다
3. 방어기제는 현실을 왜곡하고 무의식적으로 작동하며 억압, 투사, 치환, 동일시, 반동형성, 합리화가 있다
4. 부적응적 관계는 회피형, 피상형, 미숙형, 탐닉형과 그 아래 8가지 유형으로 나뉜다
5. 상황을 통제할 수 있으면 문제 중심, 어려우면 정서 중심 대처가 적합하다
6. 경청과 열린 질문이 대화를 이어 주고, 촉진적 공감은 원함·상황·감정을 함께 말해 준다
7. 갈등은 피할 수 없으므로 해결이 아니라 관리의 대상이다
8. 갈등관리 5유형 중 공격성과 협조성이 모두 높은 협력형이 윈-윈을 만든다
