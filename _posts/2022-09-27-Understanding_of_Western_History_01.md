## 1. 미케네 문명과 암흑시대

### 미케네 문명 (c. 1600~1100 BC)

- 크레타(미노스) 문명의 영향을 받아 **미케네**를 중심으로 발전
- 인도유럽어족의 일파가 유럽 대륙에서 이주해 중부 그리스와 펠로폰네소스에 왕국을 세움
- 전성기(1400~1200 BC): 히타이트 기록에 등장, 왕궁 건축, **선문자 B** 사용 (벤트리스와 채드윅이 해독)
- 트로이 전쟁: 원인은 헬레네의 납치라는 전설보다 **경제적 이해의 충돌**로 보는 해석이 있다
- 종교는 다신교(포세이돈, 디오니소스 등)였고 구원의 개념은 없었으며, 국가가 종교를 통제

### 쇠퇴 (1200~1100 BC)

| 원인론 | 내용 |
| --- | --- |
| 외부원인론 | 도리스족이나 "바다 민족(Sea People)"의 침입, 지진과 가뭄 같은 자연재해 |
| 내부원인론 | 체제의 구조적 문제, 국가 간 전쟁, 대중의 저항 |

### 암흑시대 (1150~700 BC)

- 문화적 쇠퇴와 사료 부족 때문에 붙은 이름이지만, 1960년대 이후 고고학 유물이 늘면서 **용어 자체에 문제가 제기**되었다
- 사료: 호메로스의 서사시, 헤시오도스의 『신통기』
- 그리스 종교의 특징: 신들의 인격화, 공식 교리가 없음, 도덕과 무관, 사후세계 관념이 약함(하데스, 낙원과 지옥 없음) → 신과 인간이 대등하게 교류하는 관념이 **철학과 과학적 사고의 토대**가 됨
- 범 그리스주의(Pan-hellenism): 오리엔트와의 접촉 증가 → 범 그리스적 사원과 축제(올림피아 등)

## 2. 폴리스와 식민운동

### 폴리스의 성립 (기원전 800년경부터)

- 구조: 도시 + 촌락, 중심에 **아크로폴리스**(성채)와 **아고라**(광장)
- **집주(synoikismos)**: 여러 공동체 주민이 새 정주지로 모이는 과정
- 구성원: 귀족(유력자이자 전사) → 초기에는 귀족정

### 식민운동 (기원전 8~6세기)

- 이유: 인구 증가와 토지 부족, 교역과 금속 자원의 필요, 정치적 불안
- 식민시는 모시(母市)에 예속되지 않은 **정치적 독립체**
- 영향

> **팔랑크스(phalanx, 중장보병 밀집대)** 가 도입되면서 상공업자와 부유한 농민도 군대에 복무했다. 싸우는 사람이 발언권을 얻으면서 **민주정이 발달**했다.

## 3. 스파르타와 아테네

### 스파르타

| 계층 | 지위 |
| --- | --- |
| 시민 (Spartiates) | 완전한 참정권, 군 복무, 국가로부터 토지와 헤일로타이를 할당받음. 인구의 소수 |
| 주변인 (Perioikoi) | 농업·상업·수공업, 자치와 군 복무, 시민권 없음 |
| 예속농민 (Heilotai) | 시민을 부양하는 국가 노예 성격의 농민 |

- 리쿠르고스의 **대법전(Great Rhetra)**, 두 명의 왕, 감독관(ephoros), 장로회(gerousia), 민회(apella) → 왕정+과두정+민주정의 혼합정체로 보기도 함
- **아고게(agoge)**: 국가가 신생아의 생존을 결정하고, 공동체 생활과 공동식사(syssitia)로 전사를 양성

### 아테네 민주정의 발전 단계

| 인물 | 핵심 개혁 |
| --- | --- |
| 솔론 (c. 640~561 BC) | 빚 탕감(seisachtheia), 재산 등급에 따른 금권정치, 400인회, 배심원 법정 |
| 페이시스트라토스 (c. 600~527 BC) | 참주정치. 빈민 구제, 공공건축, 국가 축제 → 민주정에 긍정적 역할을 했다는 평가도 있음 |
| 클레이스테네스 (c. 565~500 BC) | 4개 혈연부족을 **10개 행정부족**으로 개편, 500인회, **도편추방법** |
| 페리클레스 | 민회 권한 강화, 6,000명의 시민 법정, 공직자 수당, 추첨제와 1년 임기 → **직접 민주정의 완성** |

> 아테네 민주정의 한계: 여성·노예·거류외인(metoikos)은 참정권이 없었고, 델로스 동맹국을 희생시킨 **제국주의적 지배에 기생**했으며, 시민권을 제한해 시민단이 폐쇄적이었다.
{: .prompt-info }

## 4. 전쟁과 그리스의 쇠퇴

### 그리스-페르시아 전쟁

- 직접 원인: 밀레토스가 주도한 **이오니아 반란**을 아테네가 지원
- 1차(492 BC) → 2차(490 BC, **마라톤 전투**) → 3차(480 BC, 테르모필레 전투와 **살라미스 해전**, 479 BC 플라타이아·미칼레 전투)
- 결과: **델로스 동맹** 결성 → 아테네가 동맹 금고를 파르테논으로 옮기고(454 BC) 동맹 기금을 민주정과 도시 치장에 전용

### 펠로폰네소스 전쟁 (431~404 BC)

- 원인: 아테네 제국에 대한 시기와 두려움 (투키디데스의 설명)
- 결과: 아테네 성벽 파괴, 델로스 동맹 해체, 30인 과두정
- 이후 스파르타와 테베의 패권 다툼 → 시민 공동체 의식 약화 → 마케도니아의 필리포스 2세에게 굴복(**카이로네이아 전투, 338 BC**)

### 그리스 문화

| 분야 | 인물 |
| --- | --- |
| 비극 | 아이스킬로스(「오레스테이아」), 소포클레스(「오이디푸스 왕」), 에우리피데스(「메데이아」) |
| 희극 | 아리스토파네스(「리시스트라타」) |
| 철학 | 탈레스, 헤라클레이토스, 데모크리토스, 프로타고라스, 소크라테스, 플라톤, 아리스토텔레스 |
| 역사 | 헤로도토스(페르시아 전쟁을 두 문명의 투쟁으로), 투키디데스(사료 비판에 기초한 서술) |

## 5. 알렉산드로스와 헬레니즘

- 알렉산드로스는 범 그리스주의를 내걸고 페르시아 원정(334 BC): 그라니코스 → 이소스 → 가우가멜라
- 323 BC에 사망하면서 계승 장치가 없어 제국이 해체 → 후계자들(디아도코이)의 섭정기 → 마케도니아, 시리아(셀레우코스), 이집트(프톨레마이오스) 왕국

### 헬레니즘

- **드로이젠**이 처음 쓴 용어. 그는 동서 문화가 융합된 국제적 문화로 보았지만, 헬레니즘 문화는 **주요 도시에서만 번성**하고 전통 문화도 존속했다는 반론이 있다
- 정치: 폴리스 대신 영토 국가. 문화: 개인적이고 세계 시민적인 성격
- 철학: 스토아학파, 에피쿠로스학파, 회의주의학파
- 예술: 절제와 균형보다 과장된 현실주의 (라오콘상, 밀로의 비너스)
- 과학: 아리스타르코스·히파르코스·에라토스테네스(천문학), 유클리드(기하학), 아르키메데스(부력)

## 6. 로마의 성장과 몰락

### 로마가 지중해 제국이 된 이유

1. **시민군 제도**에 바탕한 군사력
2. 폴리비오스가 말한 **혼합정체**: 정무관(왕정) + 원로원(귀족정) + 민회(민주정)의 견제와 균형
3. **신분투쟁**: 성산 철수(494 BC) → 12표법(450/449 BC) → 리키니우스-섹스티우스 법(367 BC) → 호르텐시우스 법(287 BC). 완전한 평등은 아니지만 시민의 결속을 만들었다
4. 지배의 유연성: 정복한 도시에 동맹 지위와 자치를 주는 동화정책, 분할통치, 탄력적인 시민권 정책

### 공화정의 위기

```text
포에니 전쟁 등 정복 전쟁
 → 노빌레스(신귀족)·에퀴테스(기사계층) 성장, 라티푼디움(대농장) 성행
 → 자영농 몰락 → 시민군 약화
 → 그라쿠스 형제의 농지개혁 실패 (벌족파 vs 평민파)
 → 마리우스의 병제개혁(107 BC): 직업군인 → 군인 정치가 등장
 → 마리우스 vs 술라 → 1차 삼두정치 → 2차 삼두정치
 → 옥타비아누스의 악티움 해전 승리 → 제정
```

- **팍스 로마나**(27 BC ~ AD 180, 아우구스투스 ~ 마르쿠스 아우렐리우스): 기번이 붙인 이름
- 로마 문화는 문학·철학은 그리스를 모방했지만, **법·도로·수도·건축**처럼 실제적인 분야가 독자적이었다

### 3세기의 위기와 몰락

| 시기 | 내용 |
| --- | --- |
| 군인황제 시대 (235~284) | 26명의 황제가 옹립, 이민족 침입, 소작제 확산 |
| 디오클레티아누스 | **4분 통치**(2명의 아우구스투스와 2명의 카이사르), 스스로를 도미누스라 칭하는 전제군주정, 기독교 박해 |
| 콘스탄티누스 | 제국 재통합(324), 밀라노 칙령, 농민을 토지에 묶음 → **콜로누스**(중세 농노의 선구) |
| 테오도시우스 | 제국을 동서로 양분(395) |
| 476년 | 용병대장 오도아케르가 로물루스 아우구스툴루스를 폐위 → 서로마 멸망 |

> **(중요!!)** 로마의 몰락을 도덕적 타락, 납중독, 기독교 하나로 설명하는 것은 **단일 원인의 오류**다. 군사인력 부족(만족 용병 의존), 공통된 문화와 이해관계 부재, 노예노동 의존과 노동력 부족, **계승 장치가 없는 정치구조**가 어떻게 결합했는지 봐야 한다.

## 최종 핵심 정리

1. 미케네 문명은 선문자 B를 쓰던 왕궁 중심 문명이며, 쇠퇴 원인은 외부 침입과 내부 구조 문제로 나뉜다
2. 암흑시대는 사료 부족에서 나온 용어로, 고고학 성과가 늘면서 용어 자체가 재검토되었다
3. 팔랑크스 전술이 평민을 전사로 만들면서 정치적 발언권이 커져 민주정이 발달했다
4. 아테네 민주정은 솔론, 클레이스테네스를 거쳐 페리클레스 때 완성되었지만 여성·노예·외인을 배제하고 동맹국을 착취했다
5. 펠로폰네소스 전쟁 이후 폴리스의 공동체 의식이 약해져 마케도니아에 굴복했다
6. 헬레니즘은 드로이젠이 만든 용어이며, 동서 융합론에는 도시에서만 번성했다는 반론이 있다
7. 로마의 팽창은 시민군, 혼합정체, 신분투쟁을 통한 결속, 유연한 동맹·시민권 정책 덕분이다
8. 로마의 몰락은 단일 원인이 아니라 군사·경제·정치 구조의 결함이 결합한 결과다
