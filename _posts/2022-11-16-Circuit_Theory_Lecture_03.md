## 1. Op Amp 모델 (Ch4)

op amp는 두 입력 단자(반전 $$-$$, 비반전 $$+$$)의 전압 차를 수십만 배 증폭해 하나의 출력으로 내보낸다. 원래 적분과 미분 같은 **연산(operation)** 을 하려고 만들어서 이런 이름이 붙었다.

### 선형 모델 → 이상 모델

선형 모델은 입력 저항 $$R_i$$, 출력 저항 $$R_o$$, 이득 $$A$$로 표현한다: $$v_o = A(v_+ - v_-)$$.

| 이상화 | 결과 |
| --- | --- |
| $$R_i \to \infty$$ | $$i_+ = i_- = 0$$ (입력 단자로 전류가 안 들어감) |
| $$A \to \infty$$ | $$v_+ = v_-$$ (**가상 단락**) |
| $$R_o \to 0$$ | 출력이 부하에 영향받지 않음 |

> **(중요!!)** 이상 op amp 해석은 두 규칙만 쓴다: **(1) 입력 전류 = 0, (2) $$v_+ = v_-$$**. 단, (2)는 **음의 피드백**이 있을 때만 성립한다. 피드백이 없는 비교기에는 쓰면 안 된다.
{: .prompt-warning }

### 기본 회로

| 회로 | 출력 |
| --- | --- |
| 반전 증폭기 | $$v_o = -\dfrac{R_2}{R_1}v_1$$ |
| 비반전 증폭기 | $$v_o = \left(1 + \dfrac{R_2}{R_1}\right)v_1$$ |
| 전압 팔로워 (버퍼) | $$v_o = v_1$$ |
| 반전 가산기 | $$v_o = -R_f\left(\dfrac{v_1}{R_1} + \dfrac{v_2}{R_2} + \cdots\right)$$ |
| 차동 증폭기 | $$v_o = \dfrac{R_2}{R_1}(v_2 - v_1)$$ (저항비가 맞을 때) |
| 적분기 | $$v_o(t) = -\dfrac{1}{R_1 C}\displaystyle\int_0^t v_1(x)\,dx + v_o(0)$$ |
| 미분기 | $$v_o(t) = -R_2 C\dfrac{dv_1(t)}{dt}$$ |
| 비교기 | 피드백 없음. $$v_+ > v_-$$면 $$+V_{sat}$$, 아니면 $$-V_{sat}$$ |

### 반전 증폭기 유도

$$v_+ = 0$$이므로 가상 단락으로 $$v_- = 0$$. 반전 단자에서 KCL (입력 전류 0):

$$\frac{v_1 - 0}{R_1} + \frac{v_o - 0}{R_2} = 0 \;\Rightarrow\; v_o = -\frac{R_2}{R_1}v_1$$

### 버퍼가 필요한 이유

전압 분배 회로에 부하를 직접 달면 부하 저항이 병렬로 붙어 전압이 떨어진다. 버퍼는 입력 저항이 무한대라서 앞 회로에서 전류를 끌어가지 않고, 출력 저항이 0이라서 뒤 회로에 같은 전압을 그대로 공급한다. 즉 **두 회로를 분리(isolation)** 한다.

실제 op amp의 출력은 전원 전압 근처에서 **포화**하므로, 계산한 $$v_o$$가 전원 범위를 넘으면 그 값은 나오지 않는다.

## 2. 선형성과 중첩 (Ch5.1~5.2)

선형 회로는 두 성질을 만족한다.

$$\text{가법성: } T(u_1 + u_2) = T(u_1) + T(u_2), \qquad \text{동차성: } T(\alpha u) = \alpha T(u)$$

### 동차성 활용: 거꾸로 풀기

사다리형 회로에서 출력 $$V_o$$를 구할 때

1. $$V_o' = 1\text{V}$$라고 가정하고 거꾸로 계산해 필요한 전원 $$V_s'$$을 구한다
2. 실제 전원이 $$V_s$$면 $$V_o = \dfrac{V_s}{V_s'} \times 1\text{V}$$

### 중첩의 원리

독립 전원이 여러 개일 때, **하나씩만 남기고 나머지를 끈 회로**의 응답을 모두 더한다.

| 끌 전원 | 바꾸는 방법 |
| --- | --- |
| 전압원 | 단락 (0V) |
| 전류원 | 개방 (0A) |
| 종속 전원 | **끄지 않는다** |

> 중첩은 전압과 전류에만 쓸 수 있고 **전력에는 쓸 수 없다**. $$p = i^2R$$은 선형이 아니라서 $$(i_1 + i_2)^2 R \ne i_1^2 R + i_2^2 R$$이다.
{: .prompt-danger }

### 전원 변환

전압원 $$V_s$$와 직렬 저항 $$R$$은 전류원 $$I_s = V_s/R$$와 병렬 저항 $$R$$로 바꿀 수 있다 (반대도 가능). 단자 밖에서 보면 같은 회로다.

## 3. 테브난과 노턴 (Ch5.3)

선형 회로는 단자 a-b에서 보면 다음과 같이 바꿀 수 있다.

| 등가회로 | 구성 |
| --- | --- |
| 테브난 | 전압원 $$V_{Th} = v_{oc}$$ + 직렬 $$R_{Th}$$ |
| 노턴 | 전류원 $$I_N = i_{sc}$$ + 병렬 $$R_{Th}$$ |

$$R_{Th} = \frac{v_{oc}}{i_{sc}}, \qquad V_{Th} = I_N R_{Th}$$

### $$R_{Th}$$ 구하는 방법

| 회로 | 방법 |
| --- | --- |
| 독립 전원만 있음 | 독립 전원을 끄고 단자에서 본 합성 저항 |
| 종속 전원 포함 | $$v_{oc}$$와 $$i_{sc}$$를 따로 구해 나눔 |
| 종속 전원만 있음 | $$v_{oc} = 0$$이므로 단자에 시험 전원 $$V_x$$를 걸고 $$R_{Th} = V_x / I_x$$ |

### 예제

12V 전원, 6kΩ과 3kΩ 분압기, 3kΩ 양단에서 2kΩ을 거쳐 단자 a-b로 나가는 회로.

1. 개방 전압: 2kΩ에는 전류가 안 흐르므로 $$V_{Th} = 12 \times \dfrac{3}{6+3} = 4\text{V}$$
2. 전원 끄고 합성: $$R_{Th} = 6\text{k} \parallel 3\text{k} + 2\text{k} = 4\text{k}\Omega$$
3. 노턴: $$I_N = 4/4\text{k} = 1\text{mA}$$

## 4. 최대 전력 전달 (Ch5.4)

테브난 회로에 부하 $$R_L$$을 달면

$$P_L = \left(\frac{V_{Th}}{R_{Th} + R_L}\right)^2 R_L, \qquad \frac{dP_L}{dR_L} = 0 \;\Rightarrow\; R_L = R_{Th}, \qquad P_{max} = \frac{V_{Th}^2}{4R_{Th}}$$

위 예제에서 $$R_L = 4\text{k}\Omega$$일 때 $$P_{max} = 16/(4 \times 4\text{k}) = 1\text{mW}$$다. 이때 효율은 50%로, 전송 효율이 중요한 전력 계통이 아니라 **통신처럼 신호 전력이 중요한 곳**에서 쓰는 조건이다.

```python
import numpy as np
Vth, Rth = 4, 4e3
RL = np.linspace(100, 20e3, 2000)
P = (Vth / (Rth + RL)) ** 2 * RL
print(RL[P.argmax()], P.max() * 1e3)   # 약 4000 Ω, 1.0 mW
```

## 최종 핵심 정리

1. 이상 op amp는 입력 전류가 0이고, 음의 피드백이 있으면 두 입력 전압이 같다
2. 반전 증폭기의 이득은 -R2/R1, 비반전 증폭기의 이득은 1 + R2/R1이다
3. 버퍼는 이득 1이지만 앞뒤 회로를 분리해 부하 효과를 없앤다
4. 선형 회로는 가법성과 동차성을 만족하며, 동차성으로 출력을 1V로 가정해 거꾸로 풀 수 있다
5. 중첩은 독립 전원 하나씩만 남기고(전압원 단락, 전류원 개방) 응답을 더하며, 전력에는 쓸 수 없다
6. 테브난 등가회로는 개방 전압과 직렬 저항, 노턴은 단락 전류와 병렬 저항으로 이루어진다
7. 종속 전원만 있으면 시험 전원을 걸어 테브난 저항을 구한다
8. 부하 저항이 테브난 저항과 같을 때 최대 전력 Vth²/4Rth가 전달된다
