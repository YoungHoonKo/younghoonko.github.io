# Practicing Linux Commands

이번 학습에서는 Git을 터미널에서 다룰 때 자주 사용하는 **리눅스 명령어**들을 실습해보았다. 또한 터미널 기반 편집기인 **Vim**과 관련 설정까지 함께 익혔다.

---

## 기본 명령어

### ✅ `pwd`  
- 현재 작업 중인 디렉토리의 경로 출력  
→ _print working directory_

---

### ✅ `ls`  
- 현재 디렉토리 내의 파일 및 폴더 목록 출력  
→ _list_

옵션 | 설명
---- | -------------------------------
-a   | 숨김 파일 포함
-l   | 상세 정보 보기
-r   | 역순 정렬
-t   | 시간 순 정렬

---

### ✅ `cd`  
- 디렉토리 간 이동  
→ _change directory_

| 명령어 | 설명                       |
|--------|----------------------------|
| `cd ..`   | 상위 디렉토리로 이동        |
| `cd 디렉토리명` | 특정 디렉토리로 이동     |
| `cd ~`    | 홈 디렉토리로 이동         |
| `./`      | 현재 디렉토리를 의미       |
| `../`     | 상위 디렉토리를 의미       |

---

### ✅ `mkdir`  
- 디렉토리 생성  
→ _make directory_

```bash
mkdir 디렉토리명
```

---

### ✅ `rm`  
- 파일 또는 디렉토리 삭제  
→ _remove_

```bash
rm -r 디렉토리명  # 하위 항목 포함 삭제
```

---

### ✅ `cat`  
- 파일 내용 확인 및 병합  
→ _concatenate_

| 명령어                        | 설명                                     |
|-------------------------------|------------------------------------------|
| `cat 파일명`                  | 파일 내용 출력                           |
| `cat 파일1 파일2 > 새파일`     | 파일 병합 후 새 파일로 저장              |
| `cat 파일1 >> 파일2`          | 파일1의 내용을 파일2 뒤에 덧붙이기       |

---

## Vim (기본 편집기)

- 터미널 기반의 대표 편집기
- 메모장 없이 터미널에서 직접 편집 가능

```bash
vim 파일명.txt
```

| 명령어    | 설명                                      |
|-----------|-------------------------------------------|
| `i` 또는 `a` | 입력 모드 진입                              |
| `esc` → `:w` | 저장                                     |
| `esc` → `:q` | 종료                                     |
| `esc` → `:wq`| 저장 후 종료                              |
| `esc` → `:q!`| 저장하지 않고 종료 (임시 파일 생김)       |

---

## Git 편집기 설정

```bash
git config --global core.editor "사용할 편집기"
```

예: `"code --wait"` (VS Code)

---

## 실습 요약

| 명령어       | 사용 예시                         |
|--------------|------------------------------------|
| `cd ~`       | 홈 디렉토리로 이동                 |
| `mkdir pop`  | pop 디렉토리 생성                  |
| `cd pop`     | pop 디렉토리로 이동                |
| `cd ../`     | 상위 디렉토리로 이동               |
| `pwd`        | 현재 위치 경로 확인                |
| `ls`         | 파일 목록 보기                     |
| `ls -a`      | 숨김 파일 포함 목록 보기           |
| `rm -r pop`  | pop 디렉토리 삭제                  |
| `vim word.txt`| word.txt 파일 열기 또는 생성       |

| 명령어         | 설명                       |
|----------------|----------------------------|
| `cat word.txt` | 파일 내용 출력              |
| `clear`        | 터미널 화면 초기화          |
| `exit`         | 터미널 종료                 |

---

> 📌 정리  
터미널 명령어는 Git을 CLI 환경에서 자유롭게 다루기 위한 기초 역량이다. 반복 실습을 통해 익숙해지면 Git을 더 강력하게 활용할 수 있다.
